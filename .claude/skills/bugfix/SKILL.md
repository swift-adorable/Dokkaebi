# 버그 수정

1. 재현부터: EditMode 테스트, 또는 `Dokkaebi/Debug/…` 점검 메뉴(자리 · 방향을 고정해 수치 · 사진으로). 영상이면 video-feedback.
2. Play 중 NullRef 는 먼저 도메인 리로드 탓인지 가른다 — 멈추고 다시 Play 해서도 나는지.
3. 원인을 짐작으로 고치지 않는다 — 값을 꺼내 본다(로그 · 그림 덤프 · 기록 줄). 찾은 원인을 사용자에게 한두 줄로.
4. 가장 작은 수정. 같은 원인의 다른 자리도 grep.
5. 재현 방법으로 고쳐졌는지 확인(전 · 후 나란히) → 테스트 → 필요하면 결정 줄.
