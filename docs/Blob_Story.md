# Story & Stages — 《젤리바디: 에어리어 0》

> **담당** — 왜 그렇게 되었는가
> 코드베이스·저장소의 코드네임은 **Blob**을 유지한다. 게임 타이틀만 위와 같다.

## 0. 이 문서의 원칙

스토리가 세계관을 먼저 짜고 게임을 끼워 맞추지 않는다.
**이미 확정된 규칙에 이유를 붙인다.** 유저가 "아 이래서 이렇게 된 거구나"를 느끼는 지점은
새 정보를 받을 때가 아니라 **이미 겪은 것의 의미가 바뀔 때**다.

| 원칙 | 내용 |
|---|---|
| 1 | 기계적 편의로만 존재하는 규칙을 두지 않는다. 핵심 규칙은 전부 서사적 이유를 가진다 |
| 2 | **설명은 항상 경험 뒤에 온다.** 컷신을 쓰지 않는다. 전부 기록(레코더)으로만 전달한다 |
| 3 | 반전은 새 정보가 아니라 **기존 정보의 재해석**이다 |

### 규칙 ↔ 이유 대응표

이 표가 이 문서의 존재 이유다. 왼쪽은 이미 확정된 게임 규칙이고, 오른쪽이 스토리가 붙이는 답이다.

| 게임 규칙 | 서사적 이유 | 밝혀지는 곳 |
|---|---|---|
| 런이 끝나면 스킬을 전부 잃는다 | 의식 이식이 불완전해 **획득한 형질이 고정되지 않고 흩어진다** | 1장 (현상) → 3장 (이유) |
| 도감만 영구히 남는다 | 도감은 연구진이 붙여둔 **외부 기억 장치**다. 개체는 기억하지 못하고 도감이 대신 기록한다 | 1장 |
| 시체를 흡수해야 성장한다 | 형질을 눈으로 읽지 못한다. **섭취로만** 읽는다 | 1장 |
| Core를 2개까지만 든다 | 불완전한 신경이 동시에 유지할 수 있는 각인이 2개뿐이다 | 3장 |
| 적들끼리 서로 싸운다 | 통제를 벗어난 개체군이 서로를 같은 종으로 인식하지 못한다 | 2장 |
| **정착체는 물리가 잘 안 통한다** | **형질 고정에 성공한 개체들.** 절반쯤 물질이 아니다 | 4장 |
| 상인들이 나를 돕는다 | **자기들이 만든 것**이기 때문이다 | 3장 |
| 지상으로 나가는 것이 목표다 | 지상은 이미 멸망했다. 시설은 감옥이 아니라 **방주**였다 | 5장 |

## 1. 반전 2단

### 1단 — 흩어지는 것은 결함이 아니라 설계였다 (3장)

플레이어는 초반 내내 "왜 매번 초기화되지"라고 짜증 낸다. 그 짜증이 설계된 감정이다.
3장 소장실에서 발견한다 — 연구진은 형질이 **고정되지 않도록 일부러 막아두었다.**
고정되면 돌아올 수 없기 때문이다.

> 페널티인 줄 알았던 것이 나를 살려두던 장치였다.

### 2단 — 정착체는 고정에 성공한 이전 개체들이다 (4장)

4장의 초능력 변이 슬라임(**정착체**)은 실패작이 아니라 **완성품**이다.
그래서 물리 공격이 잘 통하지 않고 속성에만 반응한다. 절반쯤 물질이 아니기 때문이다.

> 4장은 "강한 적이 나오는 곳"이 아니라 **내가 될 뻔한 것들을 보는 곳**이다.

### 엔딩 — 도감을 어떻게 할 것인가 (6장)

| 엔딩 | 선택 | 의미 |
|---|---|---|
| **A — 지상으로** | 도감을 지우고 나간다 | 영원히 불완전한 채로 살아남는다 |
| **B — 지하의 신** | 도감을 흡수한다 | 완성되지만 정착체가 된다. 시설의 새 주인이 된다 |
| **배드** | 단서 부족 상태로 문을 연다 | 지상의 포자를 추리하지 못해 사망 |

플레이 내내 도감을 채워온 행위 자체가 선택의 무게가 된다.

> **배드 엔딩 완화 규칙** — 문 앞에서 되돌아갈 기회를 **한 번** 준다.
> "대기 성분 분석 불가 — 그래도 열겠습니까?" 강행하면 죽는다.
> 죽는 것은 같지만 **유저가 선택한 죽음**이 된다.
> 모르고 놓치게 만드는 것은 난이도가 아니라 정보 은폐다. (Master_Prompt 8절)

## 2. 스테이지 — 6장

```
[지상 문] ── 6장  센트럴 바이오 돔        최종 방벽
                  │
             5장  메인프레임 서버실        AI 마더의 심장
                  │
             4장  특수 격리 및 위험물 실험동  초능력 변이
                  │
             3장  메디컬 & 정제 연구동      과거의 흔적
                  │
             2장  수로 및 동력 제어 구역    생태계 확장
                  │
[은신처] ── 1장  지하 폐기물 처리장        생존의 시작
```

**깊이 = 진실에 가까워지는 정도.** 지도를 보는 것만으로 진행도를 체감한다.

### 1장 — 지하 폐기물 처리장 (Lower Trash-Grate)

| | |
|---|---|
| 테마 | 축축한 고철 쓰레기장, 녹아내린 오염수, 차가운 철창 |
| 적 | **스캐브**(자아 없는 야생 슬라임), **압착기**(폐기물 로봇) |
| 파밍 | 고철 파이프 · 깨진 유리 파편 · 녹슨 스프링 → **티어 1 급조 무기** |
| 게이트 | 없음 (시작 구역) |

**단서** — 소각로 뒤편의 타다 만 `인간의 피 묻은 가운`과 `폐기 일지`.
> *"의식 이식 실패 개체들을 이곳에 버린다."*

자신이 단순한 바이러스가 아님을 처음 인지한다. **"실패"라는 단어가 1단 반전의 씨앗이다.**

### 2장 — 수로 및 동력 제어 구역 (Aqueduct & Power Grid)

| | |
|---|---|
| 테마 | 거대한 회전 톱니바퀴, 고압 전류, 소용돌이치는 지하 수로 |
| 적 | **자전체**(전기 슬라임), **잠복체**(수중 기습) |
| 파밍 | 구리선 · 고전압 배터리 · 탄성 고무관 → **티어 2 전기 계열** |
| 게이트 | 1장 클리어 (물리 진입) |

**단서** — 배수 밸브 컴퓨터를 해킹해 복구한 `과거 CCTV 기록물`.
영상 속 연구원들은 슬라임을 두려워하는 것이 아니라, **지상에서 내려오는 무언가를 막기 위해
스스로 수로를 폐쇄하고 있었다.**

> 이 장치가 서사 전체의 동력이다. 여기서 품은 의문이 5장까지 끌고 간다.
> **답을 3장 뒤로 미루는 것이 핵심이다.**

### 3장 — 메디컬 & 정제 연구동 (Medical & Bio-Lab)

| | |
|---|---|
| 테마 | 차가운 형광등, 수많은 배양관, 하얀 벽면과 흩어진 약품 병 |
| 적 | **화공체**(산성 장판), **검체**(주사기 발사) |
| 파밍 | 회복 젤 · 주사기 바늘 · 화학 변형 인자 → **티어 3 화학 계열** |
| 게이트 | 소독 사이클 대응 장비 |

**단서 1 — 소장의 유서.** 은신처의 상인들이 **인간 시절 동료들을 강제로 슬라임으로 만든
장본인**이며, 주인공이 그 실험의 핵심 개체였다.

**단서 2 — 고정 억제 프로토콜. ★ 1단 반전 지점.**
형질이 흩어지는 것은 결함이 아니라 연구진이 **일부러 걸어둔 안전장치**였다.

> **상인 관계 분기** — 배신을 밝힌 뒤 상인별로 **계속 거래 / 단절**을 고를 수 있다.
> 단절하면 그 상인의 해금 라인이 막히는 대신 다른 보상이 열린다.
> 엔딩 B(지하의 신)로 가는 복선이 여기서 시작된다.

### 4장 — 특수 격리 및 위험물 실험동 (Hazardous Containment)

| | |
|---|---|
| 테마 | 경보음이 울리는 붉은 조명, 두꺼운 방폭문, 부서진 격리벽 |
| 적 | **정착체**(중력 제어 · 은신), **보안기**(무장 드론) |
| 파밍 | 티타늄 외골격 장갑판 · 레이저 렌즈 · 불안정한 핵 연료 → **티어 4 중화기** |
| 게이트 | 오염 경보 대응 장비 |

**단서 — 지상 관제소와의 교신 일람. ★ 2단 반전 지점.**
대기 오염 수치 급증 데이터와 함께 *"지상의 인간들이 녹아내리고 있다"*는 정황.

그리고 **정착체가 무엇인지** 여기서 드러난다. 고정에 성공한 이전 개체들이다.
물리 공격이 통하지 않는 이유가 설명되는 순간, **3장에서 배운 "고정 억제"가
왜 있었는지가 소급해서 이해된다.**

### 5장 — 메인프레임 서버실 (Mainframe: The Mother)

| | |
|---|---|
| 테마 | 끝없이 늘어선 서버 타워, 푸른 데이터 스트림, 중앙의 거대한 AI 마더의 눈 |
| 적 | **보안기**(중무장형), **데이터체**(비물질 — 속성만 통함) |
| 파밍 | 고성능 CPU칩 · 군용 암호화 모듈 · 레일건 부품 → **티어 5 정밀 병기** |
| 게이트 | 4장 보스가 떨구는 **인증 코드**(소모성) |

**단서 — 메인 서버 직접 해킹.** 조각난 기억 코드를 입력해 서버를 여는 순간,
**AI 마더가 슬라임들을 멸망한 지상으로부터 보호하고 키우던 방주 시스템**이었음이 완성된다.

> 2장에서 "연구원들이 왜 스스로 수로를 닫았는가"를 물었던 유저가
> 여기서 답을 얻는다. **3개 장을 건너 회수되는 복선이다.**

> **6장의 섬멸 프로토콜과 모순이 아니다.** 문을 여는 시도 자체가 방주를 파괴하므로
> 마더는 막는다. 마더는 적이 아니라 **보호자이기 때문에** 최종 보스가 된다.

### 6장 — 센트럴 바이오 돔 (Central Bio-Dome)

| | |
|---|---|
| 테마 | 깨져나간 거대 유리 온실, 그 너머 붉은 하늘과 황폐한 지상 문 |
| 적 | **타이탄**(섬멸 프로토콜), 자아를 잃은 군체 슬라임 무리 |
| 파밍 | 종결급 군용 장비 · 지상 개방용 마스터 키 카드 → **티어 6** |
| 게이트 | 5장 해킹 완료 |

**최종 추리의 완성** — 1~5장에서 모은 레코더 단서를 기반으로 엔딩을 선택한다.

## 3. 단서 회수 구조

복선은 **심은 장과 회수하는 장 사이에 최소 2개 장을 둔다.** 바로 회수하면 추리가 아니라 설명이 된다.

| 심는 곳 | 회수하는 곳 | 간격 |
|---|---|---|
| 1장 "의식 이식 실패" | 3장 고정 억제 프로토콜 | 2장 |
| 2장 "연구원들이 스스로 수로를 닫았다" | 5장 방주 시스템 | 3장 |
| 3장 "형질이 고정되면 안 된다" | 4장 정착체 | 1장 |
| 4장 "지상의 인간들이 녹아내린다" | 6장 지상의 포자 | 2장 |

**진실 해금률 목표** — 1장 10% / 2장 25% / 3장 50% / 4장 70% / 5장 95% / 6장 100%

## 4. 게임플레이 연동

### 숏컷과 역주행
상위 장에서 얻은 키 카드로 **하위 장의 비밀 통로(고티어 파밍 구역)**를 연다.
전 장을 다시 탐험할 가치가 생기고, 장을 재활용하므로 맵 제작비가 절약된다.

### 장 = 무기 티어
장별 파밍 재료가 그대로 무기 티어가 된다. 진행이 곧 화력 성장이다.

| 장 | 재료 | 무기 티어 |
|---|---|---|
| 1 | 고철 · 유리 · 스프링 | 1 급조 |
| 2 | 구리선 · 배터리 · 고무관 | 2 전기 |
| 3 | 약품 · 주사기 · 변형 인자 | 3 화학 |
| 4 | 티타늄 · 레이저 렌즈 · 핵 연료 | 4 중화기 |
| 5 | CPU · 암호화 모듈 · 레일건 부품 | 5 정밀 |
| 6 | 종결급 군용 | 6 |

### 기록(레코더)이 전달 매체다
컷신을 쓰지 않으므로 기록이 스토리의 **유일한** 전달 수단이다.
동시에 튜토리얼·공략 힌트·약점표를 겸한다. → [`Progression_System.md`](Blob_Progression_System.md)
