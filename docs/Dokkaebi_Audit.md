## F. 미구현 (로드맵상 정상 — 참고용)

- **결정 2-52 (거점 상인 · 건물)** — 문서 · 본문은 바꿨고 코드는 아직 이전 구조다: `BuildingTable`(잡화 · 무기 · 방어구 상점) · `StoryTable.merchants`(참봉 → 잡화 · 빚쟁이 → 방어구 · 길달 → 무기) · 결정 2-57(약은 약탕간 · 잡화 가게에 음식)도 미반영 → 목표: 영감 → 잡화 가게(처음부터) · 빚쟁이 → 대장간(무기 + 방어구) · 참봉 → 약탕간 · 길달 → 장부방. 장별 재료 24종도 에셋이 없다
