0. 방침 — 그대로 도용한다
--------------------------------------------------------------------------------
Duckov의 장비 체계를 구조·슬롯·스탯 항목까지 그대로 가져온다.
임의로 축약하거나 재해석하지 않는다.

바꾸는 것은 딱 세 가지뿐이다.

  1. 속성 5종을 Blob의 속성으로 치환한다
     Duckov : 물리 / 공간 / 전기 / 화염 / 독
     Blob   : 물리 / 냉기 / 번개 / 화염 / 카오스
     ※ Skill 시스템의 5속성과 일치시켜야 「내화 피부」 같은 레이드 특성과
        장비 내성이 같은 축에서 계산된다.

  2. Duckov의 "폭풍 방어"를 「레이드 특성 저항」으로 치환한다
     Duckov의 폭풍은 특정 구역의 환경 피해다.
     Blob의 대응물은 레이드 특성이므로 그쪽에 연결한다.

  3. 아이템 이름은 Duckov 것을 쓰지 않는다
     구조만 도용하고 이름은 Blob 세계관으로 새로 짓는다.
     (저작권 문제이자, 오리 세계관 이름이 Blob에 맞지 않는다)

1. Duckov 실측 자료 (도용 근거)
--------------------------------------------------------------------------------

[슬롯 6종]  [확인됨]
  머리 방어구 / 신체 방어구 / 얼굴 / 이어폰 / 가방 / 토템

[모든 장비의 공통 표기]  [확인됨]
  무게 (kg) / 최대 내구도 / 옵션 (여러 줄)

[실측 옵션 항목]  [확인됨]
  머리 방어구 +N        신체 방어구 +N
  가방 공간 +N          최대 소지 중량 +N
  이동 능력 ±N%         이동 속도 / 달리기 속도
  시야 거리 ±N%         시야 각도 ±N%        야간 시야 능력 +N
  감지 거리 +N          발각될 거리 계수 -N
  청각 ±N               소리로 위치 파악 +N
  달리기 소리 범위 -N   보행 소리 범위 -N
  에너지 소모율 ±N%     수분 소모율 ±N%
  물리/공간/전기/화염/독 대미지 내성 배율 ±N
  폭풍 방어 +N          화염 방어 +N   전기 방어 +N   독가스 방어력 +N
  근접 대미지 배율 +N   총기 헤드샷 대미지 +N   근접 치명타 대미지 +N
  영혼 대미지 감당 배율 -N

[실측 사례 — 성능과 대가의 패턴]  [확인됨]
  왕관              21.7kg / 머리 +1 / 근접 +0.1 / 헤드샷 +0.1 / 전 속성 내성 -0.1
  신의 용접 헬멧     3.6kg / 머리 +6 / 시야각 -30%
  비다 헬멧          2.1kg / 머리 +5 / 시야각 -30% / 이동 -5% / 수분 소모 +10%
  바리케이드 헬멧    3.8kg / 머리 +4 / 시야각 -70% / 헤드샷 +0.05
  탱크 헬멧          0.4kg / 머리 +1.5 / 청각 -1
  5레벨 경량 헬멧    2.2kg / 머리 +5.1 / 청각 -0.5
  눈가리개           0.1kg / 감지 +4.5 / 청각 +0.2 / 근접 +10% / 야간 시야 +1
                            / 시야 거리 -900%
  4레벨 작전 방탄복  3.8kg / 신체 +3.9 / 가방 공간 +7
  4레벨 중형 방탄복  6.7kg / 신체 +4.3 / (가방 공간 없음)
  전술 가방 MAX      3.9kg / 최대 소지 중량 +30 / 가방 공간 +30

  → 읽어낼 수 있는 규칙
     · 티어가 높을수록 페널티가 커진다
     · 같은 티어 안에서 "방어 ↔ 적재", "방어 ↔ 무게", "방어 ↔ 감각"을 맞바꾼다
     · 극단적인 장비일수록 극단적인 대가를 진다 (눈가리개: 시야 -900%)
     · 가방만이 최대 소지 중량과 가방 공간을 동시에 준다

[세트 효과]  [확인됨]
  석면 세트 : 전신 착용 시 바닥 화염 피해 무효
  폭풍 세트 : 전신 착용 시 1단계 폭풍 무효
  공간 방호 : 단독으로 공간 교란 방어, 세트로 공간 왜곡까지 방어
  고무 작업복 : 몸통 단독으로 바닥 전류 피해 무효

  → 세트 효과는 수치가 아니라 【규칙(면역·무효화)】으로 준다.

[티어]  [확인됨]
  1~6레벨 체계. 6티어는 성능이 높지만 제작·구매가 막혀 드랍/암시장에 의존한다.
  보스 고정 장비는 성능이 좋지만 내구도가 크게 깎인 상태로 떨어진다.

2. Blob 슬롯 — 6 (Duckov 그대로)
--------------------------------------------------------------------------------
| 슬롯     | 주 역할                        | 비고                          |
|----------|--------------------------------|-------------------------------|
| 머리     | 방어 + 감각 페널티             | 대가가 가장 자주 붙는 슬롯    |
| 몸통     | 방어 + 적재 공간               | 방어와 적재를 맞바꾼다        |
| 얼굴     | 시야 · 감지                    | 방어력은 거의 없다            |
| 청각     | 소리 · 위치 파악               | 방어력 없음                   |
| 가방     | 최대 소지 중량 + 적재 공간     | 이중 제한의 핵심 슬롯         |
| 토템     | 특수 효과 1개                  | 방어력 없음. 유틸 전용        |

  ※ Duckov의 "이어폰" 슬롯을 「청각」으로만 바꿨다. 기능은 동일하다.
  ※ 6슬롯을 줄이지 않는다. 슬롯 수가 곧 빌드 조합의 폭이다.

3. 공통 속성
--------------------------------------------------------------------------------
모든 장비가 반드시 가진다.

  · 무게 (kg)   — 소수점 1자리. 0.1 ~ 25.0
  · 최대 내구도 — 0이 되면 방어 옵션이 작동을 멈춘다 (다른 옵션은 유지)
  · 티어 1~6    — 성능 대역
  · 옵션 목록   — 4절의 항목이 0개 이상

  ※ Skill은 티어를 쓰지 않지만 장비는 쓴다.
     Skill의 티어는 "같은 이름의 등급 구분"이라 인지 부담이지만,
     장비의 티어는 서로 다른 아이템이므로 문제가 없다.

--------------------------------------------------------------------------------
4. 옵션(능력치) 항목 — Duckov 구조 그대로
--------------------------------------------------------------------------------

[방어]
  머리 방어              +N
  몸통 방어              +N
  속성 내성 배율         물리 / 화염 / 냉기 / 번개 / 카오스   각 ±N
  레이드 특성 저항       +N        ← Duckov 「폭풍 방어」 대응

[생존]
  체력 재생              +N/초
  보호막 재생            일정 시간 무피격 시 재생
  치명상 무적            N초

[기동]
  이동 능력              ±N%
  대시 쿨다운            ±N%

[탐지]
  시야 거리              ±N%
  시야 각도              ±N%
  야간 시야 능력         +N
  감지 거리              +N
  발각될 거리 계수       -N

[청각]
  청각                   ±N
  소리로 위치 파악       +N
  이동 소리 범위         -N

[수집]
  Biomass 흡수 범위      +N%
  Biomass 흡수량         +N%
  희귀 이상 적 드랍률    +N%        ← 사냥 시스템과 연동

[적재]
  최대 소지 중량         +N
  적재 공간              +N

  ※ Duckov에 있으나 Blob에 도입하지 않는 항목
       에너지 / 수분 소모율 — Blob에 허기·갈증 시스템이 없다
       근접 대미지 / 헤드샷 대미지 — Blob은 단일 사격이며 부위 판정이 없다
       영혼 대미지 — 대응 개념이 없다
     ※ 필요해지면 그때 추가한다. 지금 넣으면 죽은 스탯이 된다.

5. 확정 규칙
--------------------------------------------------------------------------------

[5-1] 무게와 이중 제한
  · 착용 장비 + 가방 내용물의 무게 합이 「최대 소지 중량」을 넘으면
    이동 능력과 대시 거리가 단계적으로 감소한다.
  · 초반 병목은 적재 공간, 중반 이후 진짜 병목은 무게다. (Duckov와 동일)
  · 「가방」이 최대 소지 중량과 적재 공간을 동시에 제공하는 유일한 슬롯이다.
  · 과중량 단계는 3단계로 둔다. (수치는 TBD)

[5-2] 강한 장비에는 반드시 대가가 붙는다
  · 티어 4 이상의 장비는 최소 1개의 음수 옵션을 가진다.
  · 티어 6은 최소 2개.
  · 이것이 Skill의 통화(Cost) 원칙과 같은 사상이다.
      Skill : 메커니즘을 얻으면 대가를 치른다
      장비  : 성능을 얻으면 무게나 감각을 내준다

[5-3] 내구도
  · 피격 시 감소한다. 0이 되면 【방어 옵션만】 작동을 멈춘다.
    탐지·수집·적재 옵션은 계속 작동한다.
  · 벙커에서 수리한다. 일부 장비는 수리 불가로 두어 소모품성을 만든다.
  · 고유(보스) 등급 적이 떨구는 장비는 내구도가 크게 깎인 상태로 드랍된다.

[5-4] 세트 효과
  · 같은 계열 장비를 3부위 이상 착용하면 특수 효과가 발동한다.
  · 세트 효과는 옵션 수치가 아니라 【규칙(면역·무효화)】으로 준다.
    수치로 주면 그냥 강한 장비가 되어 선택이 사라진다.
  · 주 용도는 레이드 특성 대응이다.
      예) 내화 계열 3부위 → 「내화 피부」 레이드의 화염 봉인을 완화
          잔류물 차폐 계열 3부위 → 적이 남긴 잔류물 피해 무효

[5-5] 사망·추출 실패 시
  · 착용 장비와 가방 내용물을 전부 잃는다.
  · 도감과 적재 슬롯 수는 유지된다.
  · ※ Duckov의 난이도별 회수 규칙(시체 가방 재입장)은 도입하지 않는다.
       모바일 세션이 짧아 "재입장해서 회수"가 성립하지 않는다.
  · 이것이 Skill 시스템과의 역할 분담이다.
      장비 = 리스크    도감 = 안전장치

[5-6] 획득 경로
  · 적 드랍 / 맵 루팅 / 벙커 상점 / 제작(청사진) / 암시장
  · 티어 5~6은 제작 또는 드랍에만 의존한다. 상시 구매를 열지 않는다.
  · 드랍 등급은 사냥 시스템의 몬스터 등급과 속성 수에 연동된다.

[5-7] Skill과의 경계 — 절대 규칙
  · 장비 옵션은 투사체 행동(관통·연쇄·갈래 등)을 주지 않는다.
  · 장비 옵션은 상태이상(점화·동결 등)을 부여하지 않는다.
  · 장비 옵션은 처치 시 연쇄 같은 전투 메커니즘을 주지 않는다. (전령은 Skill이다)
  · SkillDefinition에는 상시 능력치 필드를 두지 않는다.
  · 이 경계는 `SkillDefinition`과 `EquipmentDefinition`의 필드 구성으로
    타입 수준에서 강제한다.

    한 줄 요약 —  Skill은 메커니즘을 바꾸고, 장비는 능력치를 준다.

6. 명명 규칙
--------------------------------------------------------------------------------
Duckov의 아이템 이름을 쓰지 않는다. Blob 세계관으로 새로 짓는다.

  세계관 : 점액질 생물이 외부 물질을 몸에 두르거나 흡수해 굳힌 것
  어휘   : 각질 / 결정 / 피막 / 섬유 / 갑각 / 포자낭 / 신경삭 / 공생체

  티어를 이름에 노출하지 않는다. (Duckov는 "3레벨 방탄복"처럼 노출하지만,
  모바일 UI에서는 아이콘과 색으로 구분하는 편이 낫다)

  예시 (초안, 확정 아님)
    머리 : 굳은 각질 / 석회 피막 / 결정 외피
    몸통 : 섬유 외피 / 겹친 갑각 / 응결 갑주
    얼굴 : 홑눈 / 겹눈 / 열감지 소포
    청각 : 진동모 / 공명낭
    가방 : 저장낭 / 확장낭 / 심층낭
    토템 : 공생체 · 기생체 계열

7. 데이터화
--------------------------------------------------------------------------------
- 장비는 ScriptableObject로 정의한다.
  위치: Assets/Data/ScriptableObjects/Equipment/<슬롯>/
- 옵션은 (EquipmentStatType, float) 쌍의 리스트로 둔다.
  enum + 값 구조여야 합산·표시·세이브가 전부 단순해진다.
- 옵션 합산은 MonoBehaviour 의존 없는 순수 클래스로 분리한다.
  (EquipmentModifiers — WeaponModifiers와 같은 원칙. EditMode 테스트 대상)
- 무게 계산, 과중량 판정, 세트 효과 판정도 전부 순수 로직으로 분리한다.
- EquipmentCatalogBuilder가 폴더를 스캔해
  Resources/EquipmentCatalog.asset을 자동 갱신한다.

[클래스 구성 (예정)]
  Assets/Scripts/Core/Equipment/
    EquipmentSlot.cs          슬롯 enum 6종
    EquipmentStatType.cs      옵션 enum
    EquipmentDefinition.cs    정의 SO
    EquipmentInstance.cs      개체 (내구도 현재값을 가진다)
    EquipmentLoadout.cs       6슬롯 착용 상태. 순수 클래스
    EquipmentModifiers.cs     옵션 합산 결과. 순수 클래스
    WeightCalculator.cs       무게 합산 · 과중량 단계 판정. 순수 클래스
    SetBonusResolver.cs       세트 효과 판정. 순수 클래스
    EquipmentCatalog.cs       카탈로그 SO
