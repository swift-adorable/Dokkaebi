# Map System — 지도 · 미니맵 · 마커

상태: **구역 맵 — 0장 그레이박스 구현 (결정 2-86).** 지도 · 미니맵 · 마커는 아직 설계 전 — 아래 2절은 「무엇을 정해야 하는가」의 목록이다.

> **구역 맵 (결정 2-86)** — 장 하나 = 씬 하나(「Chapter0」…) · 구역은 그 안의 땅. 표 `Core/Map/ZoneMapTable.cs` → 메뉴 「Dokkaebi/Map/장 맵 굽기 (전부)」 → 씬. 런타임 `Map/ZoneMap.cs` — 출발 자리 · 금줄 · 자리 묻기. 0장: 서쪽 헛간 ~ 고목 = 0-1(대숲 · 언덕 · 냇물 · 방앗간), 고목 너머 = 0-2(수풀).
로드맵: 9단계 (구역 맵과 함께 — 장 하나 = 맵 하나, 결정 2-47)

---

## 0. 왜 지금 문서만 만드는가

사이드 메뉴에 덕코프의 **「마커」** 줄을 넣지 못했다.
그 버튼이 무엇을 하는지 어느 위키에도 적혀 있지 않고(아래 2절),
Dokkaebi에는 아직 구역 맵이 없어 표시할 것이 없기 때문이다.

지도가 생기면 그 줄이 돌아온다. 그때 「마커가 뭐였더라」로 시작하지 않도록
지금 알아낸 것과 정해야 할 것을 적어 둔다.

**거의 없다.** `research/duckov/raw/*.jsonl` 약 210만 자에서
「지도 · 미니맵 · 나침반 · 마커」를 훑었다.

| 낱말 | 나온 맥락 | 판정 |
|---|---|---|
| 마커 | **상점에서 파는 아이템**(매직펜, 제작 재료). 3회 | [확인 불가] UI 버튼 설명 없음 |
| 나침반 | 전리품 목록의 **아이템**. 2회 | [확인 불가] 기능 설명 없음 |
| 지도 | 위키 내비게이션의 메뉴 이름 | — |
| 미니맵 | **0회** | [확인 불가] |

웹에서 한 번 더 확인했다 (2026-09-22, duckescapefromduckov.com/guides/game-mechanics).

- [확인됨] **철수 지점은 초록 연기 또는 특수 출구로 표시된다.**
- [확인됨] 「그라운드 제로」 구역에 전체 지도 화면이 있고, 텔레포트 거품의
  시작·끝 지점이 그 위에 표시된다.
- [확인 불가] 레이드 중 미니맵 유무 · 전장의 안개 · 플레이어가 찍는 마커 ·
  지도를 보려면 아이템이 필요한지 · 전체 지도를 여는 방법

**즉 「마커」 버튼의 정체는 자료로는 알 수 없다.** 추정은 적지 않는다.

## 2. 정해야 할 것

| # | 질문 | 왜 중요한가 |
|---|---|---|
| 1 | 미니맵을 **늘 띄울 것인가** | 모바일 화면에서 늘 띄우면 전투 화면이 그만큼 줄어든다. 「정보 은폐」 방침(Master_Prompt 6절)과도 걸린다 |
| 2 | 전체 지도를 **아이템 없이** 볼 수 있는가 | 지도를 아이템으로 만들면 가방 한 칸을 먹는다 — 칸 설계와 직접 엮인다. 지도는 장부방[가칭]이 관리한다(결정 2-52) — 그 기능과 함께 정한다 |
| 3 | **전장의 안개**를 둘 것인가 | 두면 탐색이 보상이 되고, 안 두면 첫 판부터 최단 경로로 달린다 |
| 4 | 철수 지점을 **처음부터** 보여 줄 것인가 | 덕코프는 초록 연기로 현장에서 보여 준다 [확인됨]. 지도에도 찍을지는 별개. **→ 현장에서는 처음부터 보인다 (결정 2-78 · 임시: 2곳 · 25~35m · 초록 기둥 + 화면 화살표 · 원 안 5초 버티기).** 지도에 찍을지는 지도가 생길 때 |
| 5 | **마커** — 플레이어가 찍는 것인가, 아이템을 찍는 것인가 | 사이드 메뉴의 「마커」 줄이 여기 달려 있다. 퀘스트 목표는 구역 단위 하이라이트까지만 — 핀포인트 마커는 두지 않는다 (Progression 4절) |
| 6 | 마커의 **개수 제한**과 지속 | 무제한이면 지도가 낙서장이 된다 |
| 7 | 소리·감지와의 연결 | 「소리 방향 표시 UI」가 이미 보류 목록에 있다 (Decisions 4-7) |

## 4. 절대 금지 사항 (미리 못 박아 둔다)

1. **지도가 적 위치를 알려 주지 않는다.** 그것은 감지 시스템(7-D)의 몫이고,
   지도에 점으로 찍으면 시야각·소리 설계가 통째로 무의미해진다.
2. **미니맵이 화면의 주인이 되지 않는다.** 이 게임은 화면을 보고 피하는
   게임이지 지도를 보고 이동하는 게임이 아니다.
3. **마커를 전투 이점으로 만들지 않는다.** 찍어 두면 피해가 오르는 식의
   보정을 붙이지 않는다. 마커는 기억을 대신할 뿐이다.
