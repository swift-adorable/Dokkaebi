## 0. 이름 원칙

1. **시스템 용어는 덕코프를 따른다** — 체력 · 방어도 · 중첩 · 파밍 · 철수 · 레벨 · 골드
2. **아이템 · 장소 이름은 테마를 따른다** — 출처 순서: 실제 기록 → 설화 → 조어
3. **이름이 기능을 거짓말하지 않는다**
4. 코드 식별자(영어)는 바꾸지 않는다 — 화면 글자만 바뀐다
5. **오방 색 체계** — 빨강 화염 · 검정 냉기 · 파랑 전기 · 흰색 물리 · 노랑 독. 탈 · 사신수 · 장이 같은 색을 쓴다

## 6. 이야기 · 게임 화면 표기

기획 문서의 시스템 용어는 그대로 두고, **이야기와 게임 화면에서만** 아래처럼 부른다.

| 기획 문서 | 이야기 · 게임 화면 |
|---|---|
| 스킬 젬 | **구슬** (싣는 구슬 · 모였다 터지는 구슬 · 번지는 구슬). 삼키지 않고 몸에 지니며 바꿔 지닐 수 있다 |
| 경험치 · 레벨 | 정기 |
| 각인 | 새김패 (할머니의 오색 매듭 가장 굵은 두 곳에 묶는다) |
