1. 모든 용어는 **poe2db 한글판의 실존 젬명**을 그대로 쓴다. [확인됨 — poe2db.tw/kr]

## 1. 왜 전달 계열을 Support로 내렸는가

v5는 관통·분열·추적·튕겨 쏘기를 **핵심 스킬(Core)** 로 두었다. 이것이 구조적 오류였다.

**PoE2에서 투사체 행동은 전부 보조 젬이다.** [확인됨 — poe2db.tw/kr/Support_Gems]

```
스킬 젬  = 무엇을 쏘는가   → 화염구 / 얼음 화살 / 번개 창 / 원소 작렬
보조 젬  = 어떻게 날아가는가 → 관통 / 연쇄 / 튕겨 쏘기 / 추격 / 다중 사격 / 투사체 가속
```

전달 계열을 Core에 두었기 때문에 Core 「관통」과 Support 「고밀도 탄심」이 **같은 일을 하는 두 개**가 되어 있었다. 이름을 바꿔도 중복은 남는다. 배치를 고쳐야 사라진다.

### 재배치가 동시에 해결한 것

| 문제 | 해결 |
|---|---|
| Core 「관통」 ↔ Support 「고밀도 탄심」 중복 | 관통이 Support 하나로 통합 |
| 부여 Core에 `투사체` 태그가 없어 투사체 Support가 붙을 곳이 없음 | 부여 Core에 `투사체` 부여. 항상 붙을 곳이 있다 |
| Core 12 : Support 28 비율 | **8 : 32**. "Core보다 Support를 훨씬 많이"에 근접 |

> PoE2의 실제 비율은 스킬 젬 427 : 보조 젬 557이다. 변형 수단이 본체보다 130개 많다.

## 2. 도감(Codex) / 적재(Loadout)

### 2-1. 구조

```
도감 (영구, 최대 60)
   ↓ 벙커에서 선택
적재 (레이드 1회, 초기 8칸 → 최대 14칸)
   ↓ 레이드 중 레벨업
선택지 3장 (적재한 것 중에서만 등장)
   ↓
실제 작동
```

| 항목 | 값 |
|---|---|
| 적재 슬롯 초기 | 8 |
| 적재 슬롯 최대 | 14 (추출 성공 누적으로 확장) |
| 필수 조건 | **부여 계열 Core 최소 1개** (v6 강화) |

> **필수 조건을 강화한 이유**: v5는 "Core 최소 1개"였다. 기폭 계열 Core만 적재하면 `투사체` 태그를 가진 Core가 없어져 투사체 Support 9종이 통째로 죽는다.

> **14를 상한으로 둔 근거**: 한 런에서 실제 작동 가능한 최대치가 Core 2 + Support 6(소켓 3×2) + 기원 Meta 1 + Persistent 4~5(Nucleus 100 한도)다.

### 2-2. 도감 해금

```
레이드 중 변이체(Mutant) 처치
  → 「변이 샘플」 드랍 → 흡수
  → 추출 성공 : 도감에 영구 등록
     추출 실패 : 샘플 소실 (기존 도감은 유지)
```

미해금 샘플을 들고 있을 때 "지금 나갈까, 더 돌까"라는 추출 게임 고유의 긴장이 발생한다. 반면 이미 등록된 스킬은 사망해도 잃지 않으므로 이탈 방지 안전장치로도 기능한다. Duckov의 개(dog) 슬롯과 같은 역할이다.

> **용어 주의**: 「변이체」는 적 유형, 「변이 샘플」은 드랍물이다. 스킬이 아니므로 Skill로 개명하지 않는다.

## 4. 태그 — 14

poe2db 한글판 실제 태그 표기를 그대로 쓴다. [확인됨]

| 태그 | 의미 |
|---|---|

| `효과 범위` | 범위 피해를 준다 |
| `잔류물` | 바닥에 장판을 남긴다 |
| `기폭 장치` | 다른 것을 터뜨릴 수 있다 |
| `지속시간` | 시간 개념이 있다 |
| `유지형` | Nucleus를 점유한다 |

| `조건부` | 발동 조건이 있다 |
| `청산` | 상태이상을 소모한다 |

**v5에서 바뀐 표기**

| v5 | v6 | 근거 |
|---|---|---|
| 효과범위 | **효과 범위** | poe2db 띄어쓰기 |
| 기폭장치 | **기폭 장치** | poe2db 띄어쓰기 |
| 지대 | **잔류물** | poe2db에 "지대" 태그는 없다. 「잔류물 효력」 「마나 잔류물」이 실존 |

### 태그 게이팅

```
Support의 요구 태그를 Core가 전부 포함하면 → 장착 가능
하나라도 없으면 → 장착 불가. 선택창에도 등장하지 않음
```

이 규칙 하나로 죽은 선택지가 사라지고, 개별 조합 규칙을 정의할 필요가 없어진다.

## 6. 핵심 스킬 (Core) — 8

소켓 **3개** 보유. 동시 보유 상한 **2개**. 2번째 슬롯은 **Lv7**에 열린다.

```
부여 계열  →  기폭 계열
(무엇을 남기는가)  (무엇을 소모하는가)
```

> **「전달 계열」은 없어졌다.** "어떻게 닿는가"는 이제 소켓의 Support가 담당한다. (1절 참조)

### 6-1. 부여 계열 — 5

적에게 **상태를 남기는 것이 본체**다. 피해는 부수 효과다.

| 이름 | Lv | 태그 | 작동 | 생성 |
|---|---|---|---|---|
| **화염** | 1 | `투사체` `화염` `지속시간` | 적중한 적을 점화시킨다. 점화된 적이 사망하면 화염 잔류물이 남는다 | 점화 |
| **역병** | 1 | `투사체` `카오스` `지속시간` | 적중마다 중독을 중첩시킨다. 10중첩에서 `위독`이 되어 중독 피해가 2배 | 중독 |
| **서리** | 3 | `투사체` `냉기` | 냉기를 누적시켜 임계치 초과 시 동결시킨다. 피해는 낮지만 행동을 봉쇄한다 | 동결 |
| **뇌전** | 5 | `투사체` `번개` | 적을 감전시켜 **받는 모든 피해를 20% 증폭**시킨다. 단독 피해는 가장 낮다 | 감전 |
| **열상** | 7 | `투사체` `물리` `지속시간` | 출혈을 유발한다. **이동 중인 적에게 피해가 배증**되므로 추격형 적에게 강하다 | 출혈 |

> **전부 `투사체` 태그를 가진다.** Blob의 기본 동사가 사격이기 때문이며, 이 덕분에 투사체 Support 9종이 붙을 곳이 항상 존재한다. v5의 태그 게이팅 공백이 여기서 해소된다.

> **속성별 역할 분화**: 뇌전은 단독으로 약하지만 다른 모든 피해를 증폭시키고, 서리는 피해가 거의 없지만 생존을 책임지며, 열상은 적의 행동 패턴에 의존한다. "무조건 화염"을 막기 위한 의도적 설계다.

### 6-2. 기폭 계열 — 3

| 이름 | Lv | 태그 | 작동 |
|---|---|---|---|
| **원소 작렬** | 1 | `효과 범위` `기폭 장치` `청산` | 상태이상이 걸린 적이 사망하거나 최대 중첩에 도달하면 **그 상태를 소모해 해당 속성의 폭발**을 일으킨다 |
| **중력 붕괴** | 7 | `효과 범위` `잔류물` `지속시간` | 중력 우물을 만들어 적을 한 점으로 끌어모으고 `응집`을 부여한다 |
| **충격파** | 9 | `효과 범위` `기폭 장치` | 플레이어 중심으로 주기적 충격파를 방출해 적을 밀어내고, 범위 내 잔류물과 지연 기폭 대상을 즉시 터뜨린다 |

> **`투사체` 태그가 없다.** 투사체가 아니라 파동·잔류물·플레이어 중심 효과이기 때문이다. 따라서 투사체 Support는 기폭 Core에 붙지 않는다.

#### 원소 작렬의 상태별 결과

| 소모 상태 | 결과 |
|---|---|
| 점화 | 화염 폭발 + 화염 잔류물 |
| 중독 | 독 구름 확산 (주변 적에게 중독 전이) |
| 동결 | 파편 폭발 (주변 적 즉시 동결) |
| 감전 | 낙뢰 3회 |
| 출혈 | 혈액 분출 (주변 적 출혈) |

> **명칭 근거**: poe2db 스킬 젬 「원소 작렬」은 주변 적·동료·시신에 걸린 동결·감전·점화를 소모하는 파동을 내보내며, 파동 자체는 피해가 없고 소모된 상태 이상이 해당 원소 유형의 폭발을 일으킨다. 기능이 정확히 일치한다. [확인됨]

> **충격파의 근거**: `EnemyAttack`은 사거리 1.6m 진입 → 예비동작 0.35초 → **판정 시점에 사거리를 재확인**한다. 밀어내기는 판정 실패를 유도하는 **능동 방어 수단**이며, 텔레그래프 구조 자체와 맞물린다.

## 7. 보조 스킬 (Support) — 32

반드시 **Core 소켓**에 장착된다. 전역 버프가 아니다.

### 7-1. 통화(Cost) — 7종

**직접 피해 수치 감소는 사용하지 않는다.** 체력 10 / 짧은 TTK 환경에서 유저는 DPS 변화를 인지하지 못한다.

| 통화 | 내용 |
|---|---|
| **탄막 밀도** | 발사 간격 증가, 탄 수 감소 — 작은 화면에서 즉시 체감 |
| **유효 사거리** | 사거리·범위 축소 → 접근 강요 → 위험 증가 |
| **조작 제약** | 행동 자체를 제약 (이동 중에만, 연사 시 과열 등) |
| **기능 배타** | "X를 이용하는 대신 X를 생성할 수 없다" |
| **투사체 속도** | 탄속 증감. poe2db 「투사체 가속」「투사체 감속」이 각각 독립 젬으로 실존 [확인됨] |
| **지속시간** | 상태이상·잔류물의 지속시간 증감. poe2db 「지속시간 연장」「지속시간 압축」 실존 [확인됨] |
| **즉시성** | 발동이 지연되거나 즉발이 지속으로 전환된다. poe2db 「긴 퓨즈」「느린 효력」이 이 유형 [확인됨] |

> **v5의 4종을 7종으로 늘린 이유**: 4종으로 분류 가능한 Support가 28종 중 13종뿐이었다. 나머지 15종의 대가(탄속·지속시간·즉시성)가 타입 밖에 있어 `CostType`이 실제 데이터를 설명하지 못했다. PoE2도 대가의 종류를 제한하지 않는다. 제한해야 할 것은 종류가 아니라 **유저가 체감하지 못하는 대가**뿐이다.

> **`CostType` enum에 `Damage` 항목은 계속 두지 않는다.** 금지 대상은 【직접 피해 수치 감소】(예: 피해 -20%)에 한정한다. 지속시간 감소는 총 피해량을 줄이지만 유저가 "짧아졌다"로 체감하므로 별도 통화로 인정한다.

### 7-2. `투사체` 계열 — 9

요구 태그: `투사체`

## 8. 발동 스킬 (Meta) — 7

| **최후의 막** | 9 | 40 | 치명상을 입는 순간 1.5초간 무적이 된다 |

> **「감각 확장」의 점유를 10 → 30으로 올렸다.** 마스터 프롬프트 3절은 Duckov의 시야 통제(vision cone)를 핵심 긴장 장치로 삼는다. 최저가 유지형이 그것을 해제해 버리면 설계가 무너진다. Duckov의 시야 콘은 반사신경이 아니라 **포지셔닝을 강제하는 장치**이므로 싸게 풀면 안 된다. 요구 레벨도 1 → 5로 올렸다.

> **탐험 구조에서 「기동」의 가치가 높다.** 넓은 맵에서 적이 분산되어 있으므로 빠르게 이동하는 것이 곧 효율이다.

> **「변이 추적」은 도감 시스템의 핵심 유틸이다.** 변이체 드랍이 곧 도감 해금이므로, 이것을 적재하는 것은 "이번 레이드는 화력보다 수집을 우선한다"는 선언이 된다.

### 9-2. 전령(Herald) — 5

전부 **"처치 시 연쇄"** 구조다. poe2db에 전부 실존한다. [확인됨]

| 이름 | Lv | 점유 | 조건 | 결과 |
|---|---|---|---|---|
| **재의 전령** | 11 | 45 | 점화된 적 처치 | 점화 폭발 + 주변 점화 |
| **얼음의 전령** | 11 | 45 | 동결된 적 처치 | 얼음 폭발 + 주변 동결 |
| **천둥의 전령** | 11 | 45 | 감전된 적 처치 | 주변 전체에 번개 방출 |
| **역병의 전령** | 11 | 45 | 중독된 적 처치 | 중독이 주변으로 확산 |
| **피의 전령** | 11 | 45 | 출혈 적 처치 | 축적 출혈량 비례 혈액 폭발 |

> **전령은 "조건부 강함"이다.** 적이 분산된 구조에서는 처치 연쇄가 항상 강하지 않다. **「밀집 서식」 레이드에서만 최대 가치**를 낸다. 유저는 레이드 특성을 보고 전령을 넣을지 뺄지 판단하게 된다.

### 9-3. Nucleus 경제

| 구성 예 | 점유 | 판정 |
|---|---|---|
| 전령 2개 | 90 | 남은 10으로는 아무것도 못 든다 |
| 전령 1 + 최후의 막 + 인력장 | 100 | 정확히 한도 |
| 전령 1 + 최후의 막 + 기동 | 105 | **초과 — 불가능** |
| 유틸 올인 (인력장·기동·활력·경화 피막·감각 확장) | 120 | **초과 — 불가능** |

**"전령 하나를 넣으면 생존 유틸을 거의 못 든다"**가 성립한다. 체력 10 / 짧은 TTK 환경에서 이는 실질적 선택이다.

### 9-4. 유지형 자유 해제 (v6 신설)

**유지형은 Nucleus 한도 내에서 언제든 켜고 끌 수 있다. 비용은 없다.**

> **필요했던 이유**: 전령은 Lv11·Nucleus 45다. 그 전에 저레벨 유틸(인력장 15 / 기동 20)을 획득하면 Nucleus가 소진되어, 적재해 둔 전령이 **선택창에 뜨지도 못한다.** 전령이 사실상 선택 불가가 되는 구조였다.
>
> **PoE2의 Spirit 스킬은 언제든 해제·재장착이 자유롭다.** [확인됨] 같은 규칙을 적용하면 이 문제가 해소되고, 선택 Skip 규칙을 따로 둘 필요도 없어진다.
>
> **소켓(Support)은 여전히 되돌릴 수 없다.** 자유로운 것은 유지형뿐이다.

## 10. 충돌 우선순위 큐

```
Split → Pierce → Fork → Chain → Return
```

**한 번의 충돌에는 단 하나만 해결된다.**

### 10-1. 현재 각 단계의 담당

| 단계 | 담당 | 비고 |
|---|---|---|
| Split | **담당 없음** | poe2db에 대응 젬 없음 |
| **Pierce** | **관통** (Support) | 기본 3체 |
| Fork | **담당 없음** | poe2db에 대응 젬 없음 |
| **Chain** | **연쇄** (Support) | 기본 3회, 동일 적 재타격 불가 |
| Return | **담당 없음** | 「회귀」 삭제됨 |

> **5단계 구조 자체는 유지한다.** PoE2 엔진에 실재하는 판정 순서이며 [확인됨], 향후 고유 장비 등으로 담당을 채울 수 있다. `ProjectileBehaviourState`는 5단계를 모두 갖되 데이터에서 2개만 채운다.

### 10-2. 큐에 들어가지 않는 것

| 스킬 | 사유 |
|---|---|
| **튕겨 쏘기** | 지형 충돌에서 발동. 적 충돌 큐를 소모하지 않는다 |
| **다중 사격** | **발사 시점**에 탄이 늘어난다. 충돌과 무관하다 |
| **추격** | 지속 유도(호밍). 충돌 시 재유도가 아니다 |

> 이 3종을 큐에 넣으면 관통과 서로를 막게 되어 설계 의도가 깨진다.

### 10-3. 배타가 자동 발생하는 구조

관통과 연쇄를 둘 다 보유하면 한 충돌에서 관통만 해결되고 연쇄는 발동하지 않는다. **곱연산이 일어나지 않는다.** 수치 인플레 없이 선택의 무게가 생긴다.

## 11. 합성 발사 (Composite Fire)

Core를 2개 보유해도 따로 발사하지 않는다. **한 발에 합쳐진다.**

```
부여 계열 Core → 그 탄이 부여할 상태를 제공 (점화 / 중독 / 동결 / 감전 / 출혈)
소켓의 Support → 그 탄의 투사체 행동을 제공 (관통 / 연쇄 / 튕겨 쏘기 / 추격 …)
기폭 계열 Core → 투사체가 아니므로 합성 대상이 아니다. 독립 발동한다.

예: 화염 Core + 소켓의 관통 = "관통하면서 점화시키는 탄 1발"
```

### 11-1. 채택 근거

| 방식 | 탄 수 | 문제 |
|---|---|---|
| 동시 발사 | **2배** | 모바일에서 발열·드로우콜 부담이 가장 크다 |
| 교대 발사 | 1배 | 상태 부여 빈도가 절반 → 부여 Core의 체감이 무너진다 |
| 주·보조 전환 | 1배 | 전환 조작 버튼이 하나 더 필요하다 |
| **합성** | **1배** | — |

### 11-2. 확정 규칙

1. **Core 개수는 탄 수에 영향을 주지 않는다.** 탄이 늘어나는 것은 「다중 사격」뿐이다.
2. **부여 Core가 2개면 발사마다 번갈아 부여한다.** 매 발사 동시 부여로 만들면 「원소 융합」(대가: 적용 빈도 절반)이 무가치해진다. 번갈아 부여하면 각 상태가 정확히 50% 빈도가 되어, 「원소 융합」과 같은 수준이 된다.
   - Core 2개 방식은 **Core 슬롯**을 쓴다 (대신 소켓 3개가 딸려온다)
   - 원소 융합 방식은 **소켓 1칸**을 쓴다 (대신 Core 슬롯을 지킬 수 있다)
3. **기능 배타로 차단된 상태(번제 → 점화)는 탄에 실리지 않는다.**
4. **태그 게이팅은 Core 단위를 유지한다.** 두 Core의 태그를 합집합으로 보지 않는다.

### 11-3. 2번째 Core 슬롯

**Lv7에 열린다.** 10절의 "Core 보유 상한 2개"는 상한이지 즉시 지급 보장이 아니다.

초반에는 메커니즘 하나만 익히게 하고, 단일 Core 빌드를 충분히 완성한 뒤 확장하도록 중반에 연다. 상한 2개는 그대로이므로 규칙 위반이 아니다.

## 12. 규칙 정리

### 12-1. 레이드 밖 (벙커)

| 항목 | 규칙 |
|---|---|
| 도감 등록 | 변이체 처치 → 변이 샘플 → **추출 성공 시 영구 등록** |
| 도감 소실 | 없음. 등록된 스킬은 사망해도 유지된다 |
| 적재 슬롯 | 초기 8, 최대 14 (추출 성공 누적으로 확장) |
| 적재 제약 | **부여 계열 Core 최소 1개** |
| 레이드 특성 | 진입 전 공개. 레이드당 1~2개 |

### 12-2. 레이드 안

| 항목 | 규칙 |
|---|---|
| 선택지 개수 | 3장 (적재한 것 중에서만) |
| 일시정지 | O. 제한시간 없음 |
| Core 보유 상한 | 2개 (2번째는 Lv7 개방) |
| Core당 소켓 | 3개 (최대 6 Support) |
| 소켓 장착 위치 | 획득 시점에 유저가 지정. **되돌릴 수 없다** |
| 기원형 동시 장착 | 1개 |
| 중복 등장 | 없음 (획득한 것은 해당 런의 풀에서 제거) |
| **Reroll** | **도입하지 않는다** |
| **소켓 탈착** | **도입하지 않는다** |
| Nucleus 기본 | 100 |
| 유지형 켜고 끄기 | 자유. 한도 내에서 언제든 (비용 없음) |
| 런 종료 시 | 획득한 스킬 전부 초기화 |

> **Banish와 Reroll을 둘 다 도입하지 않는 이유**: 적재 8장은 **유저가 벙커에서 직접 고른 8장**이다. 구조상 "뽑기 싫은 카드"가 존재할 수 없으므로 다시 뽑거나 빼는 행위에 의미가 없다. 8장짜리 풀에서 카드를 또 빼면 선택지가 고갈된다.

> **Reroll 폐지의 부수 효과**: Biomass의 소모 통화 용례가 사라져 **Biomass = 흡수 자원(XP)** 이라는 단일 의미만 남는다. v5는 Biomass를 흡수 자원(5곳)과 소모 통화(2곳)로 동시에 써서 모순이 있었다.

> **선택 제한시간을 없앤 이유**: 탐험 구조에서는 레벨업 횟수 자체가 적어 각 선택의 무게가 크다. 일시정지만 유지한다.

### 12-3. 영구 성장 3축

1. **도감** — 해금한 스킬 목록
2. **적재 슬롯** — 8 → 14
3. **Nucleus 상한** — 100에서 추출 성공 누적으로 증가

한 레이드에 **1~2개**가 부여되며 진입 전에 공개된다.

| 특성 | 내용 | 유리 | 불리 |
|---|---|---|---|

| **산개 순찰** | 적이 넓게 흩어져 개별 조우 | 단일 화력 · 기동 · 관통 | 전이 · 연쇄 |
| **경화 외피** | 적 방어도가 높음 | 관통 · 즉발 화력 | 지속 피해 |
| **재생 조직** | 적이 체력을 회복함 | 즉발 화력 | 점화 · 중독 |
| **내화 피부** | 화염 저항 높음 | — | **화염 봉인** |
| **저온 적응** | 냉기 저항 높음 | — | **서리 봉인** |
| **절연 피막** | 번개 저항 높음 | — | **뇌전 봉인** |
| **면역 항체** | 카오스 저항 높음 | — | **역병 봉인** |
| **응고 혈액** | 출혈 지속시간 절반 | — | **열상 봉인** |
| **부식 대기** | Biomass 흡수량 감소 (레벨업 지연) | 저레벨 완성형 빌드 | 후반 스케일 빌드 |

> **봉인 특성을 3종 → 5종으로 늘렸다.** v5는 냉기·번개·물리만 봉인해서 **화염과 카오스가 어떤 레이드에서도 봉인되지 않았다.** "가장 강한 속성 하나로 모든 레이드를 도는 것을 막는다"가 목적인데, 화염이 정확히 그 하나가 되는 구조였다. 이제 5속성 전부가 봉인 대상이다.

> **「밀집 서식」과 「산개 순찰」은 동시에 부여되지 않는다.** 서로 모순되는 배치 규칙이다. (구현 시 배타 규칙 필요)

## 14. 조합 예시

**① 「밀집 서식」 — 전이 특화**
- 적재: 화염 / 원소 작렬 / 불난 집 부채질 / 폭발 투사체 / 연쇄 / 재의 전령 / 인력장 / 기세
- 작동: 폭발 투사체가 적중 지점에서 점화를 퍼뜨리고, 불난 집 부채질이 다시 주변으로 전파한다
- 트리거: 점화된 적이 사망하는 시점
- 결과: 재의 전령이 점화 폭발을 일으켜 주변을 다시 점화시키고, 원소 작렬이 남은 점화를 소모해 화염 잔류물을 깐다 → **무리 하나가 통째로 연쇄 소멸**

**② 「산개 순찰」 — 단일 화력 특화**
- 적재: 열상 / 유혈 충동 / 깊은 상처 / 관통 / 원거리 사격 / 혈액의 기원 / 기동 / 감각 확장
- 작동: 관통탄이 일렬로 출혈을 걸고, 원거리 사격이 먼 거리에서의 화력을 보장한다. 유혈 충동은 출혈을 만들지 못하므로 열상이 필수다
- 트리거: 유저가 게이지를 확인하고 **직접 기원 버튼을 누르는 시점**
- 결과: 저장된 출혈량에 비례한 전방 관통 분출 → **개별 조우를 빠르게 정리하고, 강적에게 저장분을 터뜨림**

**③ 「경화 외피」 — 관통 · 증폭 특화**
- 적재: 뇌전 / 감전 도약 / 관통 / 넘치는 충전 / 감전 시 시전 / 천둥의 전령 / 기동
- 작동: 관통탄이 일렬로 감전을 걸어 **받는 피해를 35%까지 증폭**시키고, 감전 도약이 인접으로 퍼뜨린다
- 트리거: 감전 유발 누적으로 「감전 시 시전」 에너지가 100% 도달
- 결과: 화면 내 감전된 모든 적에게 낙뢰 → **방어도가 높아 지속 피해가 통하지 않는 적을 증폭 + 즉발로 공략**

**④ 「저온 적응」 — 속성 조율 공략**
- 적재: 서리 / 화염 조율 / 원소 작렬 / 긴 퓨즈 / 관통 / 지속시간 연장 / 최후의 막
- 작동: 완성된 서리 빌드를 그대로 가져가되, 화염 조율로 냉기를 화염으로 전환한다. 냉기 전용 Support는 무효화되지만 나머지는 살아남는다
- 트리거: 화염 조율 획득 시점
- 결과: 동결 기반 빌드가 점화 기반으로 전환되고, 긴 퓨즈가 누적 점화를 한 번에 소모한다 → **봉인된 속성을 우회**

**⑤ 「재생 조직」 — 즉발 화력 특화**
- 적재: 서리 / 얼어붙은 악의 / 살을 에는 서리 / 원소 작렬 / 짧은 퓨즈 / 지속시간 압축 / 충격파
- 작동: 지속 피해가 재생에 상쇄되므로 동결로 행동을 봉쇄하고 즉발로 처리한다. 살을 에는 서리가 동결을 소모하고, 얼어붙은 악의가 다시 공급한다
- 트리거: 냉기 누적이 임계치를 넘겨 적이 동결되는 시점
- 결과: 공급과 소비가 경쟁하며, 남은 동결은 원소 작렬이 짧은 퓨즈로 즉시 파편 폭발시킨다 → **재생할 틈을 주지 않는 즉발 루프**

## 16. 절대 금지 사항

1. **단순 스탯 증가만 주는 스킬을 만들지 않는다.**
   - 적용 범위는 **핵심(Core)과 보조(Support)** 에 한정한다. 유지형(Persistent)은 전투 메커니즘이 아니라 유틸이므로 수치형을 허용한다.
   - PoE2도 Spirit 젬(전령·오라)은 수치 버프가 대부분이고, 메커니즘 변형은 스킬 젬/보조 젬이 담당한다. [확인됨]
2. **다양성을 "중복 획득 금지"로 강제하지 않는다.** (PoE2가 0.3 패치에서 폐기한 설계)
3. **확률 발동 트리거를 쓰지 않는다.** 에너지 축적형을 쓴다.
4. **대가로 직접 피해 수치 감소를 쓰지 않는다.** (예: 피해 -20%)
   - 지속시간 감소는 유저가 "짧아졌다"로 체감하므로 별도 통화로 인정한다.
5. **티어(I/II/III) 체계를 도입하지 않는다.** 모든 스킬은 단일 정의다.
   - PoE2는 티어를 쓰지만 모바일에서 동일 이름의 등급 구분은 인지 부담만 늘린다.
6. **소환수 계열(드론/포탑/포자 등 독립 개체)을 도입하지 않는다.**
7. **정지(stationary)를 보상하는 스킬을 만들지 않는다.** 핵심 방어 동사인 대시 회피와 정면 충돌한다.
