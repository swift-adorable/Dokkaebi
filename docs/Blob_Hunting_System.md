# Hunting System

> **담당** — 상대를 정의한다 · 무엇을 상대하는가
> 수치는 [`Combat_Baseline.md`](Blob_Combat_Baseline.md) 5절. 이 문서는 **누가 갖는가**만 정한다.

```
원형 → 등급 → 속성 → 진영 → 시설 상태 → 드랍 → 배치
```

## 1. 적 원형 9종

**원형은 고정 수치를 갖고, 장은 구성비만 정한다.** 장이 올라간다고 체력에 배율을 곱하지 않는다.

> 근거 — 덕코프는 상위 구역에서 "넝마꾼의 체력"이 아니라
> "용병이 철갑탄을 들기 시작한다"가 바뀐다. [확인됨]

| 원형 | 장 | 정체 | 핵심 기믹 |
|---|---|---|---|
| **스캐브** | 1~2 | 자아 없는 야생 슬라임 | 근접 돌진. 예비동작 → 대시 회피 |
| **압착기** | 1 | 폐기물 처리 로봇 | 느리고 단단. **전기 ×2 / 카오스 면역** |
| **자전체** | 2 | 전기를 머금은 슬라임 | 기본 원거리. 감전 부여 |
| **잠복체** | 2 | 수중 매복형 | 기습. **발소리가 없다** |
| **화공체** | 3 | 산성 용액 개체 | 8방향 장판 |
| **검체** | 3 | 주사기 실험체 | 원거리 연사. 중독 부여 |
| **정착체** | 4 | **형질 고정에 성공한 이전 개체** | 중력·은신. **물리 ×0.66 / 화염 ×1.5** |
| **보안기** | 4~5 | 무장 드론 | 3점사 × 2~4. 무한 추적 |
| **데이터체** | 5 | 서버에 남은 의식 잔해 | 비물질. **물리 ×0.66**. 발소리 없음 |

> **정착체는 스토리의 핵심이다.** 4장에서 "내가 될 뻔한 것들"임이 밝혀진다.
> 물리가 안 통하는 이유가 3장의 「고정 억제」와 소급해서 이어진다. → [`Story.md`](Blob_Story.md)

**개체 배수는 허용한다** — 같은 원형이라도 5장 개체는 더 두껍게 둘 수 있다.
전역 배율을 쓰지 않을 뿐이다.

## 2. 등급 4종 (PoE2)

| 등급 | 속성 수 | 표시 |
|---|---|---|
| 일반 | 0 | 기본 |
| 마법 | 1~2 | 푸른 윤곽 |
| 희귀 | 3~4 | 노란 윤곽 + 오라 + 고유 이름 |
| 고유(보스) | 고정 | 전용 연출 |

> poe2db — "몬스터 속성 하나당 드랍 희귀도가 100% 이상 증가한다" [확인됨]
> → **등급이 곧 드랍 품질이다.** 별도 드랍 테이블이 필요 없다.

**표시는 색만으로 하지 않는다.** 윤곽 두께와 아이콘을 함께 쓴다 (색각 이상 대응).

## 3. 몬스터 속성 13

개체 단위 수식어. 레이드 특성(맵 단위)과 혼동하지 않는다.

| 분류 | 속성 | 효과 | 대응 |
|---|---|---|---|
| **방어 5** | **갑각** | **방어도 +3** | **방어 관통(장비)** 또는 상태이상 |
| | 경화 | 물리 내성 ×0.5 | 속성 전환(인자) |
| | 내화성 / 절연성 / 항체 | 해당 내성 ×0.5 | 다른 속성 |
| **생존 3** | 재생 | 초당 회복 | 즉발 화력 |
| | 껍질 | 첫 피격 1회 무효 | 다중 적중 |
| | 분열성 | 사망 시 2마리로 분열 | 광역 |
| **공격 3** | 신속 | 이동 +40% | 동결 / 밀어내기 |
| | 과민 | 예비동작 0.35 → 0.2초 | 더 이른 대시 |
| | 육중 | 밀어내기·기절 면역, 이동 −20% | 거리 유지 |
| **지원 2** | 전파 | 주변 일반 적 강화 | 먼저 처치 |
| | 잔향 | 사망 시 속성 1개를 주변에 넘긴다 | 처치 순서 |

> **「갑각」과 「경화」는 다른 축이다 — 두 시스템의 분업 지점이다.**
> 갑각(방어도)은 **장비**의 방어 관통으로 뚫고, 경화(내성)는 **인자**의 속성 전환으로 우회한다.
> 상태이상은 방어도를 무시하므로 갑각에는 도트가 답이지만 경화에는 통하지 않는다.

> ⚠️ **「과민」은 시각 신호가 구현되기 전까지 붙이지 않는다.** 보이지 않는 단축은 불공정하다.

**조합 금지** — 방어형 3개 이상 동시 부여 금지 / 희귀는 방어형 최대 2개 /
**갑각과 경화를 동시에 붙이지 않는다** (두 답을 모두 막는다)

## 4. 진영 5

다른 소속끼리 서로 싸운다. **먼저 어그로를 끈 대상이 있으면 자기가 공격당해도 그 대상을 우선한다.** [확인됨]

| 진영 | 소속 |
|---|---|
| **야생** | 스캐브 · 잠복체 · 화공체 |
| **시설** | 압착기 · 보안기 |
| **실험체** | 자전체 · 검체 |
| **정착** | 정착체 · 데이터체 — 모든 생명체와 적대 |
| **우호** | 구역 내 수집기(상인) · 중립 개체 |

**적 수를 늘리지 않고 전투 다양성을 키우는 가장 싼 방법이다.**
어부지리 · 뒤통수 · 3장 이후 난전의 정체성이 여기서 나온다.
적대만 있으면 구역이 사격장이 되므로 **우호를 반드시 둔다.**

> 진영 구분 자체가 스토리다. "원래 같은 곳에서 나온 것들이 서로를 알아보지 못한다."
> ⚠️ 진영 판정은 프레임마다 돌리지 않는다. 어그로 변경 시에만 갱신한다.

## 5. 시설 상태 — 환경 조건부 스폰

| 상태 | 추가 스폰 | 부수 효과 |
|---|---|---|
| **정전** | 데이터체 | 시야 대폭 감소. **보안기 정지** |
| **침수** | 잠복체 | 이동 감소. **감전 피해 2배** |
| **소독 사이클** | 화공체 | 지속 화학 피해. 화공체 강화 |

- 한 번 스폰된 개체는 상태가 풀려도 사라지지 않는다.
- **출격 전 화면에 표시한다.** 들어가서 알게 하지 않는다.
- 의뢰가 이 축을 직접 쓴다 ("정전 중에만 나오는 데이터체 3마리").

> 맵 제작이 가장 비싼 자산이다. **장 수를 늘리지 않고 조우 다양성을 3배로 만드는 가장 싼 축이다.**
> 정전이 보안기를 멈추듯 **상태가 양날이어야** "위험하지만 기회"가 된다.

## 6. 드랍

| 등급 | 경험치 | 장비 | **인자** | 변이 샘플 |
|---|---|---|---|---|
| 일반 | 기본 | 티어 1~2 낮음 | 낮음 | 없음 |
| 마법 | ×1.5 | 티어 2~3 | 보통 | 없음 |
| 희귀 | ×3 | 티어 3~5 | 높음 | 확률 |
| 고유 | ×6 | 티어 4~6 (**내구도 손상**) | **확정 1개** | **확정** |

**인자 드랍 풀은 도감에 해금된 것만** 포함한다.
레이드 시작 직후 **부여 계열 Core 1개를 확정 드랍**한다 — 없으면 아무것도 쏘지 못한다.

### 6-1. 경험치와 크레딧을 분리한다

> 근거: 덕코프 [확인됨] — 같은 보스가 구역에 따라
> 경험치 800·현금 600 / 경험치 300·**현금 6,000**

| 보상 | 쓰는 곳 | 효율이 좋은 곳 |
|---|---|---|
| **경험치** | 각성 레벨 → 소켓 개방 | **저층 (1~3장)** |
| **크레딧** | 패시브 · 건설 · 상점 | **고층 (4~6장)** |

소켓을 열려면 아래층을 돌고, 벙커를 지으려면 위층으로 간다.
**「어디로 갈까」가 기분이 아니라 목적으로 갈린다.**

### 6-2. 전리품은 컨테이너다

처치하면 **최소 8칸 컨테이너**를 남긴다. **들고 이동할 수 있다** —
들고 있으면 달릴 수 없고 대시하면 내려놓는다.

> 무거운 물건을 담아 옮기다 전투 직전 내려놓아 과중량을 푼다 /
> 추출 지점 근처에 쌓아두고 더 파밍한다. **루팅이 곧 전술이 된다.**

**경험치와 아이템을 분리한다** — 경험치는 접근하면 자동에 가깝게(놓치면 스트레스),
아이템은 컨테이너를 열어 고른다(무게 판단이 필요하다).

### 6-3. 조건부 드랍

```
온전한 신경절   치명타가 아닌 공격으로 처치
굳지 않은 수액   동결 상태에서 처치
미연소 포자     점화를 걸지 않고 처치
```

빌드를 "가장 센 것" 하나로 수렴시키지 않는 가장 값싼 장치다.
**조건은 반드시 사전에 알려준다.** 모르고 놓치게 만드는 건 난이도가 아니라 정보 은폐다.

### 6-4. 변이 샘플 — 도감 해금

```
희귀 이상 처치 → 샘플 드랍 → 흡수
  추출 성공 : 도감 영구 등록      추출 실패 : 샘플 소실
```

미해금 샘플을 들고 있을 때 **"지금 나갈까, 더 돌까"**가 성립한다.

## 7. 배치

- 적은 **맵 전역에 넓게 분산**된다. 탐험하며 소규모로 점진적으로 조우한다.
  **"동시에 수십 마리가 추격하는 군집 생존 게임이 아니다."**
- 루팅과 배치는 매 출격마다 무작위 재배치.
- 등급 분포(맵 1회) — 일반 75% / 마법 20% / 희귀 4~5% / 고유 1~2체 고정. (장이 오르면 상향)
- 조우 단위 — 일반·마법 2~5 / 희귀 단독 또는 일반 3~4 대동 / 고유 지정 구역 고정.
  서로 다른 진영이 같은 구역에 배치될 수 있다 → 난전.

> `EnemyManager`의 "동시 상한 60"은 **성능 상한값**이지 동시 추격 수가 아니다.
> 현재 `EnemySpawner`(2초 간격 원주 스폰)는 임시이며 9단계에서 **맵 전역 사전 배치**로 교체한다.

## 8. 적 행동

**텔레그래프 — 확정.** "예비동작 → 판정" 구조. 접촉 피해가 아니다.
**판정 시점에 사거리를 재확인하는 것이 핵심이다.** 이 구조 덕분에 대시 회피가 유효하다.
시각 신호는 **붉은 플래시**.

**감지 — 원형별로 다르다**

| 원형 | 특이 |
|---|---|
| 자전체 · 검체 | **정면 넓고 측·후방 좁다** → 측면 접근을 인지하지 못한다 |
| 잠복체 · 데이터체 | **발소리가 없다** → 먼저 감지할 수 없다 |
| 스캐브 | 시야는 좁지만 벽에 막혀도 **입구를 찾아 우회 추적** |
| 보안기 | 한 번 추적하면 **끝까지** 쫓는다. 소리로 미리 알 수 있다 |

> **「먼저 감지당하는가 / 먼저 감지하는가」가 이 게임의 핵심 긴장이다.**
> 시야 콘을 무력화하는 수단을 싸게 풀면 설계 전체가 무너진다.

**교전 행동** — 유지 거리를 지키고, 정면으로 붙지 않고 옆으로 돌며,
탄창을 비우면 거리를 벌려 재장전한다.
**동시에 공격하는 수를 제한한다** — 없으면 다섯이 동시에 때려
어려운 게 아니라 **부당하게** 느껴진다.

## 9. 레이드 특성 10종

맵 전체에 적용되며 몬스터 속성과 곱해진다.
예) 「경화 외피」 레이드 + 「경화」 적 → 물리 내성 ×0.25

밀집 서식 / 산개 순찰 / 경화 외피 / 재생 조직 / 내화 피부 / 저온 적응 /
절연 피막 / 면역 항체 / 응고 혈액 / 부식 대기

**중복 완화** — 레이드 특성과 같은 계열의 몬스터 속성은 출현 확률을 낮춘다.
없으면 "그 속성 빌드가 아예 못 싸우는" 구간이 생긴다.

※ 「밀집 서식」과 「산개 순찰」은 동시 부여되지 않는다.
밀집은 조우 단위를 키우며, 이때 전령(처치 시 연쇄)이 최대 가치를 낸다.
