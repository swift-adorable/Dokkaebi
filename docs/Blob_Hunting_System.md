# Hunting System

> **담당** — 상대를 정의한다 · 무엇을 상대하는가
> 수치는 [`Combat_Baseline.md`](Blob_Combat_Baseline.md) 5절. 이 문서는 **누가 갖는가**만 정한다.

```
유형 → 등급 → 속성 → 진영 → 시설 상태 → 드롭 → 배치
```

## 1. 적 유형 9종

**유형은 고정 수치를 갖고, 장은 구성비만 정한다.** 장이 올라간다고 체력에 배율을 곱하지 않는다.

> 근거 — 덕코프는 상위 구역에서 "넝마꾼의 체력"이 아니라
> "용병이 철갑탄을 들기 시작한다"가 바뀐다. [확인됨]

| 유형 | 장 | 정체 | 핵심 기믹 |
|---|---|---|---|
| **스캐브** | 1~2 | 자아 없는 야생 슬라임 | 근접 돌진. 예비동작 → 대시 회피 |
| **압착기** | 1 | 폐기물 처리 로봇 | 느리고 단단. **전기 ×2 / 카오스 면역** |
| **자전체** | 2 | 전기를 머금은 슬라임 | 기본 원거리. 감전 부여 |
| **잠복체** | 2 | 수중 매복형 | 기습. **발소리가 없다** |
| **화공체** | 3 | 산성 용액 개체 | 8방향 장판 |
| **검체** | 3 | 주사기 실험체 | 원거리 연사. 중독 부여 |
| **정착체** | 4 | **형질 고정에 성공한 이전 개체** | 중력·은신. **물리 ×0.66 / 화염 ×1.5** |
| **보안기** | 4~5 | 무장 드론 | 3점사 × 2~4. 무한 추적 |
| **데이터체** | 5 | 서버에 남은 의식 잔해 | 비물질. **물리 ×0.66**. 발소리 없음 |

> **정착체는 스토리의 핵심이다.** 4장에서 "내가 될 뻔한 것들"임이 밝혀진다.
> 물리가 안 통하는 이유가 3장의 「고정 억제」와 소급해서 이어진다. → [`Story.md`](Blob_Story.md)

**개체 배율은 허용한다** — 같은 유형이라도 5장 개체는 더 두껍게 둘 수 있다.
전역 배율을 쓰지 않을 뿐이다.

## 2. 등급 4종 (PoE2)

| 등급 | 속성 수 | 표시 |
|---|---|---|
| 일반 | 0 | 기본 |
| 마법 | 1~2 | 푸른 윤곽 |
| 희귀 | 3~4 | 노란 윤곽 + 오라 + 고유 이름 |
| 고유(보스) | 고정 | 전용 연출 |

> poe2db — "몬스터 속성 하나당 드롭 희귀도가 100% 이상 증가한다" [확인됨]
> → **등급이 곧 드롭 품질이다.** 별도 드롭 테이블이 필요 없다.

**표시는 색만으로 하지 않는다.** 윤곽 두께와 아이콘을 함께 쓴다 (색각 이상 대응).

## 3. 몬스터 속성 14

개체 단위 수식어. 레이드 특성(맵 단위)과 혼동하지 않는다.

| 분류 | 속성 | 효과 | 대응 |
|---|---|---|---|
| **방어 5** | **갑각** | **방어도 +3** | **방어 관통(장비)** 또는 상태이상 |
| | 경화 | 물리 저항 ×0.5 | 속성 전환(젬) |
| | 내화성 / 절연성 / 항체 | 해당 저항 ×0.5 | 다른 속성 |
| | **내한성** | **냉기 저항 ×0.5** | **다른 속성** |
| **생존 3** | 재생 | **초당 최대 체력의 2% 회복** | 즉발 화력 |
| | 껍질 | 첫 피격 1회 무효 | 다중 적중 |
| | 분열성 | 사망 시 2마리로 분열 | 광역 |
| **공격 3** | 신속 | 이동 +40% | 동결 / 밀어내기 |
| | 과민 | 예비동작 0.35 → 0.2초 | 더 이른 대시 |
| | 육중 | 밀어내기·기절 면역, 이동 −20% | 거리 유지 |
| **지원 2** | 전파 | 주변 일반 적 강화 | 먼저 처치 |
| | 잔향 | 사망 시 속성 1개를 주변에 넘긴다 | 처치 순서 |

> **「내한성」은 2026-09-21에 더했다 — 원래 13종이었다.**
> 피해 속성은 물리·화염·냉기·번개·카오스 5종인데 방어 속성은 넷만 막고 있었다.
> 냉기 빌드만 「저항을 만나 답을 바꾸는」 경험을 하지 않는다는 뜻이고,
> 그것이 의도라는 서술은 문서 어디에도 없었다. 레이드 특성에는 「저온 적응」이
> 이미 있어 누락 쪽에 무게가 실린다. PoE2에도 Cold Resistant가 있다.
> [확인됨 — docs/research/poe2/01_몬스터_속성.md]
> `HuntingTests.모든_피해_속성에_저항하는_적이_존재한다`가 이 균형을 강제한다.

> **「재생」의 초당 2%는 PoE2 Regenerates Life에서 가져왔다.**
> 원래 이 칸은 비어 있었다. [확인됨 — 출처 동일] **Blob에서는 미검증이다.**

> **저항 속성은 유형의 약점을 「줄이기만」 한다. 뒤집지 않는다. (2026-09-22)**
> 압착기는 전기 ×2가 정체성인데, 절연성이 붙어 ×0.5가 되면
> 「얘는 전기로 잡아라」라는 답 자체가 사라진다.
> 그래서 저항은 곱하되 자기 배율을 바닥으로 삼는다 —
> 전기 2.0 + 절연성 = **1.0**(약점이 줄 뿐 사라지지 않음),
> 물리 1.0 + 경화 = 0.5, 물리 0.66 + 경화 = 0.5(0.33이 되지 않음).
> 이미 저항이 더 높은 적은 그대로 둔다 — 속성 때문에 물러지지 않는다.
> (`ElementalResistances.LowerTo`)

> **「갑각」과 「경화」는 다른 축이다 — 두 시스템의 분업 지점이다.**
> 갑각(방어도)은 **장비**의 방어 관통으로 뚫고, 경화(저항)는 **젬**의 속성 전환으로 우회한다.
> 상태이상은 방어도를 무시하므로 갑각에는 도트가 답이지만 경화에는 통하지 않는다.

> ⚠️ **「과민」은 시각 신호가 구현되기 전까지 붙이지 않는다.** 보이지 않는 단축은 불공정하다.

**조합 금지** — 방어형 3개 이상 동시 부여 금지 / 희귀는 방어형 최대 2개 /
**갑각과 경화를 동시에 붙이지 않는다** (두 답을 모두 막는다)

## 4. 진영 5

다른 소속끼리 서로 싸운다. **먼저 어그로를 끈 대상이 있으면 자기가 공격당해도 그 대상을 우선한다.** [확인됨]

| 진영 | 소속 |
|---|---|
| **야생** | 스캐브 · 잠복체 · 화공체 |
| **시설** | 압착기 · 보안기 |
| **실험체** | 자전체 · 검체 |
| **정착** | 정착체 · 데이터체 — **나머지 네 진영 전부와 적대** |
| **우호** | 구역 내 수집기(상인) · 중립 개체 |

> **「모든 생명체와 적대」를 「나머지 전부와 적대」로 고쳤다. (2026-09-22)**
> 앞 문장은 정착체와 데이터체도 서로 싸운다는 뜻으로 읽히는데,
> 같은 표에서 둘을 한 진영으로 묶어 놓아 표와 모순이었다.
>
> 덕코프가 이 경우를 어떻게 다루는지가 답이 됐다 —
> 「늑대 / 보행 버섯 / 기계 거미 / 폭풍 생물 = **전용 진영**. 플레이어 포함
> 모든 생명체 적대」. 즉 「모든 것과 적대」는 **혼자만 있는 진영**으로 표현한다.
> [확인됨 — research/duckov_적.md 1절]
>
> 정착체와 데이터체를 한 진영에 묶어 둔 이상 그 둘은 덕코프의 「전용 진영」이
> 아니다. 표가 이기고 문장을 고친다. 스토리로도 맞다 —
> 4장에서 「내가 될 뻔한 것들」이 서로 죽이는 그림은 의도가 아니다.

**적 수를 늘리지 않고 전투 다양성을 키우는 가장 싼 방법이다.**
어부지리 · 뒤통수 · 3장 이후 난전의 정체성이 여기서 나온다.
적대만 있으면 구역이 사격장이 되므로 **우호를 반드시 둔다.**

> 진영 구분 자체가 스토리다. "원래 같은 곳에서 나온 것들이 서로를 알아보지 못한다."
> ⚠️ 진영 판정은 프레임마다 돌리지 않는다. 어그로 변경 시에만 갱신한다.

## 5. 시설 상태 — 환경 조건부 스폰

| 상태 | 추가 스폰 | 부수 효과 |
|---|---|---|
| **정전** | 데이터체 | 시야 ×0.45. **보안기 정지** |
| **침수** | 잠복체 | 이동 ×0.75. **감전 피해 2배** |
| **소독 사이클** | 화공체 | 초당 1 화학 피해. 화공체 ×1.3 |

> 수치는 「대폭 감소」 「이동 감소」 같은 서술에서 정한 값이다.
> 정전의 ×0.45는 기본 시야 18m를 8m로 만든다 — **총성(22m)보다 짧아져
> 「보기 전에 듣는다」가 뒤집힌다.** 그것이 정전의 정체다.
> (`docs/Blob_Decisions.md` 2-20~2-23)

- 한 번 스폰된 개체는 상태가 풀려도 사라지지 않는다.
- **파밍 전 화면에 표시한다.** 들어가서 알게 하지 않는다.
- 퀘스트가 이 축을 직접 쓴다 ("정전 중에만 나오는 데이터체 3마리").

> 맵 제작이 가장 비싼 자산이다. **장 수를 늘리지 않고 조우 다양성을 3배로 만드는 가장 싼 축이다.**
> 정전이 보안기를 멈추듯 **상태가 양날이어야** "위험하지만 기회"가 된다.

## 6. 드롭

| 등급 | 경험치 | 장비 | **젬** | 변이 샘플 |
|---|---|---|---|---|
| 일반 | 기본 | 티어 1~2 낮음 | 낮음 | 없음 |
| 마법 | ×1.5 | 티어 2~3 | 보통 | 없음 |
| 희귀 | ×3 | 티어 3~5 | 높음 | 확률 |
| 고유 | ×6 | 티어 4~6 (**내구도 손상**) | **확정 1개** | **확정** |

**젬 드롭 풀은 도감에 해금된 것만** 포함한다.
레이드 시작 직후 **부여 계열 핵심 젬 1개를 확정 드롭**한다 — 없으면 아무것도 쏘지 못한다.

### 6-1. 경험치와 크레딧을 분리한다

> 근거: 덕코프 [확인됨] — 같은 보스가 구역에 따라
> 경험치 800·현금 600 / 경험치 300·**현금 6,000**

| 보상 | 쓰는 곳 | 효율이 좋은 곳 |
|---|---|---|
| **경험치** | 레벨 → 소켓 개방 | **저층 (1~3장)** |
| **크레딧** | 패시브 · 건설 · 상점 | **고층 (4~6장)** |

소켓을 열려면 아래층을 돌고, 벙커를 지으려면 위층으로 간다.
**「어디로 갈까」가 기분이 아니라 목적으로 갈린다.**

### 6-2. 전리품은 상자다

처치하면 **최소 8칸 상자**를 남긴다. **들고 이동할 수 있다** —
들고 있으면 달릴 수 없고 대시하면 내려놓는다.

> 무거운 물건을 담아 옮기다 전투 직전 내려놓아 과중량을 푼다 /
> 철수 지점 근처에 쌓아두고 더 파밍한다. **루팅이 곧 전술이 된다.**

**경험치와 아이템을 분리한다** — 경험치는 접근하면 자동에 가깝게(놓치면 스트레스),
아이템은 상자를 열어 고른다(무게 판단이 필요하다).

### 6-3. 조건부 드롭

```
온전한 신경절   치명타가 아닌 공격으로 처치
굳지 않은 수액   동결 상태에서 처치
미연소 포자     점화를 걸지 않고 처치
```

빌드를 "가장 센 것" 하나로 수렴시키지 않는 가장 값싼 장치다.
**조건은 반드시 사전에 알려준다.** 모르고 놓치게 만드는 건 난이도가 아니라 정보 은폐다.

### 6-4. 변이 샘플 — 도감 해금

```
희귀 이상 처치 → 샘플 드롭 → 흡수
  철수 성공 : 도감 영구 등록      철수 실패 : 샘플 소실
```

미해금 샘플을 들고 있을 때 **"지금 나갈까, 더 돌까"**가 성립한다.

## 7. 배치

- 적은 **맵 전역에 넓게 분산**된다. 탐험하며 소규모로 점진적으로 조우한다.
  **"동시에 수십 마리가 추격하는 군집 생존 게임이 아니다."**
- 루팅과 배치는 매 파밍마다 무작위 재배치.
- 등급 분포(맵 1회) — 일반 75% / 마법 20% / 희귀 4~5% / 고유 1~2체 고정. (장이 오르면 상향)
- 조우 단위 — 일반·마법 2~5 / 희귀 단독 또는 일반 3~4 대동 / 고유 지정 구역 고정.
  서로 다른 진영이 같은 구역에 배치될 수 있다 → 난전.

> `EnemyManager`의 "동시 상한 60"은 **성능 상한값**이지 동시 추격 수가 아니다.
> 현재 `EnemySpawner`(2초 간격 원주 스폰)는 임시이며 9단계에서 **맵 전역 사전 배치**로 교체한다.

## 8. 적 행동

**텔레그래프 — 확정.** "예비동작 → 판정" 구조. 접촉 피해가 아니다.
**판정 시점에 사거리를 재확인하는 것이 핵심이다.** 이 구조 덕분에 대시 회피가 유효하다.
시각 신호는 **붉은 플래시**.

**감지 — 유형별로 다르다**

| 유형 | 특이 |
|---|---|
| 자전체 · 검체 | **정면 넓고 측·후방 좁다** → 측면 접근을 인지하지 못한다 |
| 잠복체 · 데이터체 | **발소리가 없다** → 먼저 감지할 수 없다 |
| 스캐브 | 시야는 좁지만 벽에 막혀도 **입구를 찾아 우회 추적** |
| 보안기 | 한 번 추적하면 **끝까지** 쫓는다. 소리로 미리 알 수 있다 |

> **「먼저 감지당하는가 / 먼저 감지하는가」가 이 게임의 핵심 긴장이다.**
> 시야각을 무력화하는 수단을 싸게 풀면 설계 전체가 무너진다.

### 추적을 그만두는 조건 — 시간이 정한다 (2026-09-22 구현)

| 축 | 값 | 누가 |
|---|---|---|
| 망각 시간 | 8초 / 22초 / 30초 | 기본 / 자전체·검체 / 보안기 |
| 강제 추적 거리 | 0m / 15m / 40m | 기본 / 자전체·검체 / 보안기 |
| 최후 방어선 | 감지 거리 × 3 | 전부 |
| 듣는 쪽 청각 | 0.75 / 1.0 / 2.0 | 기계형 / 기본 / 잠복체 |

**거리가 아니라 시간으로 놓는다.** 거리로만 판정하면 플레이어가 적보다
느릴 때 — 즉 짐을 잔뜩 들었을 때 — 교전을 피할 방법이 아예 없다.
철수 루팅에서 가장 중요한 순간에 선택지가 사라진다.
시간으로 두면 **「엄폐물 뒤에서 버틴다」가 유효한 수**가 된다.

위 표의 「보안기는 끝까지 쫓는다」는 **40m 안에서는 잊지 않고, 벗어나도
30초를 더 찾아다닌다**로 구현했다. 문자 그대로의 「끝까지」가 아니다 —
그렇게 두면 보안기를 만난 순간 구역을 뜨는 것 외의 수가 없어진다.
「끝까지」가 전하려던 **「이놈만은 쉽게 떼어낼 수 없다」**는 유지된다.

수치는 전부 실제로 출시된 게임의 실측값이다.
[확인됨 — `docs/research/duckov/05_적_AI_실측치.md` 2·3절]

**교전 행동** — 유지 거리를 지키고, 정면으로 붙지 않고 옆으로 돌며,
탄창을 비우면 거리를 벌려 재장전한다.
**동시에 공격하는 수를 제한한다** — 없으면 다섯이 동시에 때려
어려운 게 아니라 **부당하게** 느껴진다.

## 9. 레이드 특성 10종

맵 전체에 적용된다. **저항은 곱해지지 않는다 — 가장 낮은 배율 하나만 적용한다.**

> 예) 「경화 외피」 레이드(물리 ×0.5) + 「경화」 적(물리 ×0.5) → **×0.5**. ×0.25가 아니다.
>
> 곱연산이면 원천 두 개만으로 「이 속성으로는 못 잡는다」가 된다.
> 상태이상 피해에도 속성 상성이 곱해지므로 **방어도 무시라는 우회로까지 같이 막힌다.**
> 철수 루팅에서 그건 파밍을 버리라는 뜻이다.
>
> 깊이는 **「여러 속성에 동시에 저항하는 적」**으로 낸다. 그러면 플레이어가
> "남은 속성을 쓰면 된다"를 즉시 판단할 수 있다. 곱연산은 그 판단을 불가능하게 만든다.
> (`Combat_Baseline` 「속성 상성」 · `ElementalResistances.TakeLowest`)

| 특성 | 효과 | 출처 |
|---|---|---|
| 밀집 서식 | 무리 크기 ×1.6 · 좁게 뭉친다 | 수치는 정한 값 |
| 산개 순찰 | 무리 크기 ×0.6 · 넓게 흩어진다 | 수치는 정한 값 |
| 경화 외피 | 물리 ×0.5 | 속성과 같은 배율 |
| 화염 저항 피부 | 화염 ×0.5 | |
| 저온 적응 | 냉기 ×0.5 | |
| 전기 저항 피막 | 번개 ×0.5 | |
| 면역 항체 | 카오스 ×0.5 | |
| 재생 조직 | 초당 최대체력 2% 회복 | 속성 「재생」과 같은 값 |
| 응고 혈액 | **출혈이 걸리지 않는다** | 기획서엔 이름만 — 정한 값 |
| 부식 대기 | **장비 내구도 소모 ×1.5** | 기획서엔 이름만 — 정한 값 |

**저항 특성은 한 판에 하나만 건다.** 맵 전체에 둘을 걸면 남은 속성이 셋뿐이라
「빌드를 바꾸면 된다」가 「이 빌드로는 못 온다」가 된다.
깊이는 문서가 말한 대로 **개체 단위**(여러 속성에 동시에 저항하는 적)로 낸다.

**한 판의 특성은 최대 2개.** 셋이면 특성 목록을 다 외워야 판을 읽을 수 있다.

**중복 완화** — 레이드 특성과 같은 계열의 몬스터 속성은 출현 확률을 낮춘다.
없으면 "그 속성 빌드가 아예 못 싸우는" 구간이 생긴다.

※ 「밀집 서식」과 「산개 순찰」은 동시 부여되지 않는다.
밀집은 조우 단위를 키우며, 이때 전령(처치 시 연쇄)이 최대 가치를 낸다.
