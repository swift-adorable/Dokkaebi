# Passive System

> **담당** — 계정이 배우는 것 · 런을 넘어 남는 것
> **근거** — 덕코프 「스킬」 (조사 기록: [`research/duckov_스킬.md`](research/duckov_스킬.md))

수치의 출처는 이 문서다. 전투 수치는 이 문서에 **없다** — 그것은
[`Equipment_System.md`](Blob_Equipment_System.md)의 몫이다. 그 경계가 이 문서의 핵심이다.

## 0. 세 축을 먼저 못 박는다

| 축 | 여는 것 | 잃는가 | 문서 |
|---|---|---|---|
| **각성 레벨** | 소켓 | 런마다 초기화 | Skill_System 12절 |
| **장비 · 인자** | 전투 능력 | 죽으면 들고 있던 것 전부 | Equipment / Skill |
| **계정 레벨 (패시브)** | 휴대 · 수집 · 회수 · 경제 · 해금 | **영구. 잃지 않는다** | 이 문서 |

### 절대 규칙 — 패시브는 전투 수치를 주지 않는다

방어도 · 방어 관통 · 피해 · 최대 체력 · 이동 속도 · 시야 · 감지 · 대시는 **전부 장비**다.

> **덕코프는 이것을 지키지 않는다.** 「생존 본능 I = 최대 생명력 +5」,
> 「팔굽혀펴기 I = 근접데미지 +5%」, 「하이니즈 달리기 = 이동 능력 +2%」가 실제로 있다. [확인됨]
>
> 따르지 않는 이유 — 덕코프는 장비 옵션이 단순해 겹쳐도 장비의 존재 이유가 남는다.
> Blob의 장비는 옵션이 25종이다. 패시브가 같은 축을 건드리면
> **장비를 고르는 결정이 통째로 사라진다.** 성장 축 셋 중 하나가 죽는다.

검사는 문서가 아니라 테스트가 한다 — `PassiveStateTests.패시브_효과에_전투_수치가_없다`가
`PassiveEffectType` enum 이름에서 전투 단어(Armour · Damage · Health · Move · View · Detect …)를 막는다.
문서에만 적힌 규칙은 언젠가 "방어력 +5 하나쯤이야"로 무너진다.

## 1. 계열 5갈래 — 단일 트리를 쓰지 않는다

덕코프의 가장 중요한 구조적 사실은 **스킬이 독립된 5계열**이라는 것이다. [확인됨]
단일 트리는 "위로 한 줄"뿐이라 유저가 고를 것이 순서밖에 없다.
계열이 갈리면 **출격 성향이 갈린다.**

| 계열 | 무엇을 | 해금 조건 | 대응 (덕코프) |
|---|---|---|---|
| **적응** | 얼마나 들고 나가는가 | 계정 레벨 | 스킬 강화 |
| **대사** | 얼마나 얻는가 | 계정 레벨 | 생존 스킬 |
| **회수** | 죽어도 무엇이 남는가 | 계정 레벨 | (Blob 고유) |
| **중개** | 벙커에서 무엇을 하는가 | **크레딧만** (레벨 무관) | 블랙마켓 업그레이드 |
| **역행** | — | **탐험. 조우해야 보인다** | 이상한 개조 |

「신체 단련」 계열은 통째로 **가져오지 않는다.** 전부 장비의 축이다.
그 자리를 Blob 고유의 **회수**가 대신한다 — 추출 루팅 게임에서
「죽어도 무엇이 남는가」는 휴대만큼 큰 결정이다.

## 2. 해금 조건 3종

| 종류 | 계열 | 규칙 |
|---|---|---|
| `AccountLevel` | 적응 · 대사 · 회수 | 계정 레벨 + 크레딧 + **필요물품** |
| `CreditsOnly` | 중개 | 레벨을 보지 않는다. 돈만 있으면 연다 |
| `Discovery` | 역행 | **계열 전체가 조우 전까지 보이지 않는다** |

> **역행이 조우 해금인 근거** — 덕코프의 「이상한 개조」는
> 지하실 열쇠 → 독가스 구역 통과 → 갈림길 열쇠 → 수상한 상인 조우로 열린다. [확인됨]
> 레벨도 돈도 아니고 **「거기까지 갔는가」**가 조건이다.
> Blob은 4장(특수 격리동)의 봉인된 관측실에서 「역행자」를 만나야 열린다.
> (스토리 연결: [`Story.md`](Blob_Story.md) 4장)

## 3. 필요물품 — 크레딧만으로는 열리지 않는다

덕코프 스킬 표에는 **「필요물품」 열이 존재한다.** [확인됨]
(현재 모든 행이 `-`지만 열이 있다는 것은 아이템을 요구하는 설계라는 뜻이다)

Blob은 이것을 실제로 쓴다.

```
하위 칸  : 크레딧만
중간 칸  : 크레딧 + 흔한 재료 (고철 · 전선 뭉치)
상위 칸  : 크레딧 + 귀한 재료 (메모리 코어 · 조직 샘플)
```

**왜 중요한가** — 크레딧만 쓰면 시간을 들이면 전부 열린다. 결정이 없다.
재료를 요구하면 **"이 메모리 코어를 팔까, 패시브에 쓸까"**가 생긴다.
파밍이 성장에 직접 닿는다.

## 4. 트리 모양 — 덕코프에서 가져온 세 패턴

| 패턴 | 덕코프 사례 [확인됨] | Blob 적용 |
|---|---|---|
| **다이아몬드** | 영양 관리 3 → 4·5 → 6 (합류) | 각 계열에 최소 1개 |
| **교차 선행** | 식이요법 = 낚시 3 **＋** 영양 관리 3 | 역행 계열이 다른 계열의 칸을 요구 |
| **계단** | 블랙마켓 통신 I~V (같은 효과 반복) | 중개 계열 전체 |

- 다이아몬드는 **순서에 결정**을 만든다. 4를 먼저 갈지 5를 먼저 갈지.
- 교차 선행은 **한 갈래만 파면 닿지 않는 칸**을 만든다. 넓게 파야 하는 이유가 생긴다.
- 계단은 **고민 없이 쌓는 갈래**다. 전부 결정이면 피로하다. 하나쯤은 단순해야 한다.

## 5. 효과 목록

전부 비전투다. 새 효과를 추가할 때는 **"이것이 전투 중에 적용되는가"**를 먼저 묻는다.

### 적응 — 휴대

| 효과 | 설명 | 장비와의 관계 |
|---|---|---|
| `CarrySlots` | 가방 적재 칸 | 겹침. **패시브 총합 ≤ 장비 최대치의 1/3** |
| `CarryWeight` | 최대 소지 중량 | 겹침. 같은 제한 |

> 겹치는 축에 상한을 두는 이유 — 가방 티어 6종을 고르는 결정이 남아야 한다.

### 대사 — 수집

| 효과 | 설명 |
|---|---|
| `AbsorbAmount` | 경험치 획득 +n% |
| `AbsorbRange` | 흡수 감지 범위 +n |
| `LootRolls` | 시체 전리품 추첨 +n회 |
| `RareDropRate` | 희귀 드랍 +n% |

### 회수 — 죽어도 남는 것

| 효과 | 설명 |
|---|---|
| `SafeSlots` | 사망해도 지키는 가방 칸 +n |
| `CorpseRecovery` | 【해금】 추출 실패 시 내 시체에서 1회 회수 |
| `ExtractMark` | 【해금】 지도에 추출 지점 상시 표시 |

> `SafeSlots`는 **규칙 하나(죽으면 들고 있던 것 전부)의 유일한 예외**다.
> 예외를 늘리지 않기 위해 이 계열 밖에는 두지 않는다.
> 각인이 사망에 비유실인 것은 아이템 속성이지 패시브가 아니다.

### 중개 — 벙커 경제

| 효과 | 설명 |
|---|---|
| `SellPrice` | 판매가 +n% |
| `StashSlots` | 창고 칸 +n |
| `ShopRefresh` | 상점 갱신 쿨타임 −n% |
| `ShopSlots` | 상점 갱신 횟수 +n |

### 역행 — 숨겨진 것

| 효과 | 설명 |
|---|---|
| `CraftBench` | 【해금】 제작대 |
| `CodexAuto` | 【해금】 처치만 해도 도감에 등록 (샘플 흡수 불필요) |
| `GemSalvage` | 【해금】 인자를 분해해 재료로 |
| `MapLoot` | 【해금】 지도에 전리품 위치 표시 |

## 6. 금지 사항

1. **전투 수치를 주지 않는다.** 방어도·관통·피해·체력·이동·시야·감지·대시.
2. **새 예외를 만들지 않는다.** 사망 규칙의 예외는 `SafeSlots` 하나뿐이다.
3. **초기화(리스펙)를 넣지 않는다.** 되돌릴 수 있으면 고를 때 고민하지 않는다.
   ※ 덕코프에 리스펙이 있는지는 [확인 불가] — 문서에 없다. 없는 쪽으로 간다.
4. **계열을 6개 이상으로 늘리지 않는다.** 화면 한 장에 들어와야 한다.
5. **같은 효과를 두 계열에 두지 않는다.** 어느 갈래를 팔지가 흐려진다.
6. 패시브로 **인자(스킬)를 주지 않는다.** 인자는 파밍으로만 얻는다.
