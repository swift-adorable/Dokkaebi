> **담당** — 무엇이라 부르는가
> 2026-09-29 초안 작성 · 2026-10-02 스토리 v2.2에 맞춰 갱신하고 정식 문서로 옮겼다 (초안 원본은 `archive/Dokkaebi_Naming_초안.md`).

> 수치(발사 간격 · 탄약)는 이 문서에 두지 않는다 → [`Combat_Baseline.md` 3-1 · 3-2절](Blob_Combat_Baseline.md). 서사는 [`Story.md`](Blob_Story.md).

## 0. 이름 원칙

1. **시스템 용어는 덕코프를 따른다** — 체력 · 방어도 · 중첩 · 파밍 · 철수 · 레벨 · 골드
2. **아이템 · 장소 이름은 테마를 따른다** — 출처 순서: 실제 기록 → 설화 → 조어
3. **이름이 기능을 거짓말하지 않는다**
4. 코드 식별자(영어)는 바꾸지 않는다 — 화면 글자만 바뀐다
5. **오방 색 체계** — 빨강 화염 · 검정 냉기 · 파랑 전기 · 흰색 물리 · 노랑 독. 탈 · 사신수 · 장이 같은 색을 쓴다

## 6. 이야기 · 게임 화면 표기

기획 문서의 시스템 용어는 그대로 두고, **이야기와 게임 화면에서만** 아래처럼 부른다.

| 기획 문서 | 이야기 · 게임 화면 |
|---|---|
| 스킬 젬 | **구슬** (싣는 구슬 · 모였다 터지는 구슬 · 번지는 구슬). 삼키지 않고 몸에 지니며 바꿔 지닐 수 있다 |
| 경험치 · 레벨 | 정기 |
| 각인 | 새김패 (할머니의 오색 매듭 가장 굵은 두 곳에 묶는다) |
| 벙커 | 고목 아래 소굴 (빗자루 = 그릇을 여기 두고 다닌다) |
| 결계 | 금줄 |
| 철수 지점 | 고목으로 돌아오는 길목 (UI로 표시) |

## 8. 남은 결정

- 장별 파밍 재료 이름 (3단계 — 맵과 함께)

- 「벙커」 · 「골드」를 테마 이름으로 바꿀지 (본문은 이미 「고목 아래 소굴」로 쓰고 있다)
