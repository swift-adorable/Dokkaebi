## ✅ 1. 결정 완료 (2026-09-22)

### 1-1. 정착 진영이 자기들끼리도 싸우나? → **안 싸운다**

덕코프가 이 경우를 어떻게 처리하는지가 답이 됐다.

> 「늑대 / 보행 버섯 / 기계 거미 / 폭풍 생물 = **전용 진영**.
>  플레이어 포함 모든 생명체 적대」
> [확인됨 — `research/duckov_적.md` 1절]

덕코프는 「모든 것과 적대」를 **그 종 혼자만 있는 진영**으로 표현한다.
Blob의 정착은 정착체 + 데이터체 **둘이 한 진영**이니 전용 진영이 아니다.
→ 표가 이기고 문장을 고쳤다. `Hunting 4절` 「모든 생명체와 적대」 →
**「나머지 네 진영 전부와 적대」**.

스토리로도 맞다. 4장에서 「내가 될 뻔한 것들」이 서로 죽이는 그림은 의도가 아니다.

### 1-2. 압착기 약점이 사라지는 문제 → **저항이 약점을 줄이기만 하게**

처음에는 「압착기에 절연성을 못 붙이게 막자」(조합 금지)를 추천했는데,
계산을 따져 보니 **더 나은 방법이 있어서 바꿨다.**

조합 금지는 원형이나 속성이 추가될 때마다 금지 목록을 손봐야 한다.
대신 저항 계산 한 줄을 고치면 전부 자동으로 해결된다.

```
저항 = Min(현재값, Max(현재값 × 배율, 배율))

전기 2.0  + 절연성 → 1.0   약점이 줄 뿐 사라지지 않는다
물리 1.0  + 경화   → 0.5   기존과 동일
물리 0.66 + 경화   → 0.5   0.33이 되지 않는다 (곱연산 금지 유지)
이미 0.4  + 경화   → 0.4   속성 때문에 오히려 물러지지 않는다
```

기획서의 「가장 낮은 배율 하나만」 예시(레이드 0.5 + 적 0.5 → 0.5)도 그대로 성립한다.
PoE2가 저항을 가산으로 다루는 것과 결과가 같아진다.

### 1-3. 몬스터 속성 13 → 14 → **유지**

데미지 속성 5개 중 냉기만 저항하는 적이 없었다.
레이드 특성에는 「저온 적응」이 이미 있어서 빠뜨린 쪽에 무게가 실린다.
→ `Hunting 3절`을 14종으로 수정 완료.

## ⚪ 5. 아직 눈으로 확인 못 한 것들

7-A부터 7-E까지 만든 것 중에 **실제로 게임 돌려서 본 건 7-F 한 번**이다.
테스트는 다 통과하는데, 그건 **계산이 맞다**는 거지 **재밌다**는 게 아니다.

아직 확인 안 됨 —
- 등급 배수가 실제 스폰에서 곱해지는지 (본 스폰이 전부 Normal이었음)
- 속성이 붙는지
- 적끼리 싸우는지 (스포너가 한 진영만 냄 + 에디터 포커스 나가면 게임이 멈춤)
- 시야각이랑 소리가 체감되는지
- 잡았을 때 보상이 실제로 들어오는지
