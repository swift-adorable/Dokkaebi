## 🔴 1. 설계가 어긋나 있어 지금 정해야 하는 것

### 1-1. 정착 진영 — "모든 생명체와 적대"의 범위

`Hunting 4절`은 정착(정착체·데이터체)을 **"모든 생명체와 적대"** 라고 적었다.
글자 그대로 읽으면 정착체와 데이터체도 서로 싸운다는 뜻인데,
같은 표에서 둘을 **같은 소속으로 묶어** 놓았다. 문장과 표가 모순이다.

| | 뜻 | 결과 |
|---|---|---|
| **A (현재 구현)** | 같은 소속끼리는 안 싸운다 | 정착이 다른 넷과만 싸운다. 진영 규칙이 일관됨 |
| B | 정착은 자기들끼리도 싸운다 | 정착을 「진영」이 아니라 「적대 태그」로 다뤄야 함 |

**추천 A.** B로 가면 정착만 규칙이 다른 예외가 되고, 4장에서
"내가 될 뻔한 것들"이 서로 죽이는 그림이 스토리와도 어긋난다.
→ 지금 코드: `FactionTable.IsHostile` 주석에 [불확실] 표기 상태

### 1-2. 원형의 약점이 속성 하나로 지워진다

압착기는 **전기 ×2**(약점)가 정체성이다. 그런데 「절연성」(전기 내성 ×0.5)이
붙으면 `LowerTo`가 전기를 0.5로 만든다 — **약점이 뒤집힌다.**
「이 적은 전기로 잡는다」는 답이 사라진다.

| | 방식 | 결과 |
|---|---|---|
| **A** | 원형의 약점과 같은 계열 속성을 **금지 조합**에 추가 | 압착기에 절연성이 안 붙는다. 규칙이 하나 늘어난다 |
| B | 속성은 약점을 **깎기만** 한다 (×2 → ×1, 뒤집지 않음) | PoE2 방식(저항 가산)에 가깝다. 계산이 한 겹 늘어난다 |
| C | 그대로 둔다 | 「절연성 압착기」는 전기 빌드가 포기하는 적이 된다 |

**추천 A.** 조합 금지 규칙이 이미 있고(갑각↔경화), 같은 사상이다.
B는 「가장 낮은 것 하나만」이라는 기존 규칙과 충돌한다.

> 참고 — PoE2는 내성을 **+50% 가산**으로 다뤄 약점을 지우지 않는다.
> [확인됨 — `research/poe2/01_몬스터_속성.md`]

### 1-3. 몬스터 속성 13 → 14 (내한성 추가)

피해 속성은 5종인데 방어 속성은 넷(물리·화염·번개·카오스)만 막고 있었다.
**냉기 빌드만 저항하는 적을 만나지 않는다.** 근거 없는 비대칭으로 보고 채웠다.

- 유지하면 → 문서 3절의 「13종」을 14종으로 고친다
- 되돌리면 → `EnemyAffix.Cryostable` 한 항목과 테이블 3곳을 지운다

**추천 유지.** 레이드 특성에는 「저온 적응」이 이미 있어 누락 쪽에 무게가 실린다.

## ⚪ 5. 검증 부채

7-A부터 7-E까지 **Play Mode 실증은 7-F 한 번뿐**이다.
EditMode 테스트는 전부 통과하지만, 그것이 확인하는 것은 **계산**이지 **체감**이 아니다.

확인되지 않은 것 —
- 등급 배율이 실제 스폰에서 곱해지는가 (관측된 스폰이 전부 Normal이었다)
- 속성(affix)이 붙는가
- 적끼리 싸우는가 (스포너가 한 진영만 낸다 + 에디터 포커스 문제)
- 시야각·소리가 체감되는가
- 처치 보상이 실제로 들어오는가
