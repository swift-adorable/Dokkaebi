# 덕코프 — 퀘스트 / 도전과제 / 노트 / 모드 [확인됨, namu.wiki]

## 1. 퀘스트 = 해금 배달부
NPC 6명이 각자 다른 **해금 축**을 담당한다. 퀘스트 라인이 곧 기능 개방 트리.

| NPC | 퀘스트 | 담당 축 |
|---|---|---|
| 제프 | 30 (메인) | 기지 건설 · 구역 개방 |
| 머드 | 13 | 신체 스킬 · 도핑 주사 해금 |
| 오렌지 | 9 | 방어 장비 상점 재고 |
| 김씨 | 13 | 화기·탄약 상점 재고 (무기 1정 단위로 해금) |
| 잭 | 4 | 메인 스토리 (엔딩) |
| 부처 형 | 4 | 낚시 서브시스템 |

**패턴 3가지**
1. **해금이 보상 슬롯 안에 들어있다.** 상점은 처음부터 열려 있지 않고 퀘스트로 한 줄씩 열린다
2. **NPC 영입 자체가 퀘스트다** (신호탑 수리 → 연락 → 건물 건설 → 입주)
3. **골드 싱크를 퀘스트로 정당화** (첫 퀘스트가 1,888골드 납부)

## 2. 퀘스트 유형
| 유형 | 사례 |
|---|---|
| 제출(반출)형 | 고기칼 2, 흐릿한 깃털 4, 화약 30 |
| 건설/연구형 | 작업대 건설, 스킬 연구, 창고 확장 Lv.1 |
| 처치형 | 헤드샷 5킬, 용병 3, 보스 |
| **조건부 처치형 (매우 많음)** | 지정 무기(나무 막대기로 용병 1킬) / 지정 버프(근접 주사 중 5킬) / **지정 시간(밤 22~06시 기계 거미)** / **지정 날씨(비 오는 날 버섯)** / 지정 이벤트(폭풍 중 폭풍 생물) |
| 도달/탐험형 | 창고구역 탈출, 서부공장 3개 입구 도달 |
| 선행 아이템 요구형 | 드라이버·렌치·마커 — **레이드 출발 전 준비를 강제** |

→ 조건부 처치 퀘스트가 "숙련 유도 + 플레이 다양화 + 재화 싱크"를 한 번에 해결한다.
→ 환경 조건부 스폰(비/밤/폭풍)과 퀘스트가 맞물려 있다.

## 3. 동선 유도
좌표가 아니라 **랜드마크 문장**으로 유도한다 ("끊어진 다리 북쪽, 농가의 북동쪽").
진행 반경이 계단식으로 확장. 지름길(맨홀 단축 입구)도 퀘스트에 숨겨 둔다.

## 4. 노트 = 65개 수집형 로어, 4중 기능
1. **튜토리얼 대체** — "빨간 라이트 = 공격 신호, 스페이스로 구르기"
                       "적당히 채우고 바로 집으로, 욕심 부리지 마"
2. **공략 힌트** — "하얀 녀석 건드리지 마", "개가 보이면 숨어라"
3. **보스 약점표** — 팔라팔라=독 취약, 빌리빌리=고온 취약
4. **서브시스템 DB** — 낚시 노트 5장에 시간대/날씨/지역/미끼별 어종표 분산

배치가 진행 순서와 정확히 일치. 일부는 **내용이 훼손/공란**으로 제시되어 수집욕 자극.
노트 자체의 보상 유무는 문서에 없음.

## 5. ★ 모드로 역산한 원작 페인 포인트 — "따라 하면 안 되는 것"
| 분류 | 페인 포인트 |
|---|---|
| **정보 은폐 (최대 불만)** | 아이템 가치·희귀도 미표시 (이걸 고친 모드 구독 **200만**) |
| | 내구도 수치·최대내구 손실 경고 없음 / 분해 결과 미리보기 없음 |
| | 퀘스트에 필요한 아이템인지 알 수 없음 / 퀘스트 추적 HUD 없음 |
| | 라운드 손익·플레이 시간 결산 없음 / 창고 재고 수량 미표시 |
| **인벤토리 마찰** | 창고 검색·정렬 없음 / 바닥 아이템을 하나씩 주워야 함 (Loot All 없음) |
| **조작** | 정조준이 홀드 전용(토글 없음) / 발사 모드 전환 없음 / 단축키 변경 불가 |
| **시간 낭비** | 기지 업그레이드 대기 / 특정 시간대까지 대기 / 낚시 미니게임 |
| **시스템 설계** | 수리 시 최대 내구도 영구 감소 / 적 AI가 엄폐·후퇴를 안 함 |

### 단, 고쳤지만 따라 하면 안 되는 것
퀘스트 위치 지도 표시 / 보스 실시간 마커 → 문서가 직접 경고:
"플레이 타임이 단축되고 **갑작스럽게 보스와 마주치는 긴장감이 없어진다**"
→ 불편함이 아니라 **의도된 긴장감**인 영역이 있다.

## 6. Blob 적용 시 핵심 교훈
1. 정보 UI는 처음부터 넣는다 (아이템 가치, Loot All, 창고 검색·정렬, 퀘스트 추적, 손익 결산)
2. 조작 편의(조준 토글, 상태 기억)는 옵션으로 기본 제공
3. 위치 힌트는 텍스트 랜드마크 유지, 모바일은 "구역 하이라이트" 정도로 타협
4. 수리 시 최대 내구도 감소는 경제 싱크로는 훌륭하지만 **유저 최대 불만 중 하나** — 완화 필요
