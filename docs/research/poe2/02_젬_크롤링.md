## 왜 이 형태로 남기는가

Blob은 탑다운 슈터라 PoE2의 액티브 스킬 194+115종은 대부분 옮길 수 없다.
**옮길 수 있는 것은 보조 젬 630종의 「효과축과 수치 폭」이다.**
Blob의 Support 21종이 어떤 축을 고르고 얼마를 줄지 판단할 때
「이미 검증된 게임이 이 축에 몇 %를 줬는가」가 근거가 된다.

그래서 원본은 통째로 두되, 보조 젬만 따로 정리한 표를 03 문서에 둔다.

## 쓰는 법

```bash
# 이름으로 찾기
grep '마름쇠' docs/research/poe2/raw/gems.jsonl | python3 -m json.tool

# 유형별 세기
python3 - <<'EOF'
import json,re,collections
rows=[json.loads(l) for l in open('docs/research/poe2/raw/gems.jsonl')]
print(collections.Counter(re.search(r'유형:\s*(.+?)등급:', r['text'].replace(chr(10),'')).group(1)
                          for r in rows if '유형:' in r['text']).most_common(20))
EOF
```
