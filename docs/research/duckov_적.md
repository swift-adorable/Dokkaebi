# 덕코프 — 적 (namu.wiki/w/Escape from Duckov/적) [확인됨]

## 1. 진영(팩션) 시스템
- 적들끼리 소속이 있어 같은 소속이 아니면 서로 싸운다.
- 먼저 어그로를 끈 대상이 있으면 자기가 공격당해도 그 대상을 먼저 처치하려 한다.
- 늑대 / 보행 버섯 / 기계 거미 / 폭풍 생물 = 전용 진영. 플레이어 포함 모든 생명체 적대.
- → 뒤통수 노리기, 서로 죽고 남은 전리품 루팅(어부지리)이 전술이 된다.
- 자동 터렛은 용병 진영 소속이라 용병은 쏘지 않지만 타 세력 적은 쏜다.

## 2. 전리품(시체) 구조
- 모든 적은 최소 8칸 컨테이너를 남긴다. 외형이 적마다 다르다(통닭/포대자루/금속 큐브/수트케이스).
- 전리품은 **들고 이동 가능**. 들고 있으면 달릴 수 없고, 구르면 그 자리에 떨어뜨린다.
- 활용: 무거운 물건을 넣어두고 이동 → 전투 시 내려놓아 과중 해제 / 철수 지점 근처에 미리 쌓아두기.

## 3. 일반 개체 — 역할 분담
| 적 | 역할 | 핵심 기믹 |
|---|---|---|
| 폭주 넝마꾼 | 근접 돌진 | 공격 직전 **붉은 빛 텔레그래프** → 구르기로 회피 |
| 넝마꾼 | 기본 원거리 | 정면 시야는 넓고 **측·후방 시야는 좁다** → 잠입 가능 |
| 넝마꾼(강화) | 중반 이후 | 머리 위 **별 표시**, 더 좋은 무기/방탄복 |
| 늑대 | 최약체 근접 | 피격 시 수직으로 꺾는 회피, 장애물 우회 추적 집요 |
| 용병 | 정예 원거리 | 시야·청력 우수, 멀리까지 추적, 2~5마리 무리 |
| 방랑자 | 후반 정예 | 고연사·투척물, **발소리를 내지 않는다**, 고관통탄 |
| 보행 버섯 | 탄막 | **비 올 때만 스폰**, 8방향 3발 포자, 포자는 헤드샷 판정 |
| 기계 거미 | 야간 위협 | **밤 22~06시 스폰**(낮에도 안 사라짐), 3점사×2~4회, 무한 추적, 피격 시 회피 무빙 |
| 폭풍 생물 | 환경 위협 | **폭풍 중에만**, 4발 3점사 + 무빙샷 + 구르기 회피 |

## 4. 환경 조건부 스폰 [핵심]
- 비 → 보행 버섯 / 밤 → 기계 거미 / 폭풍 → 폭풍 생물
- "무엇을 만나는가"가 시간·날씨로 바뀐다. 구역 자체는 그대로다.

## 5. 속성 상성 (폭풍 생물 예시)
- 물리 피해 = 적게 받음 / 전기 = 온전히 받음 / 화염 = **추가 피해**
- 방어력이 없으므로 철갑탄은 무의미 → **관통 축과 속성 축이 분리되어 있다**
- 후반 구역이 "속성 무기 강제"가 되는 방식

## 6. 조건부 드랍
- 폭풍 벌레 / 광산장: **치명타가 아닌 공격으로 처치해야** 특정 아이템을 떨군다.
- 보스는 고정 드랍 + 확률 드랍을 함께 가진다.
- 용병은 확정 인식표 + 많은 현금.

## 7. 기타 설계 포인트
- 자동 터렛: 정면 장갑판은 무적에 가깝고 **측·후면 본체는 취약**. 해킹 장치로 무력화 가능.
- 보스 라이트맨: 전투 도끼 피해 40 (플레이어 체력 대비 매우 큼)
- 방랑자 서바이벌/극한 기준 90 HP
- 축구 주장/팀원 이동 계수 1.24
- 약한 보스(라이트맨)는 수트케이스가 아니라 잡몹과 같은 전리품을 남긴다 = 등급 표현
