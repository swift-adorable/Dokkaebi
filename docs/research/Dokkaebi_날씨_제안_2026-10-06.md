**하룻밤 쉬기 [제안]** — 덕코프의 침대 자리. 거점에서 하룻밤 쉬면 **날씨를 다시 뽑고 달이 한 칸 돈다.** 쉬는 동안 수분 · 에너지는 줄지 않는다 (덕코프 그대로). → 궂은 날 Ⅱ는 사실상 **골라서 들어가는 날**이 된다 (덕코프 폭풍도 자고 넘긴다) — 그래서 **궂은 날에만 나오는 것 · 얻는 재료**가 있어야 들어갈 이유가 생긴다 (덕코프 폭풍 생물 · 폭풍 결정 자리).

## 2. 효과 · 피해 — 시뮬레이션 결과

- 하룻밤 쉬고 다시 뽑기 있음: 맑음 5.0판 · 흐림 3.2판 · 비 · 눈 2.5판 · 궂은 날 Ⅰ 1.3판 · 궂은 날 Ⅱ 0.0판 — 한 장에서 궂은 날 Ⅱ를 한 번이라도 만날 확률 3%

**읽는 법 · 결론**

- **한파** — 덕코프 추위 중첩 효과를 그대로 쓰고, 쌓이는 속도만 정했다: **방한이 1단계 모자라면 15분에 100중첩**(그때부터 동상). Ⅰ을 막이 없이 가면 15분 판은 버티지만 그 뒤엔 동상이 시작된다 → **화로 · 모닥불**에 30초 쬐면 다시 0 (5-1의 지방 화로와도 맞는다). Ⅱ는 7.5분 — 화로를 한 번 들르거나 방한 1을 챙겨야 한다
- **흙비** — 덕코프 폭풍의 「막이 단계」 구조 그대로, 피해 간격만 정했다: **1단계 모자라면 18초마다 1**(15분에 체력 50 · 소환단 4회), **2단계 모자라면 2.5초마다 1**(4분이면 쓰러짐). 덕코프 교란(0.5초마다 중첩당 1)보다 훨씬 약하다 — 모바일 · 첫 장(2장)이라서
- **폭염** — 수분 소모 **Ⅰ ×1.6 · Ⅱ ×2.4**(서늘함 한 단계마다 한 칸씩 내려간다). 15분 판에 샘물 2 / 3개. 마시지 않으면 10분 / 7분 만에 덕코프 「탈수」(회복 −70% · 이동 −20%)
- **짙은 안개** — 덕코프 밤의 짜임 그대로 [제안]: **내 시야 Ⅰ ×0.7 · Ⅱ ×0.45**(밝히기 한 단계마다 한 칸 회복) · **적 반응 시간 ×1.5**(덕코프 「야간 반응 시간 계수」 그대로 — 양날)
- **막이 얻는 곳** — 덕코프처럼 장비 한 부위 +0.5 ~ +1 · 소모품 +1(60 ~ 180초). 이름 · 위치는 [미정]: 방한(털 배자 · 남바위 · 막걸리) · 막이(탈 · 면포) · 서늘함(삿갓 · 모시 · 얼음물) · 밝히기(청사초롱 · 남포등 · 횃불)
- **비 · 눈 칸**은 수치 효과를 두지 않는다 — 덕코프 비도 「그때만 나오는 것」만 바꾼다 (시야를 줄인다는 수치는 찾지 못했다)

## 3. 달 — 여섯 [제안]

**달은 판마다 한 칸 돈다** (삭 → 초승달 → 상현달 → 보름달 → 하현달 → 그믐달 → 삭 …, 6판에 한 바퀴). 하룻밤 쉬어도 한 칸 돈다. 파밍 전 화면에 보인다 — **기다리면 원하는 달이 온다** (덕코프의 시간 흐름 자리).

| 달 | 밝기 = 적 시야 배율 | 무엇이 바뀌나 | 근거 |
|---|---|---|---|
| **삭** | ×0.45 | 무주귀 추가 · 순라귀 정지 — **지금의 「그믐」 그대로** (이름만 삭으로) | 달이 없는 밤 · 기존 결정 2-20~2-23 |
| 초승달 | ×0.7 | 달이 차오른다 — 잡귀 −10% | [제안] 차는 달 = 이야기가 살아나는 쪽 |
| 상현달 | ×0.85 | — (기준에 가깝다) | |
| **보름달** | **×1.25** — 서로 멀리 본다 | 잡귀 −20% · 대신 적이 일찍 알아챈다 | 대보름 달집태우기 · 액막이 풍속 [확인 필요] |
| 하현달 | ×0.85 | — | |
| 그믐달 | ×0.7 | 달이 기운다 — 잡귀 +10% | [제안] 기우는 달 = 잊힘 쪽 |

- 달은 **적의 눈**을, 짙은 안개는 **나의 눈**을 바꾼다 — 둘이 겹쳐도 같은 수치를 두 번 깎지 않는다
- 「큰물」은 여름 비 칸(장마비 — 수귀 추가 · 감전 2배)으로, 「독안개」는 3장 지형 또는 여름의 다른 궂은 날 후보로 옮긴다 (결정 2-60의 「달 + 날씨」)

## 4. 정해 주실 것

1. **궂은 날 Ⅱ를 「쉬고 넘길 수 있게」 할지** (덕코프 그대로) — 그러면 Ⅱ 전용 보상이 필요하다
2. 쌓이는 속도 · 피해 간격 목표(위 [가정])가 맞는지 — 「Ⅰ = 15분에 체력 50」 「Ⅱ = 몇 분 안에 돌아와야」
3. 달 여섯의 효과 — 특히 초승 · 상현 · 하현 · 그믐달을 「밝기만」 둘지, 무엇이 나오는지까지 나눌지
