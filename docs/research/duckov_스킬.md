## 2. 【핵심 원리 ①】 재료가 계열의 정체성을 말한다

| 계열 | 무엇을 바치는가 |
|---|---|
| 낚시 | **물고기** (갈색 정어리, 레드 골드피쉬, 보라 자라돔, 녹색 가시복어…) |
| 피지컬 강화 | **음식과 주사약** (탄산수, 코코아 우유, 감자, 케첩, 꿀, 위스키, 버섯 / 회복·열혈·근접 주사약) |
| 해킹 | **전자부품** (플로피 디스크, 무전기, CPU, 그래픽카드, 램, M.2 SSD, 회로 기판, 스마트폰) |
| 창고 | **상자** (플라스틱 통, 금속 통, 소/중/대형 확장 상자) |
| 농장 | **볼트와 너트** |
| 블랙마켓 | **정보** (연락 노트, 암호화 USB, 정보 파일, 신문, 노트, 책) |
| 설계도 연구 | **무기 설계도** (기본 / 고급 / 베테랑) |
| 이상한 개조 | **파란 큐브** — 이 계열 전용 |
| 작업대 | **만들려는 바로 그 물건** |
| 스킬 강화 | 코어 조각 + 잡템 + **완성 장비** |

**무엇을 바치는지가 그 갈래가 무엇인지 가르친다.** 설명문을 읽지 않아도 안다.
이것이 이 게임 퍽 설계에서 가장 배울 만한 점이다.

## 3. 【핵심 원리 ②】 게이트가 계열마다 다르다

- **레벨 게이트** — 스킬 강화(1~40)만 제대로 쓴다. 블랙마켓·창고·생존은 약하게.
- **돈 게이트** — 설계도(최대 150만), 창고(최대 50만).
- **재료 게이트** — 해킹·농장은 **비용이 1,000으로 고정**이다. 돈은 장식이고 부품이 진짜 문.
- **아이템 전용** — 피지컬 강화는 **크레딧을 한 푼도 쓰지 않는다.** 뿌리 2칸은 아예 「무료」.

계열마다 다른 문을 두면 "지금 뭘 팔 수 있나"에 따라 **팔 갈래가 달라진다.**

## 4. 【핵심 원리 ③】 작업대 — 만들려면 먼저 바쳐야 한다

```
방어구 제작 Ⅰ   기본 방어구 제작 해제   Lv.3 방탄복 ×1 · 특공대 헬멧 ×1 · 여행 가방 ×1
방어구 제작 Ⅱ   중급 방어구 제작 해제   Lv.4 방탄복 ×1 · SightPRO 헬멧 ×1 · 생존자 가방 ×1
철갑탄 제조     철갑탄 제조 해제        S/AR/L-철갑탄 ×30 · 철갑 산탄·저격탄·MAG ×8
```

**만들 수 있게 되려면 그 물건의 견본을 바친다.** 규칙이 한 줄로 설명되고, 파밍 목표가 명확해진다.

## 5. 【핵심 원리 ④】 상위 퍽이 좋은 장비를 먹는다

```
가방 마스터 Ⅱ    가방 공간 +6   Lv.17   17,000 · 콜드 조각 ×9 · 레드 조각 ×3 · 군인 배낭 MAX ×1
전방위 방어 Ⅰ    머리+0.2 신체+0.15   Lv.13   10,000 · SightPRO 헬멧 ×1 · Lv.4 방탄복 ×1
강화된 늑골      신체 방어구 +0.25    Lv.27   43,000 · Lv.5 방탄복 ×1 · 가속기 ×2 …
총기 그랜드마스터 대미지+7% 헤드샷+7%  Lv.28   47,000 · MCX Spear ×1 · MP-155 ULTIMA ×1 · 연사 활 ×1
대수집가         펫 가방 용량 +2      Lv.40   88,888 · 대수집가의 증명 ×1
```

→ *"이 Lv.5 방탄복을 입고 나갈까, 녹여서 영구 강화에 쓸까"*
추출 루팅 게임에서 이보다 강한 결정은 많지 않다.

계열 하나(스킬 강화)의 **누적 총 비용 807,738**. 각 칸이 자기 비용과 **누적 비용을 함께 표시**한다.

## 6. 【핵심 원리 ⑤】 이상한 개조 — 방어를 사야 대가를 살 수 있다

```
단열 Ⅰ / 절연 Ⅰ / 방독 Ⅰ     받는 화염·전기·독 대미지 −0.05     2,000 · 파란 큐브 ×100
  └ 영혼 모듈 Ⅰ               받는 공간 대미지 −0.05             3,000 · 파란 큐브 ×200
      └ 대미지 모듈 Ⅰ형        총기 헤드샷 +8%   최대 생명력 −1   5,000 · 파란 큐브 ×300
      └ 피지컬 모듈 Ⅰ          근접 대미지 +8%   최대 생명력 −1   5,000 · 파란 큐브 ×300
          └ 대미지 모듈 Ⅱ형     총기 대미지 +8%   최대 생명력 −1   10,000 · 파란 큐브 ×500 …
          └ 피지컬 모듈 Ⅱ       근접 치명타 +8%   최대 생명력 −1
```

앞쪽 8칸은 **순수 방어**, 뒤쪽 4칸은 **전부 대가 있는 강화**다.
그리고 방어 모듈이 대가 모듈의 **선행**이다 — 먼저 단단해진 뒤에야 체력을 깎는 거래가 열린다.
전용 재료 「파란 큐브」를 100~500개 요구한다.

우리 Skill_System의 **「대가(CostType)」 철학과 정확히 같은 구조**다.

## 7. 그 밖의 구조

- **설계도 연구**는 무기 사슬이다 — 글록 → 수제 사냥총 → MP155 / AK74U → AK-47 → AK102 → RPK → MF → VPO.
  레벨 요구가 없고 오직 돈과 설계도 등급. 최상위 VPO는 **150만 + 설계도 8장.**
- **블랙마켓**은 통신 ↔ 확장이 서로 선행이다. 지그재그로 번갈아 올라간다.
- **창고 확장 17칸이 전부 「창고 용량 +n」** 하나다. 고민할 것이 없는 갈래를 일부러 둔 것으로 보인다.
- **해킹·작업대는 수치가 거의 없고 전부 해금형**이다.
- **연구 시간** 3~5초. 사실상 연출이며 게이트로 쓰이지 않는다.

## 8. 전투 수치에 대한 사실 [확인됨]

**스킬 강화 44칸 중 가방 6칸·펫 4칸을 뺀 34칸이 전투 수치다.**
머리/신체 방어구, 총기 대미지·헤드샷·반동·탄퍼짐·재장전, 시야·야간·감지, 최대 생명력.

**피지컬 강화 36칸 중 약 20칸이 전투 수치다.**
이동 능력, 근접 대미지·치명타율·치명타 대미지, 체력.

## 9. Blob에 가져올 것

| 가져옴 | 이유 |
|---|---|
| **재료가 계열의 정체성** | 무엇을 바치는지가 그 갈래가 무엇인지 가르친다. 설명문이 필요 없어진다 |
| **계열마다 다른 게이트** | 레벨 / 돈 / 재료 / 무료. 지금 가진 것에 따라 팔 갈래가 달라진다 |
| **만들려면 견본을 바친다** | 작업대 규칙. 파밍 목표가 한 줄로 서고 규칙이 직관적이다 |
| **상위 퍽이 완성 장비를 먹는다** | "입고 갈까, 녹일까". 추출 루팅의 결정을 성장에 직결한다 |
| **대가 있는 강화 + 방어 선행** | 순증과 교환을 구분하고, 교환을 후반에 연다 |
| **누적 총 비용 표시** | 갈래를 끝까지 팔지 미리 판단할 수 있다 |
| **고민 없는 계단 갈래 1개** | 전부 결정이면 피로하다 |
| **해금형만의 계열** | 수치가 없는 계열이 있어야 성장이 단조롭지 않다 |

| 안 가져옴 | 이유 |
|---|---|
| 163칸 규모 | 무기·방어구 에셋이 아직 없고 상인·제작·창고가 전부 미구현 |
| 펫(강아지) 4칸 | Blob에 없다 |
| 수분·에너지·허기·낚시·농장 | Blob에 없다 |
| 연구 시간 | 3~5초라 연출일 뿐 |
| 근접 계열 | Blob은 총기 중심이다 |
