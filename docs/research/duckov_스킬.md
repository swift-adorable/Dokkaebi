# 덕코프 조사 — 스킬 (패시브)

> 출처: 나무위키 「Escape from Duckov/스킬」 (최종 수정 2026-06-19) 직접 열람
> 조사일: 2026-09-18

## 0. 이 문서의 신뢰도 — 먼저 읽을 것

**나무위키 문서 자체가 미완성이다.** 이 사실을 모르고 인용하면 설계가 후퇴한다.

| 구간 | 상태 |
|---|---|
| 스킬 강화 | **3칸만** 적혀 있음 |
| 신체 단련 | 3칸, **해금레벨 전부 `-`** |
| 생존 스킬 | 12칸, **해금레벨 전부 `-`** |
| 이상한 개조 | **표가 통째로 비어 있음** |
| 블랙마켓 업그레이드 | 9칸, 해금레벨 열 자체가 없음 |

그런데 유저가 제공한 게임 내 스크린샷에는 위키에 없는 항목이 다수 있다 —
가방 전문가 2, 신속 장전 1, 예리한 감지 1, 서바이벌 본능 2, 머리 방어력, 호크아이, 애견 훈련사 1.

**→ 스크린샷이 위키보다 최신이다.** 위키는 【구조】의 근거로만 쓰고,
【항목】은 스크린샷과 우리 설계로 채운다.

## 1. 계열 구조 [확인됨]

문서의 목차가 곧 계열이다. 5개다.

| # | 계열 | 성격 | 해금 조건 |
|---|---|---|---|
| 2 | **스킬 강화** | 가방·생명력·시야 — 몸의 기본기 | 해금레벨 (계정 레벨) |
| 3 | **신체 단련** | 이동·근접 피해·스태미나 | 표에 `-` (불명) |
| 4 | **생존 스킬** | 수분·에너지 소모, 낚시, 제작 해금 | 표에 `-` (불명) |
| 5 | **이상한 개조** | — | **탐험. 숨은 상인 조우** |
| 6 | **블랙마켓 업그레이드** | 상점 새로고침 | 해금레벨 열 없음 |

**단일 트리가 아니라 독립된 5갈래다.** 이것이 가장 중요한 구조적 사실이다.

## 2. 표의 열 구성 [확인됨]

```
이미지 | 스킬 | 해금레벨 | 필요물품 | 획득 | 선행스킬
```

**「필요물품」 열이 있다.** 현재 모든 행이 `-`지만 열이 존재한다는 것은
**스킬 해금에 아이템을 요구하는 설계**라는 뜻이다.
크레딧만 쓰는 구조가 아니다. → 파밍과 성장이 직접 연결된다.

블랙마켓만 열 구성이 다르다 — `해금레벨`이 없고 `필요물품 / 획득`만 있다.
**레벨과 무관하게 돈이나 물건으로만 연다.**

## 3. 원문 표 (옮김)

### 3-1. 스킬 강화 [확인됨]

| 스킬 | 해금레벨 | 필요물품 | 획득 | 선행스킬 |
|---|---|---|---|---|
| 가방 전문가 I | 1 | - | 가방 공간 +4 | - |
| 생존 본능 I | 1 | - | 최대 생명력 +5 | 가방 전문가 I |
| 넓은 시야 I | 1 | - | 시야 각도 +15 | 가방 전문가 I |

> 뿌리 1개에서 둘로 갈라진다. 스크린샷의 트리도 같은 모양이다.

### 3-2. 신체 단련 [확인됨 — 해금레벨은 불명]

| 스킬 | 획득 | 선행스킬 |
|---|---|---|
| 하이니즈 달리기 | 이동 능력 +2% | - |
| 팔굽혀펴기 I | 근접데미지 배율 +5% | - |
| 줄넘기 | 체력 +4 | 하이니즈 달리기, 팔굽혀펴기 |

> **선행이 2개다.** 두 뿌리가 하나로 합류하는 구조가 존재한다.

### 3-3. 생존 스킬 [확인됨 — 해금레벨은 불명]

영양 관리 계통 (선행이 번호로 표기됨 — 같은 계통 내 참조)

| 스킬 | 획득 | 선행 |
|---|---|---|
| 영양 관리 1 | 수분 소모율 −0.9 | - |
| 영양 관리 2 | 에너지 소모율 −0.8 | 1 |
| 영양 관리 3 | 에너지 −0.4 / 수분 −0.4 | 2 |
| 영양 관리 4 | 에너지 소모율 −0.8 | 3 |
| 영양 관리 5 | 수분 소모율 −1 | 3 |
| 영양 관리 6 | 에너지 −0.5 / 수분 −0.5 | **4, 5** |

낚시 계통

| 스킬 | 획득 | 선행 |
|---|---|---|
| 낚시 기술 1 | 낚시 능력 +0.1 | - |
| 낚시 기술 2 | 낚시 능력 +0.1 | 1 |
| 낚시 숙련 | 낚시 운 +0.1 / 낚시 능력 +0.1 | 1 |
| 낚시 기술 3 | 낚시 능력 +0.1 | 2 |
| 식이요법 | 의료소에서 물고기로 주사기 제작 | **3, 영양 관리 3** |
| 낚시 운 | 낚시 운 +0.1 | 식이요법 |

> 두 가지가 중요하다.
> ① **다이아몬드형** — 3에서 4·5로 갈라졌다가 6에서 합류한다.
> ② **계통 간 교차 선행** — 「식이요법」이 낚시 3과 영양 관리 3을 동시에 요구한다.
>    한 갈래만 파면 닿지 않는 칸이 있다.
> ③ **해금형 보상** — 「식이요법」은 수치가 아니라 제작 레시피를 연다.

### 3-4. 이상한 개조 [확인 불가 — 표가 비어 있음]

본문만 있다:

> 창고 구역에서 지하실 열쇠를 사용하고 독가스 구역을 지나 갈림길에서
> 왼쪽 또는 오른쪽으로 간 후 지하실 갈림길 열쇠를 사용하면 만날 수 있는
> 수상한 상인에게서 업그레이드가 가능하다.

**해금 조건이 레벨도 돈도 아니고 「거기까지 갔는가」다.**
열쇠 2개 → 위험 구역 통과 → 상인 조우. 내용은 불명.

### 3-5. 블랙마켓 업그레이드 [확인됨]

| 스킬 | 획득 |
|---|---|
| 블랙마켓 통신 I~V | 새로고침 쿨타임 10% 감소 (각) |
| 정보용량 확장 I~IV | 새로고침 1회 증가 (각) |

> 두 줄이 번갈아 나온다 (통신 I → 확장 I → 통신 II → …).
> **같은 효과를 5단계로 반복하는 단순 계단.** 트리가 아니다.

## 4. 확인하지 못한 것 [확인 불가]

- 스킬 포인트가 있는지, 있다면 어떻게 얻는지 — 문서에 없음
- 초기화(리스펙) 가능 여부 — 문서에 없음
- 총 스킬 수 — 문서가 미완성이라 셀 수 없음
- 「필요물품」에 실제로 무엇이 들어가는지 — 전부 `-`
- 이상한 개조의 내용 전부

## 5. Blob 설계에 가져올 것

| 가져옴 | 이유 |
|---|---|
| **독립 5계열** | 단일 트리는 "위로 한 줄" 뿐이다. 계열이 갈리면 출격 성향이 갈린다 |
| **필요물품** | 파밍과 성장을 직접 연결한다. 크레딧만이면 시간만 쓰면 다 열린다 |
| **탐험 해금 계열** | 레벨이 아니라 「거기까지 갔는가」가 조건인 갈래 |
| **다이아몬드 · 교차 선행** | 한 갈래만 파면 닿지 않는 칸 → 순서에 결정이 생긴다 |
| **해금형 보상** | 수치가 아니라 「할 수 있게 되는 것」 (식이요법 = 제작 레시피) |
| **계단형 단순 계열** | 블랙마켓처럼 트리가 아닌 반복 강화 갈래도 하나쯤 있어야 한다 |

| 안 가져옴 | 이유 |
|---|---|
| **신체 단련 계열 통째로** | 최대 생명력·근접 피해·이동 능력은 **전부 장비의 축**이다. (확정 기획) |
| **생존 본능(최대 생명력) · 넓은 시야** | 같은 이유 |
| **수분/에너지 소모** | Blob에는 허기·갈증이 없다 |
| **낚시** | 없다 |

> 덕코프가 전투 수치를 패시브로 주는 것은 장비 옵션이 우리보다 단순해
> 겹침이 문제가 되지 않는 구조이기 때문이다. Blob은 장비에 25종 옵션이 있으므로
> 그대로 따르면 장비를 고를 이유가 사라진다. (확정 기획 — 패시브는 전투 수치를 주지 않는다)
