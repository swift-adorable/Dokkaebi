# 덕코프 — 장비 / 아이템 / 소모품 [확인됨, namu.wiki]

## 1. 장비 슬롯 (6종 + 토템 2)
| 슬롯 | 개수 | 역할 | 내구도 |
|---|---|---|---|
| 머리 방어구 | 1 | 머리 방어 수치 + 시야/청각 트레이드오프 | 22~94 |
| 신체 방어구 | 1 | 신체 방어 + **가방 공간 제공** | 45~180 |
| 얼굴 | 1 | 시야/감지/야간투시 | 일부만 |
| 이어폰 | 1 | 청각, 소리로 위치 파악 | 없음 |
| 가방 | 1 | 최대 소지 중량 + 가방 공간 (별도 축) | 없음 |
| **토템** | **2** | 순수 스탯 빌드 슬롯 | 없음, 전부 0.3kg |

**방어구 슬롯이 인벤토리 슬롯을 겸한다.** 최고 티어일수록 가방 공간이 줄어든다
(6레벨 방탄복 +2, 5레벨 중형 0). 방어 최대화 = 파밍량 최소화.

신체 방어구는 같은 레벨 안에 **일반 / 작전(수납↑) / 중형(내구↑·수납 0)** 3변형.

## 2. 내구도
- 최대 내구도의 **33% 이하**로 떨어지면 주황색 + 성능 하락
- **수리해도 최대 내구도까지 회복되지 않는다** → 반복 수리 시 결국 폐기 (경제 싱크)
- 상인 판매가 = 기본 가격의 50%

## 3. 토템 — 등급 문법이 핵심
- 2슬롯. 종류와 단계가 **모두** 같으면 중복 불가 (감지 II + 감지 III 는 가능)
- **사망해도 유실되지 않는다** (근접 무기도 동일) → 영구 진행 레이어
- 흐릿한 깃털 8개 → 토템 1개

**등급 문법 A (일반 토템): I·II는 순수 강화, III부터 반드시 디메리트**
  - 공격 III: 총기 피해 +0.25, **사거리 계수 -0.15**
  - 민첩 III: 이동 +15%, **3.3초당 HP 1 감소**
  - HP III: 최대 HP +25, **이동 -10%**
  - 회복 III: 10초당 HP 10, **에너지·수분 소모 +30%**
  - 열광 III: 근접 치명타율 +280%, **근접 피해 -10%**
  → 하위 티어를 쓰는 선택이 유효하게 남는다

**등급 문법 B (저항 토템): I = 수치 감소 / II = 상태이상 면역 / III = 면역 + 수치**
  - 화염 저항 I 내성 -12% → II 점화 면역 → III 점화 면역 + 내성 -8%
  → II에서 질적 도약이 일어나 II와 III 사이에 취향 선택이 생긴다

## 4. 세트 효과 = 누적 수치 게이트 (올 오어 낫싱 아님)
- 폭풍 방어 1 → 1단계 폭풍 차단 / 폭풍 방어 2 → 2단계 차단
- 공간 방호 헬멧(+1) + 주사기(+1) = 2단계 차단 → **장비 1 + 소모품 1 조합이 성립**
- 고무 작업복은 몸통 단독으로 바닥 전류 무효 (세트 불필요)

## 5. "강한 장비는 반드시 대가" — 4개 축 (무게 / 감각 / 수납 / 속성 취약)
| 장비 | 얻는 것 | 대가 |
|---|---|---|
| 신의 용접 헬멧 | 머리 +6 (최고) | 시야각 -30%, 3.6kg |
| 바리케이드 헬멧 | 머리 +4, 헤드샷 +0.05 | **시야각 -70%**, 3.8kg |
| 왕관 | 방어 +1, 근접 +0.1, 헤드샷 +0.1, 폭풍 +1 | **무게 21.7kg**, 5속성 내성 전부 -0.1 |
| 눈가리개 | 감지 +4.5, 야간 +1, 근접 +10% | **시야 거리 -900%** (N키 토글) |
| 5레벨 중형 방탄복 | 내구도 180 (최고) | 8.6kg, **가방 공간 0** |
| 구루 방탄복 | 방어 +6, 폭풍 +1, 가벼움 | 내구도 70 (6티어의 절반 이하) |

## 6. 가방 — 중량 축과 공간 축의 분리
| 가방 | 소지 중량 | 가방 공간 |
|---|---|---|
| 파리 날개 (0.4kg) | **+35** | +10 |
| 전술 가방 MAX | +30 | +30 |
| 구루 | +20 | +5 |
| 빌리 | +10 | +15 |
→ "무거운 것을 들 수 있는가"와 "많이 넣을 수 있는가"가 별도 자원.
   가방 선택이 파밍 타깃(고가 중량물 vs 다수 소형물)에 따라 갈린다.

## 7. 소모품
- 회복량 ↔ 사용 시간 반비례: 붕대는 약하지만 빠르고 출혈 확정 제거,
  대형 구급상자는 HP 35씩 10회지만 **전투 중 사용 불가**
- **모든 버프가 수분/에너지를 태운다.** 강한 음식일수록 수분을 더 태움
  (꿀 +에너지100/-수분60, 영혼의 밀주 +50/-100)
- 근접 주사약: 30초 강화 뒤 **60초 쇠약** — 페널티 시간이 강화 시간보다 길다
- 공간 폭풍 방호 주사: 공간 방호 +1, 120초

## 8. 상태이상과 해제 수단
| 상태이상 | 해제·면역 |
|---|---|
| 출혈 | 붕대(확정), 구급상자(내구 추가 소모), 지혈 주사, 물리 저항 토템 I/III |
| 중독 / 점화 / 감전 / 파열 | 각 저항 토템 II 이상에서 **면역** |
| 공간 교란(1단계) / 왜곡(2단계) | 폭풍 방어 1 / 2 수치 게이트 |
| 기절(섬광) | 검은 안경·선글라스에 숨은 면역 |
| 골절 / 상처 | **광폭화 난이도에서만 존재** — 뼈 고정판 / 수술 키트 |

→ **난이도 상승이 배율이 아니라 "상태이상 종류 추가"로도 이루어진다.**

## 9. 아이템 경제
- 명시적 희귀도 등급 라벨이 **없다**. 가격(1 ~ 2,159만)과 획득처 희소성으로 표현
- 컨테이너 안의 컨테이너: 주사기 수납백(6개), 열쇠 지갑(8개), 드럼통(물고기 5)
- 종이상자: 사용 시 위장 200초. 안 움직이면 미탐지, 발포 시 파괴
