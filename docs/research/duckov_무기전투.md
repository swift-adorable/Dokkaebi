# 덕코프 — 무기 / 부착물 / 제작 [확인됨, namu.wiki]

## 1. ★ 피해 계산 공식 (원문)
```
최종 피해 = 무기 피해 × 탄약 피해 계수 × 캐릭터 공격 보정
          × (1 / 발사 탄수) × 사거리 보정 × 치명타 배율
          × 난이도 보정 × 방어도 보정 × 속성 상성
```

### 1-1. 방어도 보정 = 2 / (max(a − b, 0) + 2)
  a = 방어구 방어도, b = 탄약의 방어구 관통 레벨

| 차이 (a−b) | 배율 |
|---|---|
| 0 이하 | **1.0** (무감쇠) |
| 1 | 0.667 |
| 2 | 0.500 |
| 3 | 0.400 |
| 4 | 0.333 |
| 5 | 0.286 |

- **이분 판정이 아니라 연속 감쇠.**
- 관통 ≥ 방어도이면 보정 1, **초과 관통은 아무 이득이 없다** → 필요한 만큼만 쓰는 탄약 경제
- 등급 한 단계 부족 = 약 -33%
- **피해량의 크기와 무관하다** → 저피해·다탄 빌드가 구조적으로 죽지 않는다

### 1-2. 사거리 보정
  거리 ≤ 사거리/2 → **1** / 사거리/2 초과 → **0.5** (계단식, 점진 감쇠 아님)
- 이 한 항이 거의 모든 무기·부착물 선택의 상위 제약이다
- 스코프가 사거리를 거의 안 늘리는 이유(8배율도 +10%),
  기관단총이 후반에 몰락하는 이유, "적 피해가 반감되는 거리에서 교전"이 정석인 이유

### 1-3. 치명타
  치명타 배율 = 총기 치명타 배율 + 탄약 헤드샷 버프
  헤드샷은 **별도 판정이 아니라 치명타 배율로만** 반영된다.
  근접 무기만 **확률 기반 치명타**(치명타율 스탯)를 가진다.

## 2. 탄종 (관통 레벨)
| 등급 | 관통 |
|---|---|
| 녹슨 | -1 |
| 일반 | 1 |
| 철갑 | 3 (저격/매그넘은 2) |
| 고급 철갑 | 5 (저격/매그넘은 4) |
| 특수 철갑 | 6 |

- 탄약은 **절대 피해값이 없고 피해 계수만** 가진다 (대부분 1.0, 특수탄만 1.1~1.4)
- 함정 설계: S-특수탄(관통 0), 특수 산탄(관통 -1)은 계수만 높고 관통이 낮아 "돈값 못함"
- 탄약은 **순차 정제 체인**: 녹슨 → 일반 → 철갑 → 고급 철갑 → 특수
  각 단계가 하위 탄 + 화약통 + 화약 + 금속 조각을 요구

## 3. 속성 = 스탯이 아니라 상성 축
| 대상 | 물리 | 전기 | 화염 | 독 |
|---|---|---|---|---|
| 폭풍 생물 | **0.66배** | 1.0 | **1.5배** | — |
| 기계류 | — | **2배** | — | **완전 면역** |

- 속성 무기는 원본과 스탯이 거의 같고 속성 + 디버프 확률이 추가된다
- 대신 **소모형 업그레이드**: 원본 무기가 재료로 사라진다
- 폭풍 생물은 방어력이 0이므로 철갑탄이 무의미 → **관통 축과 속성 축이 분리**

## 4. 부착물 — 거의 전부 명시적 트레이드오프
| 부착물 | 이득 | 대가 |
|---|---|---|
| 4배율 스코프 | 조준 거리 +1.36, 사거리 +5% | 수직 반동 **+70%**, 힙파이어 확산 +15% |
| 공격 강화 총구 | 피해 +10% | 반동 +10% |
| 소음기 | 소리 -75% | 사거리 -10%, 탄속 -10% |
| 연장 총구 | 사거리 +30% | 이동 -5%, 소리 +30% |
| 레이저-신속 | 조준 -20%, 사거리 +15% | **힙파이어 확산 +20%** |
| 대용량 탄창 III | 탄창 +150% | 조준 +20%, 이동 -5% |

- 페널티 없는 부착물(균형 소염기 A, 기동성 소염기, 평화의 별)은
  **수급처를 막아 희소성으로 밸런싱**한다
- 부착물 슬롯 수(0~6)가 곧 무기 티어를 가른다

## 5. 모듈 = 무기 성격 자체를 바꾸는 개조
  SKS 정밀(헤드샷·사거리↑ + 1명 관통) / Mosin 양각대(정밀↑, **조준 중 이동 불가**)
  / 큐브건 스마트(유도 추가, **확산 +1700%, 치명타 소멸**)
  / UZI(연사 대폭↓, **치명타 +120%**)

## 6. 근접 무기
- 총기와 **스탯 체계가 다르다**: 피해 / 공격 거리 / 속도 / SP 소모 / 관통 레벨 / 치명타율
- **사망해도 유실되지 않는 귀속 아이템** → 맨몸 + 근접만 든 노리스크 플레이 성립
- 벽 관통 공격 가능 (버그성). 동시 다중 타격 가능
- 이동속도 계수가 없는 근접무기는 거의 사장 → **이동 보너스가 실질 선택 기준**

## 7. 제작
- 설계도 → 연구 → 제작. 레시피는 기본 작업대, 청사진은 고급 작업대
- 재료는 3등급 체계 (무기 부품 / 중급 / 고급 + 오염된 부품)
- 방어구도 동일 (유기섬유 / 고급 / 최고급)
- **제작 가능 여부 = 유지보수 가능성.** 보스 드랍 전용 무기는 내구도가 발목을 잡는다
