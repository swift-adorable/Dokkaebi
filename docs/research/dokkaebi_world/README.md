# 도깨비의세계 공식 가이드 — 참고할 것만 거른 정리

> 출처: forum.kakaogames.com/dokkaebi 「가이드」 게시판 1~4쪽 (2026-10-07 갱신분, 테스트 환경 기준) · 조사 2026-10-13
> **우리 말로 줄여 적었다.** 원문 · 그림은 옮기지 않았고, 저쪽의 이야기 · 지명 · 인물 · 재화 이름은 하나도 들이지 않는다.
> 우리 게임의 바탕은 여전히 `Dokkaebi_Story_Script` 하나다 (Master_Prompt 규칙 9). 여기 적힌 것은 **화면 배치 · 조작 편의**만 참고한다.

## 0. 거른 기준

저쪽은 여러 사람이 함께하는 자동 전투 MMO이고, 우리는 혼자 하는 탈출 슈터다. 그래서 세 갈래로 나눴다.

| 표시 | 뜻 |
|---|---|
| **◎ 적용 후보** | 화면 배치 · 정렬 · 조작 편의. 이야기와 무관하고, 우리 화면에 그대로 옮겨 쓸 수 있다 |
| **○ 이미 있음** | 우리에게 같은 구실이 이미 있다 — 모양만 견줘 본다 |
| **✕ 들이지 않음** | 본문에 없는 콘텐츠 · 다인 · 유료 · 자동 전투 — 제안하지도 않는다 |

### 읽은 글 (20편)
주요 UI 소개 · 길라잡이 · 상인회 · 영석 상점 · 세계지도 · 업적 · 아이템 사전 · 화첩 · 유물 수집 · 제작 · 임무 · 보스토벌 · 비경 탐험 · 전래동화 · 칭호 · 설정 · 키 설정 · 도깨비 수련장 · 보물찾기 · 플래너

### 읽지 않은 글
- 다인 · 문파 · 순위 · 거래 · 사교: 문파(4편) · 문파 상점 · 문파 창고 · 낙화의 전장 · 낙화 순위 · 순위 · 협력 수련 · 거래소 · 구인구직 · 친구 · 우편함 · 승천의 탑
- 계정 · 유료 · 설치: 설치 · 쿠폰 · 로그인 · 보안 · 리모트 · 캐릭터 생성 · 미용실 · 의복 · 탈것 · 신수 · 묘롱
- 건드리지 않기로 한 화면(결정 2-119 — 가방 · 스킬 · 패시브): 가방 · 도술 · 가호 · 기운 발현 · 내면의 길 · 영기 수련 · 단 봉인해제 · 성장 · 내 정보
- 모아보기 · 도사 수행록(일일 숙제표)

## 1. 큰 화면 배치 (주요 UI 소개)

저쪽 메인 화면의 자리 나누기:

- 왼쪽 위: 미니맵 — 누르면 세계지도. 낮밤 · 자리 표시, 카메라 되돌리기 단추.
- 위 가운데 ~ 오른쪽 위: 재화 → 아이콘 줄(안내 · 상점 · 가방 · 메뉴). 「메뉴」 하나를 누르면 나머지 기능이 분류별로 펼쳐진다.
- 오른쪽 가운데: 임무 목록(세로로 쌓임).
- 오른쪽 아래: 기본 공격 · 스킬 칸 · 회피(충전 2회).
- 아래 가운데: 체력 · 물약.

| | 우리에게 |
|---|---|
| ◎ | **메뉴 하나로 모으기** — 자주 쓰는 것 몇 개만 아이콘으로 꺼내 두고 나머지는 「메뉴」 안에 분류해 넣는다. 우리 HUD가 늘어날 때 쓸 수 있다 |
| ◎ | 미니맵 왼쪽 위 · 퀘스트 목록 오른쪽 — 결정 2-119 참고 그림과 같다. **지금 우리 미니맵은 오른쪽 위**(MinimapUI)라 옮길지 물어볼 것 (아래 5절) |
| ○ | 대시(재사용 대기) · 체력 · 빠른 칸 — 이미 있다. 저쪽의 「충전 2회」 방식은 들이지 않음 |
| ✕ | 자동 전투 · 프리셋 · 전투력 숫자 · 채팅 · 집결 — 들이지 않음 |

## 2. 가게 · 상점

### 상인회 (글 7988)
- 「상인회」는 따로 열리는 창이 아니라 **상인이 모여 있는 거점으로 데려다 주는 단추**다.
- 상인마다 맡은 일이 하나씩 정해져 있다: 잡화 · 강화 · 제작 · 창고 · 외형 · 교환소 …
- 상인 자리는 세계지도에 표시된다.

| | 우리에게 |
|---|---|
| ○ | **상인 한 명 = 일 하나** — 우리도 이미 그렇다 (잡화 영감 · 대장간 빚쟁이 · 약탕간 참봉 · 장부방 길달, 결정 2-52 · 2-57) |
| ◎ | **벙커 지도에 상인 자리 · 하는 일 아이콘** — 벙커 안에서 누가 어디 있는지 지도에 표시 |
| ✕ | 상인 수 늘리기 · 외형 · 환전 — 본문에 없음 |

### 영석 상점 (글 8005) — 유료 상점
- 탭 줄(멤버십 · 꾸미기 · 지원 · 재화 · 마일리지 · 보관함 · 장바구니).
- **장바구니**: 여러 물건을 담아 두고 한 번에 산다 · 목록에서 빼기.

| | 우리에게 |
|---|---|
| ◎ | **위쪽 탭으로 품목 나누기** — 상인 하나가 여러 갈래(무기 · 방어구 · 가방)를 팔 때 탭으로 가른다. 대장간에 바로 맞다 |
| ◎ | **담아 두고 한꺼번에 사기 + 「합계」** — 참고 그림 아래쪽 「합계」 칸과 같은 생각. 여러 줄을 고르고 합계를 본 뒤 한 번에 산다 |
| ✕ | 유료 재화 · 멤버십 · 마일리지 · 보관함 — 들이지 않음 |

### 제작 (글 7911)
- 왼쪽: 갈래 탭(무기 · 방어구 · 장신구 · 잡화) + 목록, 별표로 즐겨찾기.
- 오른쪽: 고른 것의 **필요 재료(가진 수 / 필요 수)** · 결과물 능력치.
- 재료 아이콘을 누르면 **어디서 얻는지 · 어디에 쓰는지**.
- 재료가 다 모이면 「제작 시작」이 켜진다.

| | 우리에게 |
|---|---|
| ◎ | **필요 재료를 「가진 수 / 필요 수」로, 모자라면 붉게** — 우리 요리 · 약 달이기 · 건물 짓기 화면(CookingUI · ApothecaryUI · BuildingScreenUI)에 같은 줄 모양을 쓸 수 있다 |
| ◎ | 조건이 차야 켜지는 단추 · 안 켜지면 이유 한 줄 |
| ✕ | 대성공 확률 · 게이지 — 본문에 없음 |

## 3. 지도

### 세계지도 (글 7903)
- 들어가는 길 두 가지: 메뉴 · **미니맵 누르기**.
- 지도 위에 있는 것: 지금 장소 이름 · 내 자리 · **상점 / 창고 / 임무 자리 아이콘** · 확대·축소 막대 · **「내 자리로」** 단추 · 날씨.
- 오른쪽 칸 탭: 검색 · 지역 목록(지역 누르면 그 안의 인물 · 사냥터) · 진행 중 임무와 그 장소 · 즐겨찾기 · **자리 저장(최대 10)** · 추천 사냥터.
- 지역마다 거리 표시 + 「걸어가기」 / 순간이동.

| | 우리에게 |
|---|---|
| ○ | 미니맵 누르면 전체 지도 · 확대 막대 · 내 자리로 · 날씨 · 퀘스트 구역 표시 — **이미 있다** (WorldMapUI, 결정 2-90 · 2-94) |
| ◎ | **오른쪽에 「진행 중 퀘스트 → 그 자리」 목록**, 누르면 지도가 그곳으로 옮겨 간다. 지금 우리는 왼쪽 줄의 「목표로」 하나뿐 |
| ○ | 내 마커 목록의 거리 표시 — **이미 있었다** (결정 2-94 「◆1 23m」) |
| ◎ | 벙커 · 장 지도에 **상점 · 창고 · 퀘스트 주는 사람 아이콘** (위 상인회와 같은 것) |
| ✕ | 검색 · 추천 사냥터 · 순간이동 · 자동 걸어가기 · 파티 위치 — 우리 지도 규칙(가 보지 않은 땅은 어둡다 · 적을 그리지 않는다, Map_System 4절)과 맞지 않거나 본문에 없음 |

### 보물찾기 (글 7930) — 지도에 붙는 부분만
- 장소별로 「찾은 수 / 전체 수」를 보여 주고 다 찾으면 표시. 가까이 가야 지도에 아이콘이 뜬다.

| | 우리에게 |
|---|---|
| ◎ | **장 지도에 「찾은 길목 n / 전체」 같은 진척 숫자** — 숫자만. 무엇이 어디 있는지는 드러내지 않는다 |
| ✕ | 보물 상자 콘텐츠 자체 — 본문에 없음 |

## 4. 목록 화면 공통 (업적 · 아이템 사전 · 화첩 · 유물 · 칭호 · 임무)

여섯 글이 거의 같은 틀을 쓴다:

1. 왼쪽 세로 탭: **즐겨찾기** + 갈래들.
2. 가운데 목록: 이름 · 조건 · 보상 한 줄씩. 정렬 · **거르기(전체 / 진행 중 / 받을 수 있음 / 끝남)** · 검색.
3. 오른쪽: 고른 것의 자세한 정보 + **진척률(n / 전체, %)**.
4. 받을 것이 있으면 **「모두 받기」 / 「모두 등록」** 한 번에.
5. 각 줄의 「이동하기」로 해당 장소 · 화면으로 바로 간다.

| | 우리에게 |
|---|---|
| ◎ | **거르기(진행 중 / 끝남) + 갈래별 「n / 전체」** — 퀘스트 창(QuestScreenUI)과 업적(도감 탭의 「업적 n / 54」)에 바로 쓸 수 있다. 업적은 54개라 거르기가 없으면 길다 |
| ◎ | **숨은 업적은 「???」로 자리만 보이기** — 저쪽 「숨겨진 업적」 구분 |
| ◎ | 아이템 상세의 **「어디서 얻나 · 어디에 쓰나」** 두 줄 — 지금 우리 아이템 상세에 없다. 표(ShopTable · 요리 · 약 · 건물)에서 거꾸로 찾아 채울 수 있다. 다만 가방 상세 화면을 건드리는 일이라 **결정 2-119와 겹친다 → 물어볼 것** |
| ✕ | 화첩 · 유물 · 칭호를 모아 능력치 얻기, 업적 보상 상자 · 스티커 — 본문에 없음 |

## 6. 가게 · 상점 · 지도 화면에 바로 쓸 것 — 결과 (결정 2-120)

| # | 항목 | 결과 |
|---|---|---|
| 1 | 참고 그림 배치(왼쪽 목록 · 오른쪽 상인) | 지금 화면을 보고 사용자가 정한다 — 보류 |
| 2 | 위쪽 탭으로 품목 나누기 | **했다** — 종류로 저절로, 하나뿐이면 감춘다 |
| 3 | 담아 두고 합계 보고 한 번에 사기 | **했다** — 담기 · 빼기 · 비우기 · 한꺼번에 사기(전부 아니면 전혀) |
| 4 | 모자라면 붉게 · 이유 한 줄 | **했다** — 칸의 값 · 합계 · 「n 모자랍니다」 |
| 5 | 지도 오른쪽 진행 중 퀘스트 → 그 자리 | **했다** |
| 6 | 마커 목록 거리 | 이미 있었다 (결정 2-94) — 이 정리가 틀렸다 |
| 7 | 벙커 지도 상인 · 창고 아이콘 | **벙커에는 지도가 없다** — 새로 만들지 사용자에게 물음 |
| 8 | 장 지도 「찾은 길목 n / 전체」 | 사용자 취소 |
| + | 아이템 상세 「어디서 얻나 · 어디에 쓰나」 | **했다** (사용자) |
