## 1. 감지

| 축 | 덕코프 분포 | 중앙값 | Dokkaebi 현재 | 판정 |
|---|---|---|---|---|
| 시야 거리 | 13~40 (15×7 · **17×14** · 18×7 · 21×7) | 17 | 18 | ✅ 맞음 |
| 시야 각도 | **100×14 · 120×5 · 140×27** · 150×2 · 360×4 | 140 | 80/100/120/150 | ⚠️ 80은 덕코프에 없다 |
| 반응 시간 | 0~0.8 (0.2×12 · **0.3×11** · 0.5×9) | 0.3 | 0.35 | ✅ 맞음 |

**시야 각도가 넷으로 딱 갈린다** — 100 / 120 / 140 / 150.
360은 전방위(포탑류), 음수는 특수 처리로 보인다.

## 2. 추적 — Dokkaebi와 모델이 다르다 ⚠️

| 축 | 덕코프 | Dokkaebi 현재 |
|---|---|---|
| 포기 조건 | **망각 시간**(초) — 8×35 · 22×16 · 30×4 · 120×1 · 180×3 | 목줄 거리 = 감지 거리 × 2 |
| 강제 추적 | **거리**(m) — 0×46 · 15×6 · 40×3 · 60×4 | `chasesForever` 불리언 (보안기만) |
| 순찰 범위 | 8×36 · 18×11 · 20×4 | 없음 |

덕코프는 **시간으로 잊고, 거리로 강제 추적**한다. Dokkaebi는 거리 하나로만 판단한다.

## 3. 청각 — Dokkaebi 설계와 정반대 ⚠️

덕코프는 **듣는 쪽마다 청각 능력**을 둔다.

```
청각 능력   0×3 · 0.3×1 · 0.75×19 · 1.0×29 · 1.5×1 · 2.0×3 · 5.0×2 · 20.0×1
```

그리고 플레이어 쪽에도 있다 — 「오렌지 헤드폰」:
```
소리로 위치 파악  +1
청력             +1
"청각 감도를 대폭 높여 소리 방향을 파악한다"
```

Dokkaebi는 7-D에서 **「소리 크기는 내는 쪽만 정한다」**로 결정했다.
이유는 「듣는 쪽마다 청력을 두면 같은 총성이 누구에겐 들리고 누구에겐 안 들려
유저가 예측할 수 없다」였는데, 덕코프는 **값을 거칠게 두어**(대부분 0.75 또는 1.0)
그 문제를 피한다. 특별히 잘 듣는 것은 보스급 몇뿐이다.

## 4. 생성 조건 — 7-G에 쓸 구조

```
생성 확률   100% 등
생성 수량   3 - 6
생성 시간   시간 제한 없음 / 22:00 - 5:00 / 21:00 - 5:00
생성 날씨   날씨 제한 없음 / 맑음, 흐림
```

구역별로 확률·수량·시간·날씨를 따로 잡는다.
Dokkaebi의 「시설 상태 3종(정전·침수·소독 사이클)」과 같은 축이다 —
**환경 조건이 스폰 표를 갈아끼운다.**

## 5. 그 외 확인된 것

- **난이도는 전리품에 영향이 없다.** "게임 파일을 뒤져본 결과, 난이도는 전리품 상자의
  드롭 배율이나 품질에 전혀 영향을 주지 않는다. 드롭을 결정하는 건 씬 설정이지 난이도가 아니다."
- 전리품 수량은 씬 설정의 `lootboxItemCountMultiplier`가 정한다.
- 피해 받음 배율이 7종 — 물리 / 화염 / 독 / 전기 / **공간** / **유령** / 얼음.
  Dokkaebi의 5종(물리·화염·냉기·번개·카오스)보다 둘 많다.
  늑대는 유령 0.1x — **특정 속성에 거의 완전 면역**인 적이 존재한다.
