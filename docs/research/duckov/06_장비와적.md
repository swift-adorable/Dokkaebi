## 2. 【핵심】 환경이 장비를 강제한다 [확인됨]

```
방한 작업복      "보온 성능이 뛰어나지만 극한의 추위는 막을 수 없다"
Lv.2 설원 방탄복  "보온 효과가 있긴 하지만, 효과가 미미하다"
Lv.3 설원 방탄복  "내부에 보온재를 간단히 덧댄 것 같다"

→ 구역이 장비 선택을 바꾼다. 방어도만 보고 고를 수 없다.

### 【핵심】 같은 적이 구역마다 다르다
```
늑대  제로존 체력 40 → 농장마을 65 → 37번 실험 구역 107

고스트 체력 130 · 경험치 100
```

### 보상 3종: 체력 / 경험치 / **현금**
```
일반  체력 40~130    경험치 30~150     현금 0~1,200
보스  체력 150~2,000 경험치 300~2,000  현금 0~9,000

**현금 보상이 구역마다 크게 다르다** — 같은 「쓰리샷 형님」이
농장마을에서는 경험치 800·현금 600, 아일랜드 챌린지에서는 경험치 300·**현금 6,000**.

→ **경험치를 벌 곳과 돈을 벌 곳이 다르다.**

## 7. Blob에 가져올 것

| 가져옴 | 이유 |
|---|---|
| **환경 전용 장비 라인** | 구역이 장비 선택을 바꾼다. 방어도만 보고 고를 수 없게 된다 |
| **세트 효과** | 우리 Equipment의 「누적 수치 게이트」와 같은 자리 |
| **장비 소켓** | 무기 개조 빈칸의 답. 보스 장비에만 슬롯을 두면 희소성도 선다 |
| **고유 효과 무기** | 티어 사슬만 있으면 "더 좋은 걸로 갈아탄다"뿐이다 |
| **진영** | 이미 설계에 있음. 5개 구성 참고 |
| **같은 적의 구역별 스케일링** | 우리는 "방어도만 올린다"로 정했으나 체력도 오르는 방식이 있다 |
| **경험치와 현금 분리** | 「어디서 벌 것인가」가 구역 선택의 이유가 된다 |
