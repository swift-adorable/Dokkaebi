## 2. 슬롯별 설계 패턴

### 총구 — 「무엇을 얻고 무엇을 잃는가」가 가장 선명하다

```
소음기        소리 범위 −75%  /  사거리 −10% · 탄환 속도 −10%
연장 총구     사거리 +30%     /  이동 −5% · 소리 범위 +30%
제퇴기 A형    반동 −13%×2 · 사거리 +15%
제퇴기 B형    반동 −23%×2                      ← 사거리를 포기하고 반동을 더
수직 제퇴기   수직 반동 −43%                   ← 한 축에 몰아준다
공격 강화     대미지 +10%     /  반동 +10%×2
```

> **같은 슬롯 안에서 「넓고 얕게 ↔ 좁고 깊게」가 갈린다.**
> A형(−13%×2 + 사거리)과 B형(−23%×2)이 같은 값 1100₡이다.

### 탄창 — 두 갈래뿐이다

```
확장 탄창 I    장탄 +50%
확장 탄창 II   장탄 +100%  /  조준 시간 +10%
확장 탄창 III  장탄 +150%  /  조준 시간 +20% · 이동 −5%

퀵 드로우 I    조준 −12% · 재장전 −20% · 이동 +5% · 조준 확산 회복 +12%
퀵 드로우 II   조준 −20% · 재장전 −30% · 이동 +5% · 조준 확산 회복 +8%
```

> **「많이 넣는다」 ↔ 「빨리 든다」.** 단 두 축인데 5단계 선택이 나온다.
> 퀵 드로우는 **대가가 없다** — 대신 장탄이 안 늘어난다는 것이 기회비용이다.

### 조준경 — 대가가 가장 무겁다

```
4배율   조준 거리 +120%  /  조준 시간 +0.8초 · 수직 반동 +70% · 수평 +30%
8배율   조준 거리 +250%  /  조준 시간 +1.3초 · 수직 반동 +100% · 수평 +30%
레드 도트 · 홀로그램 · 디지털 · 퀵 (성능 동일)
        치명타율 +0.02~0.12 · 대미지 +5~10%
```

> **배율계와 도트계가 완전히 다른 물건이다.** 배율은 거리를 사고 반동을 지불,
> 도트는 근거리 화력을 산다. **Lv.1~4가 수치가 같은 배율경**이 있다 — 티어가 곧 희귀도다.

### 개머리판 — 한 축만 판다

```
Lv.1~4   기본 지향사격 탄퍼짐 −10% / −15% / −25% / −40%
경량형   이동 +12%                    ← 유일한 예외
```

### 손잡이 — 확산 회복 전담

```
돌격 그립      조준 확산 회복 +20~50%
신속 분리형    지향사격 최대 확산 −10~25% · 지향사격 확산 회복 +20~50%
수직/수평 그립 해당 반동 −23% / −43%
```

### 전술 — 작고 대가가 없다

```
레이저   기본 지향사격 탄퍼짐 −10~40% · 치명타율 +0.03~0.25
플래시   기본 지향사격 탄퍼짐 −10~40% · 치명타 배율 +0.08~0.4
```

> **대가가 없는 대신 무게가 가볍고(0.05~0.15kg) 값이 비싸다.**
> Blob 문서의 「페널티 없는 부착물은 수급처를 막아 밸런싱한다」와 같은 처리다.

### 특수 모듈 — ★ 가장 중요한 발견

**무기 하나에만 끼울 수 있고, 그 총의 성격 자체를 바꾼다.**

```
SKS-45 정밀 모듈     치명타 배율 +0.75 · 사거리 +3.1 · 유닛 관통 +1
글록 3점사 모듈      대미지 −2 · 발사 속도 +3 · 점사 탄환수 +2 · 확산 증가 −0.37
M14 전자동 모듈      사격 모드 +3 · 탄창 +4 / 대미지 −4
Bizon-2 산탄화       대미지 +10 · 단발 탄환수 +4 · 각도 +23 / 발사 속도 −7 · 사거리 −4
RPD 발사 속도 모듈   탄창 +45 · 발사당 발사 속도 획득 +1.8 (연사할수록 빨라진다)
바이오 나노머신      통제 유형 +1 · 통제 지속 +30 / 치명타 배율 −1.1
```

> **수치가 전부 절대값이다.** 퍼센트가 아니라 「대미지 −2」 「탄창 +45」다.
> 전용 무기가 정해져 있으니 절대값으로 정확히 조율할 수 있다.
>
> 가격대가 3,000~8,600₡로 일반 부착물(380~5,000₡)보다 높고 **전부 고유급**이다.

## 3. Blob에 적용할 때의 판단 (구현 시점에)

**가져올 것**

1. **확산을 3축으로 쪼갠다** (최대 / 증가량 / 회복). 하나로 두면 부착물이 구분되지 않는다
2. **반동을 수직·수평으로 나눈다.** 같은 값의 다른 선택이 생긴다
3. **특수 모듈 = 무기 전용 + 절대값.** Blob의 「고유 장비 소켓」과 같은 자리다
4. **소리 범위** — Blob에 없는 축이다. 스텔스를 넣을 거라면 여기서 시작한다

**가져오지 않을 것**

1. **조준 시간 / 지향사격 구분** — Blob은 탑다운이고 조준 상태가 없다.
   확산 축 절반이 의미를 잃는다
2. **사격 모드 / 점사** — 모바일 한 손 조작에서 모드 전환은 부담이다
3. **Lv.1~4 수치가 같은 배율경** — 티어를 희귀도로만 쓰는 것은 Blob의
   「티어 = 장별 파밍 재료」와 어긋난다

**결정이 필요한 것**

- **치명타를 부착물에도 줄 것인가.** 덕코프는 조준경·레이저가 치명타율을 준다.
  Blob은 각인 「정밀」 전용으로 정했다(`Combat_Baseline` 6-A절).
  부착물에도 주면 **상한 50%를 다시 봐야 한다**
- **부착 슬롯을 무기 티어로만 가를 것인가.** 덕코프는 총기 계열별로
  끼울 수 있는 부착물이 다르다 (소총용 제퇴기 ≠ 권총용 제퇴기)
