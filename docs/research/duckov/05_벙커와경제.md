## 2. 【핵심】 건물이 NPC를 부른다 [확인됨]

업적에서 확인:
```
헬스장 건설      → 머드 입주
주방 건설        → 부처 형 입주
방어구 상점 건설 → 오렌지 입주
기술 센터 건설   → 잭 입주
무기 상점 건설   → 김씨 입주
```

**벙커를 짓는 것이 곧 등장인물을 모으는 것이다.** 시설 해금과 서사가 같은 동작이다.

## 3. 상점 11곳 [확인됨]

| 위치 | 상점 |
|---|---|
| 벙커 | 기술 센터 · 부처 형 · 머드 · 무기 상점 · 방어구 상점 · 잡화 상점 |
| 창고 구역 | 지하실 노점상 |
| 제로존 / 농장마을 / 아일랜드 | **비밀 상인** (구역마다) |
| 아일랜드 | 자판기 |

**구역 안에도 상인이 있다.** 런 도중에 팔고 살 수 있다.
그리고 **휴대용 자판기** 아이템(2,000)이 따로 있다 —
"언제든 아이템을 구매하거나 회수할 수 있다. 상품이 적고 비싸지만 회수 가격은 합리적이다."

## 4. 퀘스트 276개 [확인됨]

발급 NPC: **제프 · 오렌지 · 김씨 · 머드 · 부처 형**

### 작업 유형 5가지
```
아이템 제출하기      소형 구급상자 ×3 · 정육칼 ×2 · J-Lab 플로피 디스크 ×3
특정 대상 처치하기   폭주 넝마꾼 (0/2)
특정 위치로 이동     공장 직원 기숙사
아이템 사용하기      지혈 붕대 (0/1회)
구역에서 철수하기    제로존에서 철수
```

### 보상
경험치 + 골드 + 아이템. 레벨 요구가 붙는 것도 있다 (Lv.10).

### 관찰
- **초반 퀘스트가 곧 튜토리얼이다** — "지혈의 중요성" = 붕대 써보기,
  "덕코프에 온 걸 환영해" = 철수해보기.
- **퀘스트가 재료를 준다** — "처리하면 볼트와 너트를 사물함에 넣어둘게.
  작업대를 업그레이드하는 데 쓸 수 있을 거야."
  → **의뢰가 벙커 건설의 재료 공급원이다.**
- **특정 아이템을 들고 가야 하는 퀘스트** — "출발 전에 이동식 하드 드라이브를 챙기는 거 잊지 말고."
  가방 한 칸을 미리 비워야 한다.

## 6. Blob에 가져올 것

1. **벙커를 직접 짓는다.** 지금 Blob에는 벙커 개념만 있고 건물이 없다.
2. **건물이 NPC를 부른다.** 시설 해금과 서사 진행을 하나로 묶는다. 매우 강력하다.
3. **구역 안 상인 · 휴대용 자판기.** 런 도중의 판단(지금 팔까)이 생긴다.
4. **의뢰가 건설 재료를 준다.** 의뢰 → 건물 → NPC → 새 의뢰의 고리.
5. **초반 의뢰 = 튜토리얼.** 별도 튜토리얼을 만들지 않는다.
6. **엔딩 복수.** 우리 스토리 6장에 엔딩 분기를 둘 수 있다.
7. **자동 수입 건물(채굴기).** 접속하지 않아도 도는 축. 모바일에서 특히 유효하다.
