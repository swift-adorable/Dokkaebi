## 2. 【핵심】 열쇠 자체가 최고가 전리품이다

비밀 열쇠 Z 하나가 253,228이다. 스킬 강화 계열 하나의 누적 총비용(807,738)의 **1/3**.

→ *"이 문을 열까, 팔까"* 가 성립한다.

## 3. 열쇠 등록기 — 소모 문제의 해법 [확인됨]

벙커 건물 **「열쇠 등록기」**:
> 열쇠를 등록하면 해당하는 문을 자유롭게 열 수 있다.

그리고 아이템 태그에 **「열쇠 (등록 불가)」** 가 따로 있다.
→ **등록 가능한 열쇠**와 **매번 들고 가야 하는 열쇠**가 나뉜다.

## 4. 반출 규칙 태그 [확인됨]

| 태그 | 뜻 |
|---|---|
| **반출 불가** | 런 밖으로 못 가지고 나온다 (「강화」 아이템 전부, 클리어 출입카드) |
| **귀속 장비** | 거래 불가로 보임 [불확실] — 토템 전부, 근접 무기 |
| **수리 가능** | 내구도가 있고 수리대에서 고칠 수 있다 |
| **전시품** | 벙커에 전시할 수 있다 |
| **장식용 장비** | 성능 없는 외형 |
| **퀘스트 아이템** | 가치 1, 의뢰 전용 |
| **레시피 / 고급 작업대 설계도** | 작업대에서 연구해 제작을 해금 |
| **기지 벽지** | 벙커 꾸미기 |

## 5. 하드코어 입장권 [확인됨]

```
챌린지 승선표   10,000
"목숨을 건 챌린지. 일단 처치되면 떨어진 물건은 하나도 빠짐없이 전부 사라진다."
```

**난이도가 슬라이더가 아니라 「사서 들어가는 티켓」이다.**
값을 치르고 더 위험한 구역에 들어간다.

## 6. Blob에 가져올 것

1. **열쇠 4계층과 고가 열쇠.** 지금 Blob의 열쇠는 ItemKind.Key 하나뿐이고 내용이 없다.
2. **열쇠 등록기.** 한 번 연 문은 계속 열 수 있게 하되, **등록 불가 열쇠**를 따로 둔다.
3. **반출 불가 태그.** 「런 안에서만 사는 아이템」을 만들 수 있다 —
   우리에게 지금 없는 축이다.
4. **승선표 = 이동 수단이자 소모품.** 구역 이동에 값을 매긴다.
5. **챌린지 승선표 = 하드코어 입장권.** 난이도 슬라이더보다 결정이 선명하다.
