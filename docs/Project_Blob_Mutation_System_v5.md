## 1. 도감 시스템 — 보완이 필요한 지점 먼저 말씀드립니다

### 1-1. 그대로 두면 생기는 문제

"한 번 얻으면 영구히 사용 가능"을 그대로 구현하면, **후반부에는 60개 전부를 보유한 상태로 레이드에 들어갑니다.** 이때 두 가지가 동시에 망가집니다.

| 문제 | 결과 |
|---|---|
| **선택 풀 희석** | 레벨업 시 60개 중 3장을 뽑으므로, 원하는 조합이 뜰 확률이 급락합니다. 빌드 설계 의도와 정반대의 결과 |
| **파워 인플레** | 매 레이드 최적 빌드를 들고 들어가므로 난이도가 무의미해집니다 |

**특히 첫 번째가 치명적입니다.** 도감을 채울수록 원하는 빌드를 만들기 어려워지는 역설이 생깁니다. 이는 "레이드에 맞게 빌드를 설계하고 싶다"는 의도와 충돌합니다.

### 1-2. 보완안 — 적재(Loadout) 제한

영구 보유는 그대로 유지하되, **레이드에 가져갈 수 있는 개수를 제한**합니다.

```
도감 (영구, 최대 60)
   ↓ 벙커에서 선택
적재 (레이드 1회, 초기 8칸 → 최대 14칸)
   ↓ 레이드 중 레벨업
선택지 3장 (적재한 것 중에서만 등장)
   ↓
실제 작동
```

**적재 제한이 없으면 빌드 설계가 불가능하고, 있으면 가능해집니다.** 8칸으로 좁히면 "이번 레이드는 화염 전이로 간다"가 선언이 되고, 레벨업마다 그 빌드가 실제로 완성됩니다. 영구 보유라는 요구는 온전히 지켜집니다 — 무엇을 가져갈지만 고를 뿐, 잃는 것은 없습니다.

| 항목 | 값 |
|---|---|
| 적재 슬롯 초기 | 8 |
| 적재 슬롯 최대 | 14 (추출 성공 누적으로 확장) |
| 필수 조건 | Core 최소 1개 포함 (없으면 공격 수단이 없음) |

> **14를 상한으로 둔 근거**: 한 런에서 실제로 작동 가능한 최대치가 Core 2 + Support 6(소켓 3×2) + 기원 Meta 1 + Persistent 약 4~5개(Nucleus 100 한도)입니다. 14를 넘으면 가져가도 쓸 수 없는 변이가 생겨 슬롯 확장이 무의미해집니다.

### 1-3. 도감 해금 — 추출 게임과 연결

변이는 레이드 밖에서 자동으로 해금되지 않습니다.

```
레이드 중 변이체(Mutant) 처치
  → 「변이 샘플」 드랍
  → 흡수
  → 추출 성공  → 도감에 영구 등록
     추출 실패  → 샘플 소실
```

**이 구조가 Blob의 장르와 정확히 맞물립니다.** 미해금 변이 샘플을 들고 있을 때 "지금 나갈까, 더 돌까"라는 추출 게임 고유의 긴장이 발생합니다. 반면 **이미 도감에 등록된 변이는 사망해도 잃지 않으므로**, `Blob_Prompt.txt`가 요구한 "하이 리스크 구조에서 이탈을 막는 안전장치"로도 기능합니다. Duckov의 개(dog) 슬롯과 같은 역할입니다.

### 1-4. 레이드 특성 — "레이드에 맞게 설계"를 실제로 만드는 장치

**레이드가 전부 똑같으면 매번 같은 적재를 들고 갑니다.** 빌드 설계가 성립하려면 레이드가 서로 달라야 합니다. 진입 전에 특성이 공개되고, 유저는 그에 맞춰 적재를 짭니다.

| 특성 | 내용 | 유리 | 불리 |
|---|---|---|---|
| **밀집 서식** | 적이 무리 단위로 뭉쳐 있음 | 전이 · 확산 · 범위 · 전령 | 단일 집중 |
| **산개 순찰** | 적이 넓게 흩어져 개별 조우 | 단일 화력 · 기동 · 관통 | 전이 · 연쇄 |
| **경화 외피** | 적 방어도가 높음 | 관통 · 즉발 화력 | 지속 피해 |
| **재생 조직** | 적이 체력을 회복함 | 즉발 화력 | 점화 · 중독 |
| **저온 적응** | 냉기 저항 높음 | — | 서리 |
| **절연 피막** | 번개 저항 높음 | — | 뇌전 |
| **응고 혈액** | 출혈 지속시간 절반 | — | 열상 |
| **부식 대기** | Biomass 흡수량 감소 (레벨업 지연) | 저레벨 완성형 빌드 | 후반 스케일 빌드 |

한 레이드에 **1~2개**가 부여됩니다.

> **「저온 적응」 같은 속성 봉인 특성이 필요한 이유**: 유저가 가장 강한 속성 하나를 찾아내면 이후 모든 레이드를 그것으로 돌게 됩니다. 속성 봉인은 강제로 2지망·3지망 빌드를 경험하게 만들고, 그 과정에서 도감의 나머지 변이에 가치가 생깁니다.

### 1-5. 런 중 규칙

- 적재한 변이 중 **레벨업 시 3장**이 제시됩니다
- 선택한 것만 실제 작동합니다. 적재했다고 자동 보유가 아닙니다
- **런 종료 시 전부 초기화**됩니다. 도감과 적재 구성만 남습니다

## 2. 적 모델 정정

v4는 `EnemyManager`의 **동시 생존 상한 60**을 "동시에 60마리가 추격한다"로 잘못 해석했습니다. 정정합니다.

| 항목 | 정정된 내용 |
|---|---|
| 총량 | **맵마다 다릅니다.** 60은 성능 상한이며 설계 전제가 아닙니다 |
| 분포 | 맵 전역에 **넓게 분산**되어 있습니다 |
| 조우 방식 | 유저가 탐험하며 **소규모로 점진적으로** 만납니다 |

### 이 정정이 설계에 미치는 영향

| 항목 | v4 판단 | v5 정정 |
|---|---|---|
| **전투 형태** | 상시 군집 생존 | **소규모 조우의 반복 + 탐험** |
| **전령(처치 시 연쇄)** | 항상 강력 | **무리를 만났을 때만 빛남** → 레이드 특성 「밀집 서식」과 연동되는 조건부 강함으로 재배치 |
| **단일 화력** | 저평가 | **재평가.** 「산개 순찰」에서는 단일 화력이 정답 |
| **기동·탐색 유틸** | 부수적 | **핵심으로 격상.** 탐험이 플레이 시간의 큰 비중을 차지 |
| **기세(이동 중 강화)** | 그저 선택지 | **탐험 루프와 가장 잘 맞는 Support** |
| **충격파** | "포위 해소"로 정당화 | 근거 교체 — 아래 참조 |
| **정지 보상형** | "즉사하므로 제거" | 사유 교체 — 아래 참조 |

**충격파의 재근거**: `EnemyAttack`은 사거리 1.6m 진입 → 예비동작 0.35초 → **판정 시점에 사거리를 재확인**합니다. 즉 밀어내기는 판정 실패를 유도하는 **능동 방어 수단**입니다. 포위 해소가 아니라 텔레그래프 구조 자체와 맞물립니다. 근거가 더 견고해졌습니다.

**정지 보상형을 제거한 재사유**: 즉사 때문이 아닙니다. Blob의 핵심 방어 동사가 **대시 회피**이므로, 정지를 보상하는 변이는 방어 행동과 직접 충돌합니다. 유저가 살아남는 방법과 강해지는 방법이 반대 방향을 가리키면 그 변이는 선택되지 않습니다.

## 3. 소환 계열 제거

| 제거 | 영향 |
|---|---|
| 공격 드론 / 자동 포탑 | Core 역할이 4분류 → **3분류**로 축소 |
| 분열의 `포자` 객체 | 분열은 순수 투사체 분열로 단순화 |
| Support「군체」「불안정 코어」 | 삭제 |
| `소환수` `지속형` 태그 | 폐기. 태그 16개 → **14개** |
| 지형 상태「전기장」 | 삭제 (포탑 연결로만 생성되던 상태) |
| Nucleus 경쟁 구조 | 3파전 → **전령 vs 유틸 2파전**. 전령 비용을 40→45로 상향해 긴장 유지 |

> **뇌전이 지대를 만들지 않게 된 점은 의도적으로 유지합니다.** 5속성 중 하나는 지대가 없어도 됩니다. 뇌전은 **증폭 특화**(받는 피해 +20%)라는 고유 역할이 이미 있으므로, 지대까지 주면 차별성이 사라집니다.

# 4. 태그 — 14

| 태그 | 의미 |
|---|---|
| `투사체` | 탄환을 발사한다 |
| `화염` `냉기` `번개` `카오스` `물리` | 피해 유형 |
| `효과범위` | 범위 피해를 준다 |
| `지대` | 바닥에 장판을 남긴다 |
| `기폭장치` | 다른 것을 터뜨릴 수 있다 |
| `지속시간` | 시간 개념이 있다 |
| `유지형` | Nucleus를 점유한다 |
| `발동` | 다른 것을 트리거한다 |
| `조건부` | 발동 조건이 있다 |
| `청산` | 상태이상을 소모한다 |

### 태그 게이팅

```
Support의 요구 태그를 Core가 전부 포함하면 → 장착 가능
하나라도 없으면 → 장착 불가. 선택창에도 등장하지 않음
```

이 규칙 하나로 죽은 선택지가 사라지고, 개별 조합 규칙을 정의할 필요가 없어집니다.

# 6. 핵심 변이 (Core Mutation) — 12

소켓 **3개** 보유. 동시 보유 상한 **2개**.

```
전달 계열  →  적재 계열  →  기폭 계열
(어떻게 닿는가)  (무엇을 남기는가)  (무엇을 소모하는가)
```

## 6-1. 전달 계열 — 4

상태를 만들지 않습니다. 반드시 적재 계열과 결합해야 의미가 생깁니다.

| 이름 | Lv | 태그 | 작동 |
|---|---|---|---|
| **튕겨 쏘기** | 1 | `투사체` | 탄환이 지형에 충돌하면 튕겨 나갑니다. 기본 3회. 튕길 때마다 상태 부여 판정이 새로 발생합니다 |
| **관통** | 1 | `투사체` | 탄환이 적을 뚫고 일직선상의 모든 대상을 연속 타격합니다. 기본 3체 |
| **분열** | 3 | `투사체` | 최초 적중 시 탄환이 3갈래로 갈라집니다. 갈라진 탄은 재분열하지 않습니다 |
| **추적** | 5 | `투사체` | 탄환이 가장 가까운 적을 추적합니다. **이미 상태이상이 걸린 적을 우선 추적**합니다 |

> **튕겨 쏘기와 관통은 서로를 막지 않습니다.** 튕겨 쏘기는 지형 충돌, 관통은 적 충돌에서 발동하므로 충돌 우선순위 큐를 공유하지 않습니다. poe2db의 「튕겨 쏘기」가 지형 충돌 시에만 연쇄를 부여하는 구조와 같습니다. [확인됨]

## 6-2. 적재 계열 — 5

적에게 **상태를 남기는 것이 본체**입니다. 피해는 부수 효과입니다.

| 이름 | Lv | 태그 | 작동 | 생성 |
|---|---|---|---|---|
| **화염** | 1 | `화염` `지속시간` | 적중한 적을 점화시킵니다. 점화된 적이 사망하면 화염 지대가 남습니다 | 점화 |
| **역병** | 1 | `카오스` `지속시간` | 적중마다 중독을 중첩시킵니다. 10중첩 도달 시 `위독` 상태가 되어 중독 피해가 2배가 됩니다 | 중독 |
| **서리** | 3 | `냉기` | 냉기를 누적시켜 임계치 초과 시 동결시킵니다. 피해는 낮지만 행동을 봉쇄합니다 | 동결 |
| **뇌전** | 5 | `번개` | 적을 감전시켜 **받는 모든 피해를 20% 증폭**시킵니다. 단독 피해는 가장 낮습니다 | 감전 |
| **열상** | 7 | `물리` `지속시간` | 출혈을 유발합니다. **이동 중인 적에게 피해가 배증**되므로 추격형 적에게 강합니다 | 출혈 |

> **속성별 역할 분화**: 뇌전은 단독으로 약하지만 다른 모든 피해를 증폭시키고, 서리는 피해가 거의 없지만 생존을 책임지며, 열상은 적의 행동 패턴에 의존합니다. "무조건 화염"을 막기 위한 의도적 설계입니다.

## 6-3. 기폭 계열 — 3

| **얼음의 전령** | 11 | 45 | 동결된 적 처치 | 얼음 폭발 + 주변 동결 |
| **천둥의 전령** | 11 | 45 | 감전된 적 처치 | 주변 전체에 번개 방출 |
| **역병의 전령** | 11 | 45 | 중독된 적 처치 | 중독이 주변으로 확산 |
| **피의 전령** | 11 | 45 | 출혈 적 처치 | 축적 출혈량 비례 혈액 폭발 |

> **명칭 근거**: poe2db에 재의 전령, 얼음의 전령, 천둥의 전령, 역병의 전령, 피의 전령이 실제로 존재하며, 전부 조건부 처치 시 연쇄 폭발 구조입니다. 재의 전령은 과잉살상 처치 시 점화 폭발을, 역병의 전령은 중독된 적 처치 시 중독 확산을 일으킵니다. [확인됨]

> **v5에서 전령은 "조건부 강함"으로 재배치되었습니다.** 적이 분산된 구조에서는 처치 연쇄가 항상 강하지 않습니다. **「밀집 서식」 레이드에서만 최대 가치**를 냅니다. 이것이 오히려 도감 체제에 유리합니다 — 유저는 레이드 특성을 보고 전령을 넣을지 뺄지 판단하게 됩니다.

## 9-3. Nucleus 경제

소환 계열이 사라지면서 **전령 vs 유틸 2파전**이 되었습니다. 이에 맞춰 전령 비용을 40 → **45**로 상향했습니다.

| 구성 예 | 점유 | 남는 Nucleus |
|---|---|---|
| 전령 2개 | 90 | 10 (감각 확장만 가능) |
| 전령 1 + 최후의 막 + 기동 | 105 | **초과 — 불가능** |
| 전령 1 + 최후의 막 + 감각 확장 | 95 | 5 |
| 유틸 올인 (활력·경화 피막·최후의 막·인력장·감각 확장) | 120 | **초과 — 불가능** |

**"전령 하나를 넣으면 생존 유틸을 거의 못 든다"**가 성립합니다. 체력 10 / 짧은 TTK 환경에서 이는 실질적 선택입니다.

# 10. 충돌 우선순위 큐

`Blob_Prompt.txt` 10절 확정 사항입니다.

```
Split → Pierce → Fork → Chain → Return
```

**한 번의 충돌에는 단 하나만 해결됩니다.**

| 단계 | 담당 |
|---|---|
| Split | 분열 (Core) |
| Pierce | 관통 (Core) / 고밀도 탄심 (Support) |
| Fork | 다중 사격 / 다중 분열 (Support) |
| Chain | 추적 (Core) / 유도 튕김 (Support) |
| Return | 회귀 (Support) — **재타격이 허용되는 유일한 예외** |

**튕겨 쏘기는 이 큐와 별개입니다.** 지형 충돌에서 발동하며 적 충돌 큐를 소모하지 않습니다.

### 배타가 자동 발생하는 구조

관통과 다중 사격을 둘 다 보유하면 한 충돌에서 관통만 해결되고 Fork는 발동하지 않습니다. **곱연산이 일어나지 않습니다.** 수치 인플레 없이 선택의 무게가 생깁니다.

# 12. 조합 예시

레이드 특성과 적재를 함께 기술합니다.

**① 「밀집 서식」 — 전이 특화**
- 적재: 분열 / 화염 / 원소 작렬 / 도깨비불 / 다중 분열 / 재의 전령 / 인력장 / 기세
- 작동 원리: 분열탄이 다수 적중 판정을 만들어 점화를 뿌리고, 도깨비불이 점화를 주변으로 퍼뜨립니다.
- 트리거: 점화된 적이 사망하는 시점
- 상태 변화: 재의 전령이 점화 폭발을 일으켜 주변을 다시 점화시키고, 원소 작렬이 남은 점화를 소모해 화염 지대를 깝니다. → **무리 하나가 통째로 연쇄 소멸**

**② 「산개 순찰」 — 단일 화력 특화**
- 적재: 관통 / 열상 / 유혈 충동 / 회귀 / 깊은 상처 / 혈액의 기원 / 기동 / 감각 확장
- 작동 원리: 관통탄이 출혈을 걸고, 회귀로 같은 대상을 두 번 때립니다. 유혈 충동은 출혈을 만들지 못하므로 열상이 필수입니다.
- 트리거: 유저가 게이지를 확인하고 **직접 기원 버튼을 누르는 시점**
- 상태 변화: 저장된 출혈량에 비례한 전방 관통 분출이 발생합니다. → **개별 조우를 빠르게 정리하고, 강적에게 저장분을 터뜨림**

**③ 「경화 외피」 — 관통 · 증폭 특화**
- 적재: 관통 / 뇌전 / 감전 전도 / 고밀도 탄심 / 감전 시 발동 / 천둥의 전령 / 기동
- 작동 원리: 관통탄이 일렬로 감전을 걸어 **받는 피해를 20% 증폭**시키고, 감전 전도가 인접으로 퍼뜨립니다.
- 트리거: 감전 유발 누적으로 감전 시 발동 에너지가 100% 도달
- 상태 변화: 화면 내 감전된 모든 적에게 낙뢰가 떨어집니다. → **방어도가 높아 지속 피해가 통하지 않는 적을 증폭 + 즉발로 공략**

**④ 「저온 적응」 — 속성 조율 공략**
- 적재: 관통 / 서리 / 속성 조율 / 살을 에는 서리 / 원소 작렬 / 긴 퓨즈 / 최후의 막
- 작동 원리: 완성된 서리 빌드를 그대로 가져가되, 속성 조율로 냉기를 화염으로 전환합니다. 살을 에는 서리는 무효화되지만 나머지는 살아남습니다.
- 트리거: 속성 조율 획득 시점
- 상태 변화: 동결 기반 빌드가 점화 기반으로 전환되고, 긴 퓨즈가 누적 점화를 한 번에 소모합니다. → **봉인된 속성을 우회**

**⑤ 「재생 조직」 — 즉발 화력 특화**
- 적재: 튕겨 쏘기 / 서리 / 동결 / 살을 에는 서리 / 원소 작렬 / 짧은 퓨즈 / 충격파
- 작동 원리: 지속 피해가 재생에 상쇄되므로 동결로 행동을 봉쇄하고 즉발로 처리합니다. 살을 에는 서리가 동결을 소모하고, 동결이 다시 공급합니다.
- 트리거: 냉기 누적이 임계치를 넘겨 적이 동결되는 시점
- 상태 변화: 공급과 소비가 경쟁하며, 남은 동결은 원소 작렬이 짧은 퓨즈로 즉시 파편 폭발시킵니다. → **재생할 틈을 주지 않는 즉발 루프**
