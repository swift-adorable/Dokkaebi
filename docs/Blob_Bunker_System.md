# Bunker System — 벙커

> **담당** — 런과 런 사이에 무엇을 하는가 · 왜 다시 들어가는가
> **근거** — 덕코프 건물 24 · 상점 11 · 퀘스트 276 (조사: [`research/duckov/05_벙커와경제.md`](research/duckov/05_벙커와경제.md))

## 0. 방침

추출 루팅 게임의 절반은 **밖**이 아니라 **안**에 있다.
가지고 나온 것을 어디에 쓰는가가 정해지지 않으면 파밍은 숫자 쌓기가 된다.

### 【핵심 결정】 벙커는 직접 짓는다

덕코프는 벙커 건물을 크레딧 + 재료로 짓는다. [확인됨]
그리고 **건물을 지으면 NPC가 입주한다.** [확인됨]

```
헬스장 → 머드 / 주방 → 부처 형 / 방어구 상점 → 오렌지
기술 센터 → 잭 / 무기 상점 → 김씨
```

**시설 해금과 서사 진행이 같은 동작이다.** 이것을 그대로 가져온다.

## 1. 건물 3분류

| 분류 | 무엇 | Blob 건물 |
|---|---|---|
| **기능** | 할 수 있는 일이 늘어난다 | 작업대 · 정제조 · 보관고 · 등록대 · 중계기 · 배양조 |
| **거래** | 사고 판다 | 무기상 · 방호상 · 잡화상 |
| **기록** | 본 것을 남긴다 | 도감대 · 표본장 · 레코더 선반 |

## 2. 기능 건물

| 건물 | 여는 것 | 입주 NPC |
|---|---|---|
| **작업대** | 제작 · 수리 · 분해 | — |
| **정제조** | 인자 분해 → 재료 회수 | — |
| **보관고** | 창고 칸 (패시브 「중개」로 확장) | — |
| **등록대** | **열쇠를 등록하면 그 문을 계속 열 수 있다** | — |
| **중계기** | 상점 갱신 · 의뢰 수신 | — |
| **배양조** | **자동 수입** — 접속하지 않아도 생체 재료가 쌓인다 | — |

> **등록대**는 덕코프 「열쇠 등록기」다. [확인됨]
> 열쇠를 매번 들고 가야 하면 가방 한 칸이 영구히 묶인다. 등록하면 풀린다.
> 단, **등록 불가 열쇠**를 따로 둔다 — 최고 등급 문은 매번 들고 가야 한다.
>
> **배양조**는 덕코프 「비트코인 채굴기」다. [확인됨]
> 모바일에서 특히 유효하다 — 접속하지 않는 시간에도 축이 하나 돈다.

## 3. 거래 건물

| 건물 | 판매 | 입주 |
|---|---|---|
| **무기상** | 무기 티어 1~3 · 탄약 | 「정비공」 |
| **방호상** | 방어구 · 가방 · 각인 Ⅰ·Ⅱ | 「봉합사」 |
| **잡화상** | 소모품 · 재료 · **매입** | 「수거인」 |

### 규칙
- **각인 Ⅲ은 팔지 않는다.** 돈으로 극단을 사면 결정이 아니라 구매가 된다.
- **무기 티어 4~6은 팔지 않는다.** 설계도를 구해 만들어야 한다.
- 매입가 = 가치의 50% (패시브 「중개」로 상승)
- 재고는 주기적으로 갱신된다 (중계기로 주기 단축)

### 구역 안의 상인

덕코프는 **구역 안에도 상인이 있다.** [확인됨] (비밀 상인 · 노점상 · 자판기)
Blob도 둔다 — **「수집기」**. 각 장에 하나씩, 고정 위치.

> 런 도중에 팔 수 있으면 **「지금 팔고 더 들어갈까, 들고 나갈까」** 가 생긴다.
> 추출 지점까지 가지 않아도 일부를 확정할 수 있는 안전판이다.

## 4. 기록 건물

| 건물 | 무엇 |
|---|---|
| **도감대** | 해금 기록. 드랍 풀과 제작을 넓힌다 ([`Skill_System.md`](Blob_Skill_System.md) 11-2절) |
| **표본장** | 처치한 원형을 전시. 등급별 정보가 해금된다 |
| **레코더 선반** | 수집한 레코더 재생 ([`Progression_System.md`](Blob_Progression_System.md) 5절) |

## 5. 제작 — 만들려면 먼저 바쳐야 한다

덕코프 작업대의 규칙을 그대로 가져온다. [확인됨]

```
방어구 제작 Ⅰ  해금 비용: Lv.3 방탄복 ×1 · 특공대 헬멧 ×1 · 여행 가방 ×1
철갑탄 제조    해금 비용: 철갑탄 6종
```

**만들 수 있게 되려면 그 물건의 견본을 바친다.**
규칙이 한 줄로 설명되고, 파밍 목표가 명확해진다.

| 작업대 단계 | 여는 것 | 해금 비용 |
|---|---|---|
| Ⅰ | 기초 소모품 · 탄약 | 재료만 |
| Ⅱ | 방어구 티어 1~3 | **해당 방어구 견본** |
| Ⅲ | 관통탄 · 방호구 | **관통탄 견본 + 오염 샘플** |
| Ⅳ | 무기 티어 4~6 | **설계도 + 하위 티어 무기 견본** |

## 6. 의뢰 — 벙커와 밖을 잇는다

덕코프 퀘스트 276개의 작업 유형은 5가지뿐이다. [확인됨]

```
아이템 제출 · 대상 처치 · 위치 도달 · 아이템 사용 · 구역에서 철수
```

Blob도 이 다섯으로 간다. **유형을 늘리지 않는다.**

### 의뢰가 하는 일 3가지

1. **건설 재료 공급** — 덕코프: "처리하면 볼트와 너트를 사물함에 넣어둘게.
   작업대를 업그레이드하는 데 쓸 수 있을 거야." [확인됨]
   → 의뢰 → 재료 → 건물 → NPC → 새 의뢰의 고리
2. **튜토리얼** — 초반 의뢰가 곧 조작 학습이다.
   덕코프: 「지혈의 중요성 — 붕대로 한번 지혈해 봐」 [확인됨]
   **별도 튜토리얼을 만들지 않는다.**
3. **가방 계획** — "출발 전에 이동식 하드 드라이브를 챙기는 거 잊지 말고" [확인됨]
   들고 들어가야 하는 의뢰가 가방 한 칸을 미리 묶는다.

## 7. 절대 금지 사항

1. **의뢰 작업 유형을 5개 초과로 늘리지 않는다.** 276개가 5유형으로 돌아간다.
2. **별도 튜토리얼을 만들지 않는다.** 초반 의뢰가 그 일을 한다.
3. **상점에서 최상위를 팔지 않는다.** 각인 Ⅲ · 무기 티어 4~6.
4. **건물을 순수 장식으로 만들지 않는다.** 전시 기능은 표본장·레코더 선반에 묶는다.
   덕코프의 더미·진열장 같은 순수 전시 건물은 넣지 않는다 — 우리 규모에서는 사치다.
5. **자동 수입을 크레딧으로 주지 않는다.** 배양조는 **재료**를 준다.
   돈이 자동으로 들어오면 파밍할 이유가 준다.
